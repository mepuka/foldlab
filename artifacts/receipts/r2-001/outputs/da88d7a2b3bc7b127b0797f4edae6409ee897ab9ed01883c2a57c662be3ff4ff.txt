# Finding All Palindromes with Digit Sum = 13 (No Zeros)

## Step 1: Categorize by Palindrome Length

I need to find palindromes where:
- All digits are from {1, 2, 3, 4, 5, 6, 7, 8, 9} (no zeros)
- The sum of all digits equals 13

For an n-digit palindrome, only the first ⌈n/2⌉ digits need to be chosen; the rest are determined by symmetry.

---

## Step 2: Identify Independent Positions for Each Length

| Length | Independent Positions | Count |
|--------|----------------------|-------|
| 1 | 1st | 1 |
| 2 | 1st (appears 2×) | 1 |
| 3 | 1st, 2nd (middle) | 2 |
| 4 | 1st, 2nd (each appears 2×) | 2 |
| 5 | 1st, 2nd, 3rd (middle) | 3 |
| 6 | 1st, 2nd, 3rd (each appears 2×) | 3 |

## Step 3 & 4: Find Valid Digit Combinations for Each Length

### **1-digit palindromes**
- Form: a
- Constraint: a = 13
- **Impossible** (digit max = 9)
- **Count: 0**

### **2-digit palindromes**
- Form: aa (same digit appears twice)
- Constraint: 2a = 13
- **Impossible** (13 is odd)
- **Count: 0**

### **3-digit palindromes**
- Form: aba (1st digit, 2nd digit, 1st digit)
- Constraint: 2a + b = 13
- Digits a, b ∈ {1,2,3,4,5,6,7,8,9}

Solving for b: b = 13 - 2a

| a | b | Valid? | Palindrome |
|---|---|--------|-----------|
| 1 | 11 | ✗ (b > 9) | |
| 2 | 9 | ✓ | 292 |
| 3 | 7 | ✓ | 373 |
| 4 | 5 | ✓ | 454 |
| 5 | 3 | ✓ | 535 |
| 6 | 1 | ✓ | 616 |
| 7 | -1 | ✗ (b < 1) | |

**Count: 5**

### **4-digit palindromes**
- Form: abba (1st, 2nd, 2nd, 1st)
- Constraint: 2a + 2b = 13
- Constraint: a + b = 6.5
- **Impossible** (sum must be integer)
- **Count: 0**

### **5-digit palindromes**
- Form: abcba (1st, 2nd, 3rd, 2nd, 1st)
- Constraint: 2a + 2b + c = 13
- Digits a, b, c ∈ {1,2,3,4,5,6,7,8,9}

Solving for c: c = 13 - 2a - 2b

For c to be valid: 1 ≤ 13 - 2a - 2b ≤ 9
- From c ≥ 1: 2a + 2b ≤ 12, so a + b ≤ 6
- From c ≤ 9: 2a + 2b ≥ 4, so a + b ≥ 2

Valid combinations where a + b ≤ 6 and a + b ≥ 2:

| a | b | a+b | c = 13-2a-2b | Valid? | Palindrome |
|---|---|-----|--------------|--------|-----------|
| 1 | 1 | 2 | 9 | ✓ | 11911 |
| 1 | 2 | 3 | 7 | ✓ | 12721 |
| 1 | 3 | 4 | 5 | ✓ | 13531 |
| 1 | 4 | 5 | 3 | ✓ | 14341 |
| 1 | 5 | 6 | 1 | ✓ | 15151 |
| 2 | 1 | 3 | 7 | ✓ | 21712 |
| 2 | 2 | 4 | 5 | ✓ | 22522 |
| 2 | 3 | 5 | 3 | ✓ | 23332 |
| 2 | 4 | 6 | 1 | ✓ | 24142 |
| 3 | 1 | 4 | 5 | ✓ | 31513 |
| 3 | 2 | 5 | 3 | ✓ | 32223 |
| 3 | 3 | 6 | 1 | ✓ | 33133 |
| 4 | 1 | 5 | 3 | ✓ | 41314 |
| 4 | 2 | 6 | 1 | ✓ | 42124 |
| 5 | 1 | 6 | 1 | ✓ | 51115 |

**Count: 15**

### **6-digit palindromes and beyond**
- Form: abccba (or longer)
- Constraint: 2a + 2b + 2c = 13
- Constraint: a + b + c = 6.5
- **Impossible** (sum must be integer)
- **Count: 0**

For any even-length palindrome ≥ 6 digits, the constraint is 2(sum of independent digits) = 13, which is impossible.

For odd-length ≥ 7 digits, the sum grows too large.
