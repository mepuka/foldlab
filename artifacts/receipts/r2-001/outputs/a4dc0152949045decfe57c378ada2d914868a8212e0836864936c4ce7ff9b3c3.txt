# Solution: Finding All Possible Values of BC

## What We're Calculating
We need to find all valid configurations of triangle $ABC$ where:
- $AB = 200$, $AC = 225$
- $AD$ bisects $\angle BAC$
- Circle $\omega$ passes through $A$, is tangent to $BC$ at $D$, and intersects $AB$ at $E$ and $AC$ at $F$
- Then sum all possible values of $BC$

## Complete Calculation

### Step 1: Apply the Angle Bisector Theorem
By the angle bisector theorem:
$$\frac{BD}{DC} = \frac{AB}{AC} = \frac{200}{225} = \frac{8}{9}$$

Let $BD = 8k$ and $DC = 9k$ for positive value $k$.
$$BC = 17k$$

### Step 2: Apply Power of a Point

**For point $B$** (using tangency at $D$):
$$BA \cdot BE = BD^2$$
$$200 \cdot BE = (8k)^2 = 64k^2$$
$$BE = \frac{8k^2}{25}$$
$$AE = 200 - \frac{8k^2}{25} = \frac{5000 - 8k^2}{25}$$

**For point $C$**:
$$CA \cdot CF = CD^2$$
$$225 \cdot CF = (9k)^2 = 81k^2$$
$$CF = \frac{9k^2}{25}$$
$$AF = 225 - \frac{9k^2}{25} = \frac{5625 - 9k^2}{25}$$

### Step 3: Integer Constraint Analysis

For $AE$ to be an integer:
$$5000 - 8k^2 \equiv 0 \pmod{25}$$
Since $5000 \equiv 0 \pmod{25}$: $8k^2 \equiv 0 \pmod{25}$

For $AF$ to be an integer:
$$5625 - 9k^2 \equiv 0 \pmod{25}$$
Since $5625 \equiv 0 \pmod{25}$: $9k^2 \equiv 0 \pmod{25}$

Since $\gcd(8,25) = \gcd(9,25) = 1$, we need:
$$k^2 \equiv 0 \pmod{25} \implies k = 5m \text{ for positive integer } m$$

### Step 4: Substitute k = 5m

$$AE = \frac{5000 - 8(25m^2)}{25} = 200 - 8m^2$$
$$AF = \frac{5625 - 9(25m^2)}{25} = 225 - 9m^2$$
$$BC = 85m$$

### Step 5: Find Valid Values of m

**Positivity constraints:**
- $AE > 0$: $200 - 8m^2 > 0 \implies m^2 < 25 \implies m \leq 4$
- $AF > 0$: $225 - 9m^2 > 0 \implies m^2 < 25 \implies m \leq 4$

**Check all valid values:**

| $m$ | $AE = 200 - 8m^2$ | $AF = 225 - 9m^2$ | $BC = 85m$ | Status |
|-----|-------------------|-------------------|------------|--------|
| 1   | 192               | 216               | 85         | ✓      |
| 2   | 168               | 189               | 170        | ✓      |
| 3   | 128               | 144               | 255        | ✓      |
| 4   | 72                | 81                | 340        | ✓      |

### Verification for m = 1
- $BD = 40$, $DC = 45$, $BC = 85$ ✓
- Power of $B$: $200 \times 8 = 1600 = 40^2$ ✓
- Power of $C$: $225 \times 9 = 2025 = 45^2$ ✓

### Step 6: Final Sum

$$85 + 170 + 255 + 340 = 850$$

Verification: $(85 + 340) + (170 + 255) = 425 + 425 = 850$ ✓

---

**FINAL ANSWER: 850**
