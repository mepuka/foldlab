## Step 1: Establish bounds on $n$

For $\lfloor \sqrt{n} \rfloor = k$, we have $k^2 \leq n < (k+1)^2$.

- When $k \geq 5$: $k! \geq 120$, so $k!^{n!}$ grows extremely fast
- For practical checking, focus on $n \leq 25$ where $\lfloor \sqrt{25} \rfloor = 5$
- Beyond this, divisibility becomes nearly impossible

## Step 2: Use factorial divisibility properties

Key insight: When $k! \geq n$ for prime $p \mid n$, we have $k! \equiv 0 \pmod{p}$.

## Step 3: Systematically check cases by $\lfloor \sqrt{n} \rfloor$ value

### **Case: $\lfloor \sqrt{n} \rfloor = 1$ (i.e., $n = 1$)**

### **Case: $\lfloor \sqrt{n} \rfloor = 2$ (i.e., $n \in \{2,3\}$)**

**$n = 2$**: $\lfloor \sqrt{2} \rfloor = 1$, so $1!^{2!} + 450 = 1 + 450 = 451 \equiv 1 \pmod{2}$ ✗

**$n = 3$**: $\lfloor \sqrt{3} \rfloor = 1$, so $1 + 450 = 451 \equiv 1 \pmod{3}$ ✗

### **Case: $\lfloor \sqrt{n} \rfloor = 3$ (i.e., $n \in \{4,5,6,7,8\}$)**

**$n = 4$**: $2!^{4!} + 450 = 2^{24} + 450 \pmod{4}$
- $2^{24} \equiv 0 \pmod{4}$, so $0 + 450 \equiv 2 \pmod{4}$ ✗

**$n = 5$**: $2!^{5!} + 450 = 2^{120} + 450 \pmod{5}$
- $2^4 \equiv 1 \pmod{5}$ (by Fermat), so $2^{120} \equiv 1 \pmod{5}$
- $450 \equiv 0 \pmod{5}$, so $1 + 0 \equiv 1 \pmod{5}$ ✗

**$n = 6$**: $2!^{6!} + 450 \pmod{6}$
