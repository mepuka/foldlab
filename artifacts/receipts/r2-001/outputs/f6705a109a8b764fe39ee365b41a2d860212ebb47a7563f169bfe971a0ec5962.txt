# Solution Plan

1. **Apply the Angle Bisector Theorem**
   - Since $AD$ bisects $\angle BAC$, use the angle bisector theorem to establish that $\frac{BD}{DC} = \frac{AB}{AC} = \frac{200}{225} = \frac{8}{9}$
   - Express $BD = 8k$ and $DC = 9k$ for some positive value $k$
   - Thus $BC = 17k$

2. **Use Power of a Point**
   - Apply power of point $B$ with respect to circle $\omega$: $BA \cdot BE = BD^2$
   - This gives $200 \cdot BE = (8k)^2$, so $BE = \frac{64k^2}{200} = \frac{8k^2}{25}$
   - Therefore $AE = 200 - \frac{8k^2}{25} = \frac{5000 - 8k^2}{25}$
   - Similarly for point $C$: $CA \cdot CF = CD^2$
   - This gives $225 \cdot CF = (9k)^2$, so $CF = \frac{81k^2}{225} = \frac{9k^2}{25}$
   - Therefore $AF = 225 - \frac{9k^2}{25} = \frac{5625 - 9k^2}{25}$

3. **Enforce Integer Constraints**
   - Require $AE = \frac{5000 - 8k^2}{25}$ to be a positive integer
   - Require $AF = \frac{5625 - 9k^2}{25}$ to be a positive integer
   - This means: $5000 - 8k^2 \equiv 0 \pmod{25}$ and $5625 - 9k^2 \equiv 0 \pmod{25}$
   - Simplify: $8k^2 \equiv 0 \pmod{25}$ and $9k^2 \equiv 0 \pmod{25}$
   - Since $\gcd(8,25) = \gcd(9,25) = 1$, we need $k^2 \equiv 0 \pmod{25}$, so $k \equiv 0 \pmod{5}$
   - Let $k = 5m$ for positive integer $m$

4. **Substitute and Simplify**
   - With $k = 5m$: $AE = 200 - 8m^2$ and $AF = 225 - 9m^2$
   - For $AE > 0$: $8m^2 < 200$, so $m^2 < 25$, giving $m \leq 4$
   - For $AF > 0$: $9m^2 < 225$, so $m^2 < 25$, giving $m \leq 4$
   - Also need $BE > 0$ and $CF > 0$ (automatically satisfied when $m \leq 4$)

5. **Find Valid Values of $m$**
   - Check $m \in \{1, 2, 3, 4\}$:
     - $m=1$: $AE = 192$, $AF = 216$, $BC = 85$ ✓
     - $m=2$: $AE = 168$, $AF = 189$, $BC = 170$ ✓
     - $m=3$: $AE = 128$, $AF = 144$, $BC = 255$ ✓
     - $m=4$: $AE = 72$, $AF = 81$, $BC = 340$ ✓

6. **Calculate Final Answer**
   - Sum of all possible values of $BC$: $85 + 170 + 255 + 340 = \boxed{850}$
