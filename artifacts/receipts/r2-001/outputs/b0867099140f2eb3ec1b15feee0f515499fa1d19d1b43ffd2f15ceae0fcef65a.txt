# Solution Plan

1. **Set up coordinate system**
   - Place $A$ at the origin $(0, 0, 0)$
   - Place $B$ at $(6, 0, 0)$
   - Place $C$ at $(0, 4, 0)$
   - Plane $\mathcal{P}$ is the $xy$-plane

2. **Find the centroid and point $D$**
   - Calculate centroid $G = \left(2, \frac{4}{3}, 0\right)$
   - Find line $BC$ and reflect $G$ across it to get point $D$
   - Determine coordinates of $D = (x_D, y_D, 0)$

3. **Identify sphere centers**
   - Sphere 1 center: $O_1 = (0, 0, 1)$ (radius 1)
   - Sphere 2 center: $O_2 = (6, 0, 2)$ (radius 2)
   - Sphere 3 center: $O_3 = (0, 4, 3)$ (radius 3)
   - Sphere 4 center: $O_4 = (x_D, y_D, r)$ (radius $r$)

4. **Apply mutual tangency conditions**
   - For spheres $i$ and $j$: $|O_i - O_j| = r_i + r_j$
   - Write three tangency equations using spheres 1-2, 1-3, and 2-3
   - Verify these equations are consistent with the configuration

5. **Use the common tangent plane $\mathcal{T}$**
   - Plane $\mathcal{T}$ is tangent to all four spheres on the same side
   - The distance from each center $O_i$ to plane $\mathcal{T}$ equals its radius $r_i$
   - Express plane $\mathcal{T}$ as $ax + by + cz = d$ (with $a^2 + b^2 + c^2 = 1$)

6. **Set up distance equations**
   - Write four equations: $\frac{|ax_i + by_i + cz_i - d|}{\sqrt{a^2+b^2+c^2}} = r_i$
   - With normalization, this becomes: $ax_i + by_i + cz_i - d = \pm r_i$

7. **Solve for plane parameters and $r$**
   - Use the constraint that all spheres are on the same side
   - Combine the four distance equations with the three tangency conditions
   - Solve the resulting system for $r$

8. **Express answer in lowest terms**
   - Simplify $r = \frac{m}{n}$ where $\gcd(m,n) = 1$
   - Calculate $m + n$
