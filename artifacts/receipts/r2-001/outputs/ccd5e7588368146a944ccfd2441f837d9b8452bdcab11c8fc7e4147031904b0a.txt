# Solution: Finding the Probability

## Step 1: Define the State Space
**State representation:** $(a, b, 0)$ where $a$ and $b$ are coins received by Alice and Bob.

- Start state: $(0, 0)$
- Goal: Reach any state where $a \geq 2$ AND $b \geq 2$
- Process terminates when Carol gets a coin (with probability $1/3$ at each step)

## Step 2: Identify Terminal and Target States

**Target states:** All $(a, b)$ where $a \geq 2$ and $b \geq 2$
- $P(a, b) = 1$ for these states (already won)

**Losing condition:** Carol gets a coin before reaching target

## Step 3: Set Up Transition Probabilities

From any state $(a, b)$ where goal not yet reached:
$$P(a, b) = \frac{1}{3}P(a+1, b) + \frac{1}{3}P(a, b+1) + \frac{1}{3}(0)$$

Simplifying:
$$P(a, b) = \frac{1}{3}[P(a+1, b) + P(a, b+1)]$$

## Step 4: Solve for States with $a \geq 2, b = 1$

For $a \geq 2$ and $b = 1$:
$$P(a, 1) = \frac{1}{3}[P(a+1, 1) + P(a, 2)]$$

Since $P(a, 2) = 1$ (goal reached), and assuming $P(a, 1)$ converges to constant $x$:
$$x = \frac{1}{3}[x + 1]$$
$$3x = x + 1$$
$$x = \frac{1}{2}$$

**Result:** $P(a, 1) = \frac{1}{2}$ for all $a \geq 2$ ✓

## Step 5: Solve for State $(2, 1)$ and $(1, 2)$

$$P(2, 1) = \frac{1}{3}[P(3, 1) + P(2, 2)] = \frac{1}{3}\left[\frac{1}{2} + 1\right] = \frac{1}{2}$$

By symmetry: $P(1, 2) = \frac{1}{2}$

## Step 6: Solve for State $(1, 1)$

$$P(1, 1) = \frac{1}{3}[P(2, 1) + P(1, 2)] = \frac{1}{3}\left[\frac{1}{2} + \frac{1}{2}\right] = \frac{1}{3}$$

## Step 7: Solve for States with $a \geq 2, b = 0$

For $a \geq 2$ and $b = 0$, assuming $P(a, 0) = y$ (constant):
$$y = \frac{1}{3}[y + P(a, 1)] = \frac{1}{3}\left[y + \frac{1}{2}\right]$$
$$3y = y + \frac{1}{2}$$
$$y = \frac{1}{4}$$

**Result:** $P(a, 0) = \frac{1}{4}$ for all $a \geq 2$ ✓

## Step 8: Solve for State $(1, 0)$

$$P(1, 0) = \frac{1}{3}[P(2, 0) + P(1, 1)] = \frac{1}{3}\left[\frac{1}{4} + \frac{1}{3}\right]$$
$$= \frac{1}{3} \cdot \frac{3 + 4}{12} = \frac{1}{3} \cdot \frac{7}{12} = \frac{7}{36}$$

## Step 9: Solve for States with $a = 0, b \geq 2$

By symmetry with the $b = 0$ case, assuming $P(0, b) = z$ for $b \geq 2$:
$$z = \frac{1}{3}\left[\frac{1}{2} + z\right]$$
$$z = \frac{1}{4}$$

**Result:** $P(0, 2) = \frac{1}{4}$

## Step 10: Solve for State $(0, 1)$

$$P(0, 1) = \frac{1}{3}[P(1, 1) + P(0, 2)] = \frac{1}{3}\left[\frac{1}{3} + \frac{1}{4}\right]$$
$$= \frac{1}{3} \cdot \frac{7}{12} = \frac{7}{36}$$

## Step 11: Solve for Initial State $(0, 0)$

$$P(0, 0) = \frac{1}{3}[P(1, 0) + P(0, 1)] = \frac{1}{3}\left[\frac{7}{36} + \frac{7}{36}\right]$$
$$= \frac{1}{3} \cdot \frac{14}{36} = \frac{14}{108} = \frac{7}{54}$$

## Step 12: Verify and Express as Fraction

$P(0, 0) = \frac{7}{54}$

Check: $\gcd(7, 54) = 1$ ✓ (fraction is in lowest terms)

Therefore: $m = 7$ and $n = 54$

## Step 13: Calculate Final Answer

$$100m + n = 100(7) + 54 = 700 + 54 = 754$$

**FINAL ANSWER: 754**
