# Solution

## Step 1: Set up the time equations
- Let $t$ = time (in hours) that Patrick walks until arrival at the park
- Tanya's travel time = $t - 1$ hours
- Jose's travel time = $t - 2$ hours

## Step 2: Write distance equations

Since distance = speed × time, and all three arrive at the same location (distance D):
- Patrick's distance: $D = p \cdot t$ where $p$ is Patrick's speed
- Tanya's distance: $D = (p + 2)(t - 1)$
- Jose's distance: $D = (p + 9)(t - 2)$

## Step 3: Set up equality equations

**Equation 1** (Patrick = Tanya):
$$pt = (p + 2)(t - 1)$$

**Equation 2** (Patrick = Jose):
$$pt = (p + 9)(t - 2)$$

## Step 4: Solve for $p$ using Equation 1

$$pt = (p + 2)(t - 1)$$
$$pt = pt - p + 2t - 2$$
$$0 = -p + 2t - 2$$
$$p = 2t - 2$$

## Step 5: Solve for $t$ using Equation 2

Substitute $p = 2t - 2$ into the second equation:
$$(2t - 2)t = (2t - 2 + 9)(t - 2)$$
$$2t^2 - 2t = (2t + 7)(t - 2)$$
$$2t^2 - 2t = 2t^2 - 4t + 7t - 14$$
$$2t^2 - 2t = 2t^2 + 3t - 14$$
$$-2t = 3t - 14$$
$$-5t = -14$$
$$t = \frac{14}{5}$$

## Step 6: Calculate $p$ and the distance

$$p = 2t - 2 = 2\left(\frac{14}{5}\right) - 2 = \frac{28}{5} - \frac{10}{5} = \frac{18}{5}$$

**Distance:**
$$D = p \cdot t = \frac{18}{5} \cdot \frac{14}{5} = \frac{252}{25}$$

## Step 7: Express in the form $\frac{m}{n}$

Check if $\frac{252}{25}$ is in lowest terms:
- $252 = 2^2 \cdot 3^2 \cdot 7$
- $25 = 5^2$
- $\gcd(252, 25) = 1$ ✓

Therefore: $m = 252$ and $n = 25$

## Step 8: Calculate the final answer

$$m + n = 252 + 25 = \boxed{277}$$
