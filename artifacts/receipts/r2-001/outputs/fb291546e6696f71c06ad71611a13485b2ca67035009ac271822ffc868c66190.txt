# Solution: Sphere Inside Hemisphere Problem

## 1. What We Are Calculating

We need to find the probability that a sphere of radius $r = 42$ centered at $(P_x, P_y, 42)$ lies completely inside a hemisphere of radius $R = 200$, expressed as a fraction $\frac{p}{q}$ in lowest terms, then compute $p + q$.

---

## 2. Complete Calculation with All Intermediate Steps

### Step A: Establish the Constraint Condition

For the sphere to lie completely inside the hemisphere:
- The center is at distance $d = \sqrt{P_x^2 + P_y^2 + 42^2}$ from the origin
- The farthest point on the sphere from the origin is at distance $d + 42$
- Constraint: $\sqrt{P_x^2 + P_y^2 + 42^2} + 42 \leq 200$

### Step B: Solve the Inequality

$$\sqrt{P_x^2 + P_y^2 + 42^2} \leq 158$$

Square both sides:
$$P_x^2 + P_y^2 + 42^2 \leq 158^2$$

Calculate the squared terms:
- $42^2 = 1,764$
- $158^2 = 24,964$

Substitute:
$$P_x^2 + P_y^2 + 1,764 \leq 24,964$$

$$P_x^2 + P_y^2 \leq 23,200$$

### Step C: Identify Region $\mathcal{T}$

The feasible region $\mathcal{T}$ is a disk centered at the origin with radius:
$$\rho = \sqrt{23,200}$$

Factor 23,200:
$$23,200 = 400 \times 58 = 20^2 \times 58$$

Therefore:
$$\rho = 20\sqrt{58}$$

### Step D: Calculate the Area Ratio

- Area of feasible region: $\pi \rho^2 = \pi(23,200)$
- Area of entire base disk: $\pi R^2 = \pi(200^2) = \pi(40,000)$

Ratio:
$$\frac{\pi(23,200)}{\pi(40,000)} = \frac{23,200}{40,000}$$

### Step E: Reduce to Lowest Terms

Find $\gcd(23,200, 40,000)$:
- $23,200 = 8 \times 29 \times 100 = 2^5 \times 5^2 \times 29$
- $40,000 = 16 \times 2,500 = 2^6 \times 5^4$
- $\gcd(23,200, 40,000) = 2^5 \times 5^2 = 800$

Simplify:
$$\frac{23,200}{40,000} = \frac{23,200 \div 800}{40,000 \div 800} = \frac{29}{50}$$

Verify coprimality: 29 is prime and doesn't divide 50 = $2 \times 5^2$, so $\gcd(29, 50) = 1$ ✓

---

## 3. Verification of Logic

✓ The constraint correctly ensures all points on the small sphere satisfy $x^2 + y^2 + z^2 \leq 200^2$

✓ Squaring the inequality is valid (both sides non-negative)

✓ Arithmetic checks:
- $158^2 - 1764 = 24,964 - 1,764 = 23,200$ ✓
- $\frac{29}{50} \approx 0.58$ (reasonable probability) ✓

✓ Fraction is in lowest terms with $\gcd(29, 50) = 1$ ✓

---

## 4. Substitution Check

If $P_x = P_y = 0$:
- Distance from origin: $\sqrt{0 + 0 + 1,764} = 42$
- Farthest point: $42 + 42 = 84 < 200$ ✓ (satisfies constraint)

If $P_x^2 + P_y^2 = 23,200$:
- $\sqrt{23,200 + 1,764} = \sqrt{24,964} = 158$
- Farthest point: $158 + 42 = 200$ ✓ (boundary case)

---

## 5. Final Answer

$$p + q = 29 + 50 = 79$$

**FINAL ANSWER: 79**
