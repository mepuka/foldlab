# Detailed Solution with Verification

## Step 1: Coordinate System Setup
Setting up a coordinate system with square ABCD:
- $A = (0, 0)$
- $B = (12, 0)$
- $C = (12, 12)$
- $D = (0, 12)$

✓ This creates a 12×12 square.

## Step 2: Locate Vertices W and X

From the given information:
- $W$ is on $\overline{AD}$ with $AW = 4$: **$W = (0, 4)$** ✓
- $X$ is on $\overline{AB}$ with $AX = 5$: **$X = (5, 0)$** ✓

## Step 3: Verify Side Length of Square WXYZ

$$|WX| = \sqrt{(5-0)^2 + (0-4)^2} = \sqrt{25 + 16} = \sqrt{41}$$

✓ Confirmed: The side length is $\sqrt{41}$ (not 3, as noted).

## Step 4: Find Y and Z Coordinates

The vector from $W$ to $X$:
$$\vec{WX} = (5, -4)$$

For a square, rotate this vector 90° counterclockwise using $(a, b) \to (-b, a)$:
$$\vec{WX}_{\perp} = (4, 5)$$

Calculate the remaining vertices:
- $Z = W + (4, 5) = (0, 4) + (4, 5) = (4, 9)$ ✓
- $Y = X + (4, 5) = (5, 0) + (4, 5) = (9, 5)$ ✓

**Verification that WXYZ is a square:**
- $|WX| = \sqrt{5^2 + (-4)^2} = \sqrt{41}$ ✓
- $|XY| = \sqrt{(9-5)^2 + (5-0)^2} = \sqrt{16 + 25} = \sqrt{41}$ ✓
- $|YZ| = \sqrt{(4-9)^2 + (9-5)^2} = \sqrt{25 + 16} = \sqrt{41}$ ✓
- $|ZW| = \sqrt{(0-4)^2 + (4-9)^2} = \sqrt{16 + 25} = \sqrt{41}$ ✓

All sides equal; consecutive sides perpendicular. ✓

## Step 5: Calculate Area of △BCY

**Vertices:** $B = (12, 0)$, $C = (12, 12)$, $Y = (9, 5)$

Using the coordinate formula:
$$\text{Area} = \frac{1}{2}|x_B(y_C - y_Y) + x_C(y_Y - y_B) + x_Y(y_B - y_C)|$$

Calculate each term:
- $x_B(y_C - y_Y) = 12(12 - 5) = 12(7) = 84$
- $x_C(y_Y - y_B) = 12(5 - 0) = 12(5) = 60$
- $x_Y(y_B - y_C) = 9(0 - 12) = -108$

Sum: $84 + 60 - 108 = 36$

$$\text{Area} = \frac{1}{2}|36| = 18$$

**Verification by alternative method:**
- Points $B = (12, 0)$ and $C = (12, 12)$ lie on the vertical line $x = 12$
- Base: $|BC| = 12$
- Height (perpendicular distance from $Y$ to line $x = 12$): $|12 - 9| = 3$
- Area: $\frac{1}{2} \times 12 \times 3 = 18$ ✓

FINAL ANSWER: **18**
