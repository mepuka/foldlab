## Step 5: Calculate Area of △BCY
**What I'm calculating:** Area using the standard determinant formula.

**Calculation:**
$$\text{Area} = \frac{1}{2}|x_B(y_C - y_Y) + x_C(y_Y - y_B) + x_Y(y_B - y_C)|$$

With $B = (12, 0)$, $C = (12, 12)$, $Y = (9, 5)$:

$$\text{Area} = \frac{1}{2}|12(12-5) + 12(5-0) + 9(0-12)|$$
$$= \frac{1}{2}|12(7) + 12(5) + 9(-12)|$$
$$= \frac{1}{2}|84 + 60 - 108|$$
$$= \frac{1}{2}|36| = 18$$

**Verification using base-height method:**
- Points $B = (12, 0)$ and $C = (12, 12)$ both lie on the vertical line $x = 12$
- Base $|BC| = 12$
- Perpendicular distance from $Y = (9, 5)$ to line $x = 12$ is $|12 - 9| = 3$
- Area $= \frac{1}{2} \times 12 \times 3 = 18$ ✓

Both methods agree! ✓
