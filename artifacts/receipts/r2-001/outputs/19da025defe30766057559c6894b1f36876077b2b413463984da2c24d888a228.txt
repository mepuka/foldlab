# Solution: Finding M

## Step 1: Factor the Constraint Equation

**What I'm calculating:** Rewriting the constraint in factored form

**Complete Calculation:**
Starting with: $\alpha\beta + \alpha + \beta + 100 = 0$

Rearrange: $\alpha\beta + \alpha + \beta + 1 = -99$

Factor by grouping:
$$\alpha(1 + \beta) + 1(1 + \beta) = -99$$
$$(1 + \alpha)(1 + \beta) = -99$$

**Verification:** Expanding $(1 + \alpha)(1 + \beta) = 1 + \alpha + \beta + \alpha\beta = -99$ ✓

---

## Step 2: Apply the Modulus Constraint

**What I'm calculating:** Taking absolute values to use the given constraint $|\alpha| = |\beta| = M$

**Complete Calculation:**
From $(1 + \alpha)(1 + \beta) = -99$, take absolute values of both sides:
$$|(1 + \alpha)(1 + \beta)| = |-99|$$
$$|1 + \alpha| \cdot |1 + \beta| = 99$$

**Verification:** The product of moduli equals the modulus of the product. $|-99| = 99$ ✓

---

## Step 3: Test the Symmetric Case $\alpha = \beta$

**What I'm calculating:** Substituting $\alpha = \beta$ into the factored constraint

**Complete Calculation:**
If $\alpha = \beta$:
$$(1 + \alpha)(1 + \alpha) = -99$$
$$(1 + \alpha)^2 = -99$$

**Verification:** This makes sense because $\alpha = \beta$ satisfies $|\alpha| = |\beta|$ and provides a natural symmetric case to investigate.

---

## Step 4: Solve for $\alpha$ 

**What I'm calculating:** Finding the value of $\alpha$ from $(1 + \alpha)^2 = -99$

**Complete Calculation:**
$$1 + \alpha = \pm\sqrt{-99}$$
$$1 + \alpha = \pm i\sqrt{99}$$
$$1 + \alpha = \pm i\sqrt{9 \cdot 11}$$
$$1 + \alpha = \pm 3i\sqrt{11}$$

Therefore:
$$\alpha = -1 \pm 3i\sqrt{11}$$

**Verification:** $(\pm 3i\sqrt{11})^2 = 9i^2 \cdot 11 = -99$ ✓

---

## Step 5: Calculate the Modulus M

**What I'm calculating:** The modulus of $\alpha = -1 \pm 3i\sqrt{11}$

**Complete Calculation:**
For $\alpha = -1 + 3i\sqrt{11}$ (the other solution gives the same modulus):

$$M = |\alpha| = \sqrt{\text{Re}(\alpha)^2 + \text{Im}(\alpha)^2}$$
$$M = \sqrt{(-1)^2 + (3\sqrt{11})^2}$$
$$M = \sqrt{1 + 9 \cdot 11}$$
$$M = \sqrt{1 + 99}$$
$$M = \sqrt{100}$$
$$M = 10$$

**Verification:** $1 + 99 = 100$ and $\sqrt{100} = 10$ ✓

---

## Step 6: Verify Uniqueness

**What I'm calculating:** Confirming this is the only solution

**Complete Calculation:**
The constraint $(1 + \alpha)(1 + \beta) = -99$ is a **negative real number**. 

If $\alpha = \beta = -1 + 3i\sqrt{11}$:
- Check constraint: $(3i\sqrt{11})^2 = 9i^2(11) = -99$ ✓
- Check modulus: $|{-1 + 3i\sqrt{11}}| = 10$ ✓
- Check equality: $|\alpha| = |\beta| = 10$ ✓

If we try complex conjugates $\alpha = -1 + 3i\sqrt{11}$, $\beta = -1 - 3i\sqrt{11}$:
$(3i\sqrt{11})(-3i\sqrt{11}) = -9i^2(11) = 99 \neq -99$ ✗

The negative real result uniquely forces the symmetric case.

**Verification:** The symmetric solution satisfies all constraints. ✓

---

## Final Answer Verification

Substituting back: If $\alpha = \beta = -1 + 3i\sqrt{11}$:
- Constraint: $(1 + \alpha)^2 = (3i\sqrt{11})^2 = -99$ ✓
- Modulus: $M = 10$ is a positive integer ✓
- Reasonableness: Since $(1+\alpha)^2 = -99$, we expect $M > 1$. Having $M = 10$ with $|1+\alpha| = 3\sqrt{11} \approx 9.95$ is consistent. ✓

**FINAL ANSWER: 10**
