# Solution: Maximum Reachable States for Jacob and Bojac

## 1. Problem Statement

We need to find the maximum number of distinct (Jacob position, Bojac position) pairs that can be achieved on an 8×8 chessboard, where:
- Direction D is called
- Jacob moves in direction D
- Bojac moves 90° counterclockwise from D
- Each player is blocked independently by board boundaries
- We can choose an optimal starting configuration

## 2. Movement Analysis

**Direction Mapping** (using coordinate system where right is +x, up is +y):
- Right (R): Jacob moves (1,0), Bojac moves (0,-1)
- Down (D): Jacob moves (0,-1), Bojac moves (-1,0)  
- Left (L): Jacob moves (-1,0), Bojac moves (0,1)
- Up (U): Jacob moves (0,1), Bojac moves (1,0)

**Displacement Tracking**

After applying R, D, L, U with frequencies r, d, l, u respectively:
- Jacob's displacement: (jx, jy) = (r - l, u - d)
- Bojac's displacement: (bx, by) = (u - l, r - d)

**Key Constraint**: From the displacement equations above:
$$bx + by = (u - l) + (r - d) = r + u - l - d$$
$$jx + jy = (r - l) + (u - d) = r + u - l - d$$

Therefore: **bx + by = jx + jy** (the sum constraint)

This fundamental constraint means not all position pairs are independently reachable.

## 3. Optimal Starting Position

To maximize reachability, we should start at a central position on the 8×8 board where both players have maximum room to move in all directions.

**Optimal choice**: Jacob starts at (3,3), Bojac starts at (3,3)

This gives both players access to displacements:
- jx, bx ∈ {-3, -2, -1, 0, 1, 2, 3, 4}
- jy, by ∈ {-3, -2, -1, 0, 1, 2, 3, 4}

## 4. Counting Reachable States

For each reachable pair (jx, jy) where -3 ≤ jx ≤ 4 and -3 ≤ jy ≤ 4, we need to count valid (bx, by) pairs satisfying:
- bx + by = s, where s = jx + jy
- -3 ≤ bx ≤ 4 and -3 ≤ by ≤ 4

For a given sum s = jx + jy, the number of valid (bx, by) pairs:
- Constraints: max(-3, s-4) ≤ bx ≤ min(4, s+3)

For each value of s from -6 to 8, counting valid bx values (which determines by = s - bx):

| s | Valid bx range | Count |
|---|---|---|
| -6 | [-3, -3] | 1 |
| -5 | [-3, -2] | 2 |
| -4 | [-3, -1] | 3 |
| -3 | [-3, 0] | 4 |
| -2 | [-3, 1] | 5 |
| -1 | [-3, 2] | 6 |
| 0 | [-3, 3] | 7 |
| 1 | [-3, 4] | 8 |
| 2 | [-2, 4] | 7 |
| 3 | [-1, 4] | 6 |
| 4 | [0, 4] | 5 |
| 5 | [1, 4] | 4 |
| 6 | [2, 4] | 3 |
| 7 | [3, 4] | 2 |
| 8 | [4, 4] | 1 |

The number of (jx, jy) pairs with sum s is identical to the number of (bx, by) pairs with the same sum.

**Total reachable states**:
$$\sum_{s=-6}^{8} [\text{count}(s)]^2 = 1^2 + 2^2 + 3^2 + 4^2 + 5^2 + 6^2 + 7^2 + 8^2 + 7^2 + 6^2 + 5^2 + 4^2 + 3^2 + 2^2 + 1^2$$

$$= 2(1 + 4 + 9 + 16 + 25 + 36 + 49) + 64 = 2(140) + 64 = 344$$

## 5. Verification

The constraint bx + by = jx + jy significantly restricts the state space. Each (jx, jy) pair uniquely determines a 1-dimensional solution set for (bx, by) values, and only certain portions fall within board bounds. The symmetric distribution around s=1 and the quadratic counting confirm our analysis.

**FINAL ANSWER: 344**
