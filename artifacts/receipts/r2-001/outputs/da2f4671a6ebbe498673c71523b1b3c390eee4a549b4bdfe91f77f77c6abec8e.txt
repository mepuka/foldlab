# Solution: Finding M Step by Step

## Step 1: Factor the Constraint Equation

Starting with: $\alpha\beta + \alpha + \beta + 100 = 0$

Add and subtract 1:
$$\alpha\beta + \alpha + \beta + 1 = -99$$

Factor the left side:
$$\alpha(1 + \beta) + (1 + \beta) = -99$$
$$(1 + \alpha)(1 + \beta) = -99$$

**Key result:** The factored constraint is $(1 + \alpha)(1 + \beta) = -99$

## Step 2: Apply the Modulus Constraint

Given: $|\alpha| = |\beta| = M$

Take absolute values of both sides of the factored equation:
$$|(1 + \alpha)(1 + \beta)| = |-99|$$
$$|1 + \alpha| \cdot |1 + \beta| = 99$$

**Key result:** $|1 + \alpha| \cdot |1 + \beta| = 99$

## Step 3: Test the Symmetric Case $\alpha = \beta$

By symmetry of the original constraints, assume $\alpha = \beta$.

Substitute into $(1 + \alpha)(1 + \beta) = -99$:
$$(1 + \alpha)^2 = -99$$

## Step 4: Solve for $\alpha$ When $\alpha = \beta$

Taking square roots:
$$1 + \alpha = \pm\sqrt{-99} = \pm i\sqrt{99} = \pm i \cdot 3\sqrt{11}$$

Therefore:
$$\alpha = -1 \pm 3i\sqrt{11}$$

Both solutions have the same modulus, so we can use either one.

## Step 5: Calculate the Modulus M

Using $\alpha = -1 + 3i\sqrt{11}$:

$$M = |\alpha| = \sqrt{(-1)^2 + (3\sqrt{11})^2}$$

$$M = \sqrt{1 + 9 \cdot 11}$$

$$M = \sqrt{1 + 99}$$

$$M = \sqrt{100}$$

$$M = 10$$

## Step 6: Verify Uniqueness

The constraint $(1 + \alpha)(1 + \beta) = -99$ is a **negative real number**.

For complex numbers with $|\alpha| = |\beta| = M$, if they have different arguments, their product $(1+\alpha)(1+\beta)$ would generally have a non-zero imaginary part. For the product to be purely real and negative, the symmetric case $\alpha = \beta$ is forced by the geometry of the constraint.

Verification with $\alpha = \beta = -1 + 3i\sqrt{11}$:
- $|\alpha| = 10$ ✓
- $(1 + \alpha)^2 = (3i\sqrt{11})^2 = -99$ ✓
- $\alpha\beta + \alpha + \beta + 100 = 100 - 2 - 100 + 100 = 0$ ✓

## Final Answer

$$\boxed{M = 10}$$
