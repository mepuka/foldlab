# Solution: Finding M

## Step 1: Factor the constraint equation

Starting with:
$$\alpha\beta + \alpha + \beta + 100 = 0$$

Factor by grouping:
$$\alpha\beta + \alpha + \beta + 1 + 99 = 0$$
$$\alpha(1 + \beta) + (1 + \beta) + 99 = 0$$
$$(1 + \alpha)(1 + \beta) = -99$$

✓ **Factored form established**

## Step 2: Apply the modulus constraint

Given: $|\alpha| = |\beta| = M$

Taking absolute values of both sides:
$$|1 + \alpha||1 + \beta| = |-99| = 99$$

✓ **Modulus equation: $|1 + \alpha||1 + \beta| = 99$**

## Step 3: Test the symmetric case $\alpha = \beta$

By symmetry of the constraint, assume $\alpha = \beta$.

Substituting into $(1 + \alpha)(1 + \beta) = -99$:
$$(1 + \alpha)^2 = -99$$

## Step 4: Solve for $\alpha$ in the symmetric case

Taking square roots:
$$1 + \alpha = \pm\sqrt{-99} = \pm i\sqrt{99}$$

Simplifying $\sqrt{99}$:
$$\sqrt{99} = \sqrt{9 \cdot 11} = 3\sqrt{11}$$

Therefore:
$$1 + \alpha = \pm 3i\sqrt{11}$$

$$\alpha = -1 \pm 3i\sqrt{11}$$

✓ **Symmetric solution found**

## Step 5: Calculate the modulus M

For $\alpha = -1 + 3i\sqrt{11}$ (or $-1 - 3i\sqrt{11}$, which gives the same modulus):

$$M = |\alpha| = \sqrt{(-1)^2 + (3\sqrt{11})^2}$$

$$M = \sqrt{1 + 9 \cdot 11}$$

$$M = \sqrt{1 + 99}$$

$$M = \sqrt{100}$$

$$M = 10$$

## Step 6: Verify uniqueness

For the constraint $(1 + \alpha)(1 + \beta) = -99$ (a **negative real number**):
- If we write $1 + \alpha = re^{i\theta}$ and $1 + \beta = se^{i\phi}$ where $rs = 99$
- For the product to equal $-99$ (argument $\pi$), we need: $\theta + \phi = \pi + 2\pi k$

Combined with $|\alpha| = |\beta| = M$, the geometry of the complex plane forces the symmetric solution where both $\alpha$ and $\beta$ are equidistant from $-1$ on a circle of radius $M$ centered at the origin.

The symmetric case $\alpha = \beta$ satisfies all constraints simultaneously and uniquely determines $M = 10$.

## Final Answer

$$\boxed{M = 10}$$
