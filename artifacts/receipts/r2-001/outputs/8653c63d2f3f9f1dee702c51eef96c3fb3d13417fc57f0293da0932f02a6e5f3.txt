# Solution: Expected Number of Cells Visited on a Random Path

## Step 1: Establish the Baseline
Total paths from $(0,0)$ to $(5,5)$ with no obstacles:
- Required: 5 moves right (R) and 5 moves up (U)
- Total arrangements: $\binom{10}{5} = 252$ paths

## Step 2: Coordinate System
- $(0,0)$ = bottom-left
- $(5,5)$ = top-right
- Grid cells: $0 \leq x, y \leq 5$

## Step 3: Calculate Paths Through Each Cell

For cell $(x,y)$:
$$P(x,y) = \binom{x+y}{x} \times \binom{10-x-y}{5-x}$$

## Step 4: Sum All Products

$$\sum_{x=0}^{5}\sum_{y=0}^{5} P(x,y) = 252 + 126 + 56 + 20 + 5 + 1 + 126 + 252 + 168 + 80 + 25 + 6$$
$$+ 56 + 378 + 336 + 200 + 75 + 21 + 20 + 504 + 560 + 400 + 175 + 56$$
$$+ 5 + 630 + 840 + 700 + 350 + 126 + 1 + 756 + 1176 + 1120 + 630 + 252$$

$$= 9072$$

## Step 5: Calculate Expected Value

$$E = \frac{1}{36} \times 9072 = 252$$

## Step 6: Alternative Interpretation

If the question asks for expected *unique* cells visited:
$$E = 252 - \frac{1}{36}(9072 - 252 \times 36) = 252 - \frac{1}{36}(0) = 252$$

Actually, using the correct formula:
$$E = \frac{1}{252}\sum_{i=1}^{36} (\text{paths through cell } i)$$

This gives us: $E = \frac{9072}{252} = 36$ cells on average.

# **Final Answer: 36**

Every random path visits exactly **36 cells** (one complete path through the grid), so the expected number of cells visited is **36**.
