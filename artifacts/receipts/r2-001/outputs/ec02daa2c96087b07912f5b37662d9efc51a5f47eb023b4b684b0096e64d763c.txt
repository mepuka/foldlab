# Problem Analysis

## Given Quantities and Conditions

1. **Mark writes squares of several distinct positive integers** in base 10
2. **The integers whose squares are written are distinct** (different integers)
3. **Each nonzero digit (1, 2, 3, 4, 5, 6, 7, 8, 9) appears exactly once** across all the written squares combined
4. **The digit 0 may appear any number of times** (or not at all) since only nonzero digits have the constraint
5. **We're working in base 10**

## What Is Being Asked

Find the **smallest possible sum** of all the perfect squares written on the blackboard, subject to the constraint that the nine nonzero digits collectively appear exactly once across all these squares.

In other words: Select distinct positive integers whose perfect squares, when all their digits are combined, contain each digit from {1, 2, 3, 4, 5, 6, 7, 8, 9} exactly once (and any number of zeros), such that the sum of these perfect squares is minimized.
