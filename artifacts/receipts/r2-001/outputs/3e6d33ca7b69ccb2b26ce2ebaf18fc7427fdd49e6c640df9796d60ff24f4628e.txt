# Solution: Step-by-Step Calculation

## Step 1-4: Setup (Already Defined in Plan)
We have:
- State space: $(a, b, 0)$ where $a, b$ are coins received by Alice and Bob
- Goal: Reach state where $a \geq 2$ and $b \geq 2$ before Carol receives any coin
- Recurrence: $P(a,b) = \frac{1}{3}[P(a+1,b) + P(a,b+1)]$ for $a < 2$ or $b < 2$

## Step 5: Boundary Conditions

$$P(a, b) = \begin{cases} 1 & \text{if } a \geq 2 \text{ and } b \geq 2 \\ 0 & \text{if } a \to \infty \text{ or } b \to \infty \text{ (without meeting goal)} \end{cases}$$

For states where $a \geq 2$ and $b \geq 2$: $P(a,b) = 1$

For states where $a \geq 2, b = 1$: We need $P(a, 1)$
$$P(a, 1) = \frac{1}{3}[P(a+1, 1) + P(a, 2)]$$

Since $P(a,2) = 1$ for $a \geq 2$:
$$P(a, 1) = \frac{1}{3}[P(a+1, 1) + 1]$$

This gives: $3P(a,1) = P(a+1, 1) + 1$, so $P(a+1,1) = 3P(a,1) - 1$

Let $P(a,1) = c$ (constant). Then $c = 3c - 1$, so $c = \frac{1}{2}$.

Therefore: **$P(a, 1) = \frac{1}{2}$ for all $a \geq 2$**

By symmetry: **$P(1, b) = \frac{1}{2}$ for all $b \geq 2$**

## Step 6: Calculate Key Values

**For $P(2,2)$:** $P(2,2) = 1$ ✓

**For $P(1,2)$:**
$$P(1,2) = \frac{1}{3}[P(2,2) + P(1,3)] = \frac{1}{3}\left[1 + \frac{1}{2}\right] = \frac{1}{3} \cdot \frac{3}{2} = \frac{1}{2}$$ ✓

**For $P(2,1)$:** By symmetry, $P(2,1) = \frac{1}{2}$ ✓

**For $P(1,1)$:**
$$P(1,1) = \frac{1}{3}[P(2,1) + P(1,2)] = \frac{1}{3}\left[\frac{1}{2} + \frac{1}{2}\right] = \frac{1}{3}$$

**For $P(0,2)$:**
$$P(0,2) = \frac{1}{3}[P(1,2) + P(0,3)] = \frac{1}{3}\left[\frac{1}{2} + \frac{1}{2}\right] = \frac{1}{3}$$

**For $P(2,0)$:** By symmetry, $P(2,0) = \frac{1}{3}$ ✓

**For $P(0,1)$:**
$$P(0,1) = \frac{1}{3}[P(1,1) + P(0,2)] = \frac{1}{3}\left[\frac{1}{3} + \frac{1}{3}\right] = \frac{2}{9}$$

**For $P(1,0)$:** By symmetry, $P(1,0) = \frac{2}{9}$ ✓

**For $P(0,0)$:**
$$P(0,0) = \frac{1}{3}[P(1,0) + P(0,1)] = \frac{1}{3}\left[\frac{2}{9} + \frac{2}{9}\right] = \frac{1}{3} \cdot \frac{4}{9} = \frac{4}{27}$$

## Step 7: Express as Fraction

$$P(0,0) = \frac{4}{27}$$

Check: $\gcd(4, 27) = 1$ ✓

So $m = 4$ and $n = 27$.

## Step 8: Final Answer

$$100m + n = 100(4) + 27 = 400 + 27 = \boxed{427}$$
