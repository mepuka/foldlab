# Solution Plan

## 1. **Define the State Space**
   - Represent states as $(a, b, c)$ where:
     - $a$ = number of coins Alice has received
     - $b$ = number of coins Bob has received
     - $c$ = number of coins Carol has received
   - Start at state $(0, 0, 0)$
   - Process stops when $c \geq 1$ (Carol gets a coin)

## 2. **Identify Target and Terminal States**
   - **Target state(s)**: Any state $(a, b, c)$ where $a \geq 2$, $b \geq 2$, and $c = 0$
   - **Terminal states** (process ends):
     - Any state with $c = 1$ (Carol received a coin)
     - We want probability of reaching a target state before any terminal state

## 3. **Set Up Transition Probabilities**
   - From state $(a, b, 0)$ where we haven't reached the goal yet:
     - Transition to $(a+1, b, 0)$ with probability $1/3$ (Alice gets coin)
     - Transition to $(a, b+1, 0)$ with probability $1/3$ (Bob gets coin)
     - Transition to $(a, b, 1)$ with probability $1/3$ (Carol gets coin—**stop**)

## 4. **Define Probability Function**
   - Let $P(a, b)$ = probability of reaching the goal $(a \geq 2, b \geq 2)$ starting from state $(a, b, 0)$
   - Boundary conditions:
     - $P(a, b) = 1$ if $a \geq 2$ and $b \geq 2$
     - $P(a, b) = 0$ if any path continues indefinitely without meeting the goal before Carol gets a coin

## 5. **Write Recurrence Relations**
   For $a < 2$ or $b < 2$:
   $$P(a, b) = \frac{1}{3}P(a+1, b) + \frac{1}{3}P(a, b+1) + \frac{1}{3} \cdot 0$$
   
   Simplify:
   $$P(a, b) = \frac{1}{3}[P(a+1, b) + P(a, b+1)]$$

## 6. **Solve Systematically**
   - Calculate $P(a, b)$ for small values starting from boundary conditions
   - Work backwards from the goal state $(2, 2)$ to the initial state $(0, 0)$
   - Required values: $P(0,0)$, $P(0,1)$, $P(1,0)$, $P(1,1)$, etc.

## 7. **Express as a Fraction**
   - Reduce $P(0, 0)$ to lowest terms $\frac{m}{n}$ with $\gcd(m, n) = 1$

## 8. **Compute Final Answer**
   - Calculate $100m + n$
