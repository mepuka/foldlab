# Solution Step-by-Step

## Step 1: Set up coordinate system ✓
- $A = (0, 0, 0)$
- $B = (6, 0, 0)$
- $C = (0, 4, 0)$
- Plane $\mathcal{P}$ is the $xy$-plane (where $z = 0$)

## Step 2: Find the centroid and point $D$

**Centroid:**
$$G = \frac{A + B + C}{3} = \frac{(0,0,0) + (6,0,0) + (0,4,0)}{3} = \left(2, \frac{4}{3}, 0\right)$$ ✓

**Reflect $G$ across line $BC$:**

Line $BC$ has direction vector $\vec{BC} = (-6, 4, 0)$ and passes through $B = (6, 0, 0)$.

Parametric form: $\ell(t) = (6-6t, 4t, 0)$

To find the foot of perpendicular from $G$ to $BC$:
$$\frac{d}{dt}\left[(-4+6t)^2 + \left(\frac{4}{3}-4t\right)^2\right] = 0$$

$$12(-4+6t) - 8\left(\frac{4}{3}-4t\right) = 0$$

$$-48 + 72t - \frac{32}{3} + 32t = 0$$

$$104t = 48 + \frac{32}{3} = \frac{176}{3}$$

$$t = \frac{22}{39}$$

Foot of perpendicular: 
$$\ell\left(\frac{22}{39}\right) = \left(6-\frac{132}{39}, \frac{88}{39}, 0\right) = \left(\frac{102}{39}, \frac{88}{39}, 0\right) = \left(\frac{34}{13}, \frac{88}{39}, 0\right)$$

Reflection point $D$:
$$D = 2 \cdot \left(\frac{34}{13}, \frac{88}{39}, 0\right) - \left(2, \frac{4}{3}, 0\right) = \left(\frac{68}{13} - 2, \frac{176}{39} - \frac{52}{39}, 0\right) = \left(\frac{42}{13}, \frac{124}{39}, 0\right)$$

## Step 3: Identify sphere centers ✓

- Sphere 1: $O_1 = (0, 0, 1)$, $r_1 = 1$ (tangent to $\mathcal{P}$ at $A$)
- Sphere 2: $O_2 = (6, 0, 2)$, $r_2 = 2$ (tangent to $\mathcal{P}$ at $B$)
- Sphere 3: $O_3 = (0, 4, 3)$, $r_3 = 3$ (tangent to $\mathcal{P}$ at $C$)
- Sphere 4: $O_4 = \left(\frac{42}{13}, \frac{124}{39}, r\right)$, $r_4 = r$ (tangent to $\mathcal{P}$ at $D$)

## Step 4: Apply mutual tangency condition

For sphere 1 and sphere 4 externally tangent:
$$|O_1 - O_4| = r_1 + r_4$$

$$\sqrt{\left(\frac{42}{13}\right)^2 + \left(\frac{124}{39}\right)^2 + (1-r)^2} = 1 + r$$

Squaring both sides:
$$\left(\frac{42}{13}\right)^2 + \left(\frac{124}{39}\right)^2 + (1-r)^2 = (1+r)^2$$

**Calculate the first two terms:**
$$\left(\frac{42}{13}\right)^2 = \frac{1764}{169}$$

$$\left(\frac{124}{39}\right)^2 = \frac{15376}{1521}$$

Converting to common denominator (1521 = 169 × 9):
$$\frac{1764}{169} = \frac{15876}{1521}$$

$$\frac{1764}{169} + \frac{15376}{1521} = \frac{15876 + 15376}{1521} = \frac{31252}{1521}$$

**Expand both sides:**
$$(1-r)^2 = 1 - 2r + r^2$$
$$(1+r)^2 = 1 + 2r + r^2$$

$$\frac{31252}{1521} + 1 - 2r + r^2 = 1 + 2r + r^2$$

$$\frac{31252}{1521} - 2r = 2r$$

$$\frac{31252}{1521} = 4r$$

$$r = \frac{31252}{6084}$$

## Step 5: Simplify to lowest terms

$$\frac{31252}{6084} = \frac{7813}{1521}$$

Check GCD(7813, 1521) using Euclidean algorithm:
- $7813 = 1521 \times 5 + 308$
- $1521 = 308 \times 4 + 289$
- $308 = 289 \times 1 + 19$
- $289 = 19 \times 15 + 4$
- $19 = 4 \times 4 + 3$
- $4 = 3 \times 1 + 1$
- $3 = 1 \times 3 + 0$

GCD = 1 ✓

Therefore: $m = 7813$, $n = 1521$

$$m + n = 7813 + 1521 = 9334$$

FINAL ANSWER: **9334**
