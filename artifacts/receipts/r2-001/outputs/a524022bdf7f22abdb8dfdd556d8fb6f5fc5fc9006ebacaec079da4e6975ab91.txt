# Step-by-Step Solution

## Step 1: Understand the Constraint
We need numbers $n < 1000$ where $s_2(n) = \sqrt{s_4(n)}$.

Let $a = s_2(n)$ (sum of binary digits).  
Then we need: $s_4(n) = a^2$

## Step 2: Determine Range of $a$

For $n < 1000$:
- $999 = 1111100111_2$ has exactly 8 ones
- Therefore: $s_2(n) \leq 8$, so $a \in \{1, 2, 3, 4, 5, 6, 7, 8\}$

## Step 3: Constraint from Base-4

For $n < 1000$:
- $999 = 33213_4$
- $s_4(999) = 3 + 3 + 2 + 1 + 3 = 12$
- We need $s_4(n) = a^2 \leq 12$

**Finding valid values:**
- $a=1$: $a^2 = 1 \leq 12$ ✓
- $a=2$: $a^2 = 4 \leq 12$ ✓
- $a=3$: $a^2 = 9 \leq 12$ ✓
- $a=4$: $a^2 = 16 > 12$ ✗

Therefore: **$a \in \{1, 2, 3\}$**
