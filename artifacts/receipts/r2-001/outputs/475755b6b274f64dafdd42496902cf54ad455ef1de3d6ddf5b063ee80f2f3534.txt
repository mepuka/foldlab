# Solution Plan

1. **Recognize the algebraic form**
   - Rewrite $a + b + ab$ as $(a+1)(b+1) - 1$ by factoring
   - This transforms the problem into finding values of $(a+1)(b+1) - 1 \leq 100$
   - Equivalently: find $(a+1)(b+1) \leq 101$

2. **Determine the range for products**
   - Let $m = a+1$ and $n = b+1$ where $m, n \geq 2$ (since $a, b \geq 1$)
   - Since $a \neq b$, we need $m \neq n$
   - Find all products $m \cdot n \leq 101$ where $m, n \geq 2$ and $m \neq n$

3. **Enumerate all valid products**
   - Systematically list pairs $(m, n)$ with $m < n$ such that $m \cdot n \leq 101$
   - For each valid pair, record the product value $m \cdot n$
   - Avoid counting the same product twice (use unordered pairs or ensure $m < n$)

4. **Convert products back to target integers**
   - For each distinct product $m \cdot n$, calculate $(m \cdot n) - 1$
   - These give the integers expressible in the form $a + b + ab$

5. **Count distinct values**
   - Collect all distinct results from step 4
   - Ensure all values are in the range $[1, 100]$
   - Count the total number of distinct integers
