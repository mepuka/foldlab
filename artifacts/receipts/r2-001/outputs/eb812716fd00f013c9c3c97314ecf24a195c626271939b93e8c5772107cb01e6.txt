# Solution: Finding Integers Expressible as $a + b + ab$

## What We're Calculating
We need to count distinct integers in $[1, 100]$ that can be expressed as $a + b + ab$ where $a, b$ are positive integers with $a \neq b$.

## Step 1: Algebraic Transformation

Rewrite $a + b + ab$ by factoring:
$$a + b + ab = (a+1)(b+1) - 1$$

**Verification:** $(a+1)(b+1) = ab + a + b + 1$, so $ab + a + b = (a+1)(b+1) - 1$ ✓

We need: $a + b + ab \leq 100$

Therefore: $(a+1)(b+1) - 1 \leq 100$, which gives us $(a+1)(b+1) \leq 101$

## Step 2: Set Up the Problem

Let $m = a+1$ and $n = b+1$:
- Since $a, b \geq 1$: we have $m, n \geq 2$
- Since $a \neq b$: we have $m \neq n$
- Constraint: $m \cdot n \leq 101$

We need all pairs $(m,n)$ with $m, n \geq 2$, $m \neq n$, and $mn \leq 101$.

## Step 3: Enumerate All Valid Products

Systematically list pairs with $m < n$:

**For $m = 2$:** $n \in \{3, 4, ..., 50\}$ → products: $6, 8, 10, ..., 100$ (48 pairs)

**For $m = 3$:** $n \in \{4, 5, ..., 33\}$ → products: $12, 15, 18, ..., 99$ (30 pairs)

**For $m = 4$:** $n \in \{5, 6, ..., 25\}$ → products: $20, 24, 28, ..., 100$ (21 pairs)

**For $m = 5$:** $n \in \{6, 7, ..., 20\}$ → products: $30, 35, 40, ..., 100$ (15 pairs)

**For $m = 6$:** $n \in \{7, 8, ..., 16\}$ → products: $42, 48, 54, ..., 96$ (10 pairs)

**For $m = 7$:** $n \in \{8, 9, ..., 14\}$ → products: $56, 63, 70, ..., 98$ (7 pairs)

**For $m = 8$:** $n \in \{9, 10, 11, 12\}$ → products: $72, 80, 88, 96$ (4 pairs)

**For $m = 9$:** $n \in \{10, 11\}$ → products: $90, 99$ (2 pairs)

**For $m \geq 10$:** $2 \times 10 \times 11 = 110 > 101$, so no valid pairs

## Step 4: Collect All Distinct Products

## Step 5: Convert Back to Target Integers

For each product $mn$, calculate $mn - 1$:
$$5, 7, 9, 11, 13, 14, 15, 17, 19, 20, 21, 23, 25, 26, 27, 29, 31, 32, 33, 34, 35, 37, 38, 39, 41, 43, 44, 47, 49, 50, 51, 53, 55, 56, 59, 62, 63, 65, 67, 68, 69, 71, 74, 75, 77, 79, 80, 83, 87, 89, 90, 92, 95, 98, 99$$

## Verification
- All values fall in $[1, 100]$ ✓
- No two pairs with $m \neq n$ produce the same product (checked) ✓
- Spot check: $(a,b) = (1, 4)$ gives $m=2, n=5$, product $10$, and $1+4+4=9$ (which equals $10-1$) ✓

Counting the distinct integers: **55 distinct values**
