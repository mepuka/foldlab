# Solution: Finding M

## 1. State What I'm Calculating

I need to find the value of M such that complex numbers α and β satisfy:
- $\alpha\beta + \alpha + \beta + 100 = 0$
- $|\alpha| = |\beta| = M$

## 2. Complete Calculation with Intermediate Steps

**Step 1: Factor the constraint equation**

Starting with: $\alpha\beta + \alpha + \beta + 100 = 0$

Add and subtract 1:
$$\alpha\beta + \alpha + \beta + 1 = -99$$

Factor the left side:
$$(1 + \alpha)(1 + \beta) = -99$$

**Step 2: Apply the modulus constraint**

Taking absolute values of both sides:
$$|(1 + \alpha)(1 + \beta)| = |-99| = 99$$
$$|1 + \alpha||1 + \beta| = 99$$

**Step 3: Test the symmetric case**

Assume $\alpha = \beta$ (motivated by the symmetric constraint and modulus conditions).

Substituting into $(1 + \alpha)(1 + \beta) = -99$:
$$(1 + \alpha)^2 = -99$$

Taking the square root:
$$1 + \alpha = \pm\sqrt{-99} = \pm i\sqrt{99} = \pm 3i\sqrt{11}$$

**Step 4: Solve for α**

$$\alpha = -1 \pm 3i\sqrt{11}$$

**Step 5: Calculate the modulus M**

For $\alpha = -1 + 3i\sqrt{11}$:

$$M = |\alpha| = \sqrt{(-1)^2 + (3\sqrt{11})^2}$$
$$M = \sqrt{1 + 9(11)}$$
$$M = \sqrt{1 + 99}$$
$$M = \sqrt{100}$$
$$M = 10$$

## 3. Verify Results Make Logical Sense

- The real part is $-1$ and imaginary part is $3\sqrt{11} \approx 9.95$
- These values combine to give $\sqrt{1 + 99} = 10$, which is a clean integer ✓
- The factorization created a product of $-99$, which is achievable when squared ✓

## 4. Check by Substituting Back

Using $\alpha = \beta = -1 + 3i\sqrt{11}$:

$$\alpha\beta = (-1 + 3i\sqrt{11})^2 = 1 - 6i\sqrt{11} + 9i^2(11)$$
$$= 1 - 6i\sqrt{11} - 99 = -98 - 6i\sqrt{11}$$

$$\alpha + \beta = 2(-1 + 3i\sqrt{11}) = -2 + 6i\sqrt{11}$$

$$\alpha\beta + \alpha + \beta + 100 = -98 - 6i\sqrt{11} + (-2 + 6i\sqrt{11}) + 100$$
$$= -98 - 2 + 100 + (-6i\sqrt{11} + 6i\sqrt{11}) = 0$$ ✓

Also verify $|\alpha| = |\beta| = 10$:
$$|\alpha| = \sqrt{1 + 9(11)} = \sqrt{100} = 10$$ ✓

## 5. Confirm Answer is Reasonable

- M = 10 is a clean positive integer
- The moduli are equal as required
- All constraints are satisfied
- The solution is elegant and symmetric

**FINAL ANSWER: 10**
