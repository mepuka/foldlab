# Finding All Palindromes with Digit Sum 13

## Statement of Problem
Find all palindromes using only digits from {1, 2, 3, 4, 5, 6, 7, 8, 9} (no zeros) whose digits sum to exactly 13.

---

## Complete Calculation

### Key Observation
For an n-digit palindrome with **even** n, the digit sum must be **even** (all digits appear twice). For **odd** n, the middle digit appears once while others appear twice, allowing **odd** sums. Since 13 is odd, **only odd-length palindromes are possible**.

---

### **1-Digit Palindromes**
Form: a
Need: a = 13
**Impossible** (max digit = 9)
**Count: 0**

---

### **3-Digit Palindromes**
Form: aba
Need: 2a + b = 13, where a, b ∈ {1, 2, ..., 9}

| a | b = 13 - 2a | Valid? | Palindrome |
|---|---|---|---|
| 1 | 11 | ✗ | |
| 2 | 9 | ✓ | 292 |
| 3 | 7 | ✓ | 373 |
| 4 | 5 | ✓ | 454 |
| 5 | 3 | ✓ | 535 |
| 6 | 1 | ✓ | 616 |
| 7 | -1 | ✗ | |

**Count: 5**

---

### **5-Digit Palindromes**
Form: abcba
Need: 2a + 2b + c = 13

Systematically iterating:
- **a = 1**: 2b + c = 11 → (b,c): (1,9), (2,7), (3,5), (4,3), (5,1) → **5 solutions**
- **a = 2**: 2b + c = 9 → (b,c): (1,7), (2,5), (3,3), (4,1) → **4 solutions**
- **a = 3**: 2b + c = 7 → (b,c): (1,5), (2,3), (3,1) → **3 solutions**
- **a = 4**: 2b + c = 5 → (b,c): (1,3), (2,1) → **2 solutions**
- **a = 5**: 2b + c = 3 → (b,c): (1,1) → **1 solution**
- **a ≥ 6**: 2a ≥ 12, leaving c ≤ 1, but c ≥ 1 requires a ≤ 5

Example: 42124 has digit sum 4+2+1+2+4 = 13 ✓

**Count: 5 + 4 + 3 + 2 + 1 = 15**

---

### **7-Digit Palindromes**
Form: abcdcba
Need: 2a + 2b + 2c + d = 13

Systematically iterating:
- **a = 1**: 2b + 2c + d = 11
  - b = 1: 2c + d = 9 → c ∈ {1,2,3,4} → **4 solutions**
  - b = 2: 2c + d = 7 → c ∈ {1,2,3} → **3 solutions**
  - b = 3: 2c + d = 5 → c ∈ {1,2} → **2 solutions**
  - b = 4: 2c + d = 3 → c = 1 → **1 solution**
  - Subtotal: **10**

- **a = 2**: 2b + 2c + d = 9
  - b = 1: 2c + d = 7 → c ∈ {1,2,3} → **3 solutions**
  - b = 2: 2c + d = 5 → c ∈ {1,2} → **2 solutions**
  - b = 3: 2c + d = 3 → c = 1 → **1 solution**
  - Subtotal: **6**

- **a = 3**: 2b + 2c + d = 7
  - b = 1: 2c + d = 5 → c ∈ {1,2} → **2 solutions**
  - b = 2: 2c + d = 3 → c = 1 → **1 solution**
  - Subtotal: **3**

- **a = 4**: 2b + 2c + d = 5
  - b = 1: 2c + d = 3 → c = 1 → **1 solution**
  - Subtotal: **1**

**Count: 10 + 6 + 3 + 1 = 20**

---

### **9-Digit and Higher**
Form: abcdedcba
Need: 2a + 2b + 2c + 2d + e = 13

Minimum sum with all 1s: 2(1+1+1+1) + 1 = 9 ✓ Possible
Maximum a where 2a < 13: a ≤ 6

Following similar analysis as 7-digit: **Count: 15**

---

### **11-Digit and Higher**
Following the pattern, solutions exist but become increasingly sparse.

**Continuing with diminishing counts for 11-digit, 13-digit, etc.**

After systematic enumeration:
- 11-digit: 6 solutions
- 13-digit: 1 solution (all 1s)

---

## Verification
- 42124: 4+2+1+2+4 = 13 ✓ (5-digit palindrome)
- 292: 2+9+2 = 13 ✓ (3-digit palindrome)
- 1111111111111: sum = 13 ✓ (13-digit palindrome)

---

## Final Sum
5 + 15 + 20 + 15 + 6 + 1 = **62**

**FINAL ANSWER: 62**
