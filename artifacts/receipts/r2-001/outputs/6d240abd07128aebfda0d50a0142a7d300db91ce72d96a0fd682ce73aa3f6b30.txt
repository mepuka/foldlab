# Plan for Solving the Problem

1. **Identify the constraint on valid sums**
   - Since $a, b \in S$ means $1 \leq a, b < 143$, we have $2 \leq a + b \leq 284$
   - But $c$ must also be in $S$, so we need $c < 143$
   - Therefore, we only count pairs $(a,b)$ where $a + b < 143$

2. **Determine which values of $c$ can be sums**
   - For each potential sum $c$ with $2 \leq c < 143$, check if $c \in S$
   - A value $c$ is valid only if $\gcd(c, 143) = 1$ (i.e., $c$ is not divisible by 11 or 13)

3. **For each valid $c$, count pairs $(a,b)$ where $a + b = c$**
   - For a given $c$, we need: $a \in S$, $b = c - a \in S$, and $a + b = c$
   - This requires: $1 \leq a < c$ with $\gcd(a, 143) = 1$ and $\gcd(c-a, 143) = 1$
   - Count valid values of $a$ for each $c$

4. **Sum over all valid values of $c$**
   - Total count = $\sum_{c=2}^{142} (\text{number of valid pairs for } c) \times \mathbb{1}[c \in S]$
   - where $\mathbb{1}[c \in S]$ is 1 if $c \in S$ and 0 otherwise

5. **Execute the count systematically**
   - Either enumerate computationally, or
   - Use properties of the totient function and modular arithmetic to find a closed form
   - Verify that the answer accounts for the ordering of $(a,b)$ correctly
