# Solution: Finding the Second Smallest Multiple of 101 Containing "2026"

## Step 1: Check if 2026 itself is divisible by 101

$$2026 \div 101 = 20 \text{ remainder } 6$$

Verification: $101 \times 20 + 6 = 2020 + 6 = 2026$ ✓

**2026 is NOT divisible by 101** (remainder = 6)

## Step 2: Find the smallest multiple of 101 containing "2026"

Since 2026 alone doesn't work, I'll search systematically through numbers containing "2026" as a substring.

**Range: 202600-202699** (numbers of form 202600+k all contain "2026")

For 202600:
$$202600 = 101 \times 2000 + 600$$
$$600 = 101 \times 5 + 95$$
$$202600 = 101 \times 2005 + 95$$

So remainder is 95. We need to add: $101 - 95 = 6$

$$202606 = 202600 + 6$$

**Verification that 202606 is divisible by 101:**
$$202606 \div 101 = 2006$$
$$101 \times 2006 = 202,606$$ ✓

**Verification that it contains "2026":**
Digits: 2-0-2-6-0-6. Contains "2026" at positions 0-3 ✓

**First smallest = 202606**

## Step 3: Find the second smallest

The next multiple of 101 after 202606 is:
$$202606 + 101 = 202707$$

**Check if 202707 contains "2026":**
Digits: 2-0-2-7-0-7. Does NOT contain "2026" ✗

So I need to check other ranges containing "2026".

**Range: 2026000-2026999** (all contain "2026" at the beginning)

For 2026000:
$$2026000 = 101 \times 20000 + 6000$$
$$6000 = 101 \times 59 + 41$$
$$2026000 = 101 \times 20059 + 41$$

We need to add: $101 - 41 = 60$

$$2026060 = 2026000 + 60$$

**Verification that 2026060 is divisible by 101:**
$$2026060 \div 101 = 20060$$
$$101 \times 20060 = 2,026,060$$ ✓

**Verification that it contains "2026":**
Digits: 2-0-2-6-0-6-0. Contains "2026" at positions 0-3 ✓

## Step 4: Verify the ordering

- First smallest: **202606** (divisible by 101, contains "2026")
- Second smallest: **2026060** (divisible by 101, contains "2026")

Since $202606 < 2026060$, the second smallest is indeed **2026060**.
