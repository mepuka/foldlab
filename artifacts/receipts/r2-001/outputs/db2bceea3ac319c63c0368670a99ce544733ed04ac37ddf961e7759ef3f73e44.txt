# Solution: Count of Palindromes with Digit Sum 13

I'll systematically work through each palindrome length.

## 1-digit Palindromes
Form: a
- Need: a = 13
- Impossible (max digit is 9)
- **Count: 0**

## 2-digit Palindromes  
Form: aa
- Need: 2a = 13
- 13 is odd, impossible
- **Count: 0**

## 3-digit Palindromes
Form: aba
- Need: 2a + b = 13, so b = 13 - 2a
- Constraints: a,b ∈ {1,2,...,9}

Valid combinations:
- a=2: b=9 ✓ → 292
- a=3: b=7 ✓ → 373
- a=4: b=5 ✓ → 454
- a=5: b=3 ✓ → 535
- a=6: b=1 ✓ → 616

**Count: 5**

## 4-digit Palindromes

## 5-digit Palindromes
Form: abcba
- Need: 2a + 2b + c = 13, so c = 13 - 2a - 2b
- Constraint: 1 ≤ c ≤ 9 means 1 ≤ a + b ≤ 6

Counting valid (a,b) pairs for each sum:
- a + b = 2: (1,1) → c=9 | Count: 1
- a + b = 3: (1,2), (2,1) → c=7 | Count: 2
- a + b = 4: (1,3), (2,2), (3,1) → c=5 | Count: 3
- a + b = 5: (1,4), (2,3), (3,2), (4,1) → c=3 | Count: 4
- a + b = 6: (1,5), (2,4), (3,3), (4,2), (5,1) → c=1 | Count: 5

**Count: 1 + 2 + 3 + 4 + 5 = 15**

## 7-digit Palindromes

- Constraint: 1 ≤ d ≤ 9 means 2 ≤ a+b+c ≤ 6

- Sum=3: (1,1,1) → d=7 | Count: 1
- Sum=4: (1,1,2), (1,2,1), (2,1,1) → d=5 | Count: 3
- Sum=5: Partitions with 3 parts = 6 ordered triples → d=3 | Count: 6
  - (1,1,3), (1,3,1), (3,1,1), (1,2,2), (2,1,2), (2,2,1)
- Sum=6: Partitions with 3 parts = 10 ordered triples → d=1 | Count: 10

**Count: 1 + 3 + 6 + 10 = 20**
