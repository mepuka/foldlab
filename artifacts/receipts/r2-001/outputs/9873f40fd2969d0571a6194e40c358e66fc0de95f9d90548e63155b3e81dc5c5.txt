## Step 1: Apply the Angle Bisector Theorem

**What we're calculating:** The ratio of segments created by angle bisector $AD$ on side $BC$.

**Calculation:**
By the Angle Bisector Theorem:
$$\frac{BD}{DC} = \frac{AB}{AC} = \frac{200}{225} = \frac{8}{9}$$

Let $BD = 8k$ and $DC = 9k$ for some positive constant $k$.

Therefore: $BC = BD + DC = 8k + 9k = 17k$

**Verification:** The ratio simplifies correctly and $BD + DC = BC$ ✓

---

## Step 2: Use Power of a Point

**What we're calculating:** The lengths $AE$ and $AF$ using power of a point.

**For point $B$:**
$$BA \cdot BE = BD^2$$
$$200 \cdot BE = (8k)^2 = 64k^2$$
$$BE = \frac{8k^2}{25}$$
$$AE = 200 - \frac{8k^2}{25} = \frac{5000 - 8k^2}{25}$$

**For point $C$:**
$$CA \cdot CF = CD^2$$
$$225 \cdot CF = (9k)^2 = 81k^2$$
$$CF = \frac{9k^2}{25}$$
$$AF = 225 - \frac{9k^2}{25} = \frac{5625 - 9k^2}{25}$$

**Verification:** The power of point formula is correctly applied ✓

---

## Step 3: Enforce Integer Constraints

**What we're calculating:** The divisibility conditions for $AE$ and $AF$ to be integers.

**Calculation:**
For $AE$ to be an integer: $5000 - 8k^2 \equiv 0 \pmod{25}$

Since $5000 = 200 \times 25 \equiv 0 \pmod{25}$:
$$8k^2 \equiv 0 \pmod{25}$$

Since $\gcd(8, 25) = 1$, we need $k^2 \equiv 0 \pmod{25}$, thus $k \equiv 0 \pmod{5}$.

Same analysis for $AF$: $9k^2 \equiv 0 \pmod{25}$ also requires $k \equiv 0 \pmod{5}$.

**Conclusion:** $k = 5m$ for positive integer $m$ ✓

---

## Step 4: Substitute and Simplify

**What we're calculating:** Expressions for $AE$ and $AF$ in terms of $m$.

**Substituting $k = 5m$:**
$$AE = \frac{5000 - 8(25m^2)}{25} = \frac{5000 - 200m^2}{25} = 200 - 8m^2$$
$$AF = \frac{5625 - 9(25m^2)}{25} = \frac{5625 - 225m^2}{25} = 225 - 9m^2$$

**Finding constraints:**
- For $AE > 0$: $200 - 8m^2 > 0 \Rightarrow m^2 < 25 \Rightarrow m \leq 4$
- For $AF > 0$: $225 - 9m^2 > 0 \Rightarrow m^2 < 25 \Rightarrow m \leq 4$

**Verification:** Both constraints give $m \in \{1, 2, 3, 4\}$ ✓
