# Solution: HATER + HEART = EARTH

## Step 1: Simplify the Algebraic Constraint

Starting with the cryptarithmetic equation:
- HATER = 10000H + 1000A + 100T + 10E + R
- HEART = 10000H + 1000E + 100A + 10R + T  
- EARTH = 10000E + 1000A + 100R + 10T + H

**Expanding the left side:**
$$10000H + 1000A + 100T + 10E + R + 10000H + 1000E + 100A + 10R + T$$
$$= 20000H + 1100A + 101T + 1010E + 11R$$

**Setting equal to EARTH:**
$$20000H + 1100A + 101T + 1010E + 11R = 10000E + 1000A + 100R + 10T + H$$

**Rearranging to standard form:**
$$19999H + 100A + 91T + 1010E + 11R = 10000E + 1000A + 100R + 10T + H$$
$$19999H + 100A + 91T = 8990E + 89R$$

**Verification by collecting coefficients:**
- H: 20000 - 1 = 19999 ✓
- A: 1100 - 1000 = 100 ✓
- T: 101 - 10 = 91 ✓
- E: 1010 - 10000 = -8990 ✓
- R: 11 - 100 = -89 ✓
