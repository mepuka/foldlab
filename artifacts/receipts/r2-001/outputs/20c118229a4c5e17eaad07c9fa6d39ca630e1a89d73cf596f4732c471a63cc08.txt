# Detailed Solution

## Step 1: Set Up Coordinate System

- $A = (0, 0)$
- $B = (1, 0)$ (since $AB = 1$)
- $D = (0, h)$ where $h = AD$ (unknown)
- $C = (1, h)$ (rectangle configuration)

## Step 2: Express Positions of X and Y

- $X = (1, x)$ for some $0 \leq x \leq h$ (point on $\overline{BC}$)
- $Y = (0, y)$ for some $0 \leq y \leq h$ (point on $\overline{AD}$)

## Step 3: Apply Length Ratio Conditions

**From $AX = k$:**
$$AX = \sqrt{1^2 + x^2} = k$$
$$1 + x^2 = k^2 \quad \text{...(1)}$$

**From $XY = 2k$:**
$$XY = \sqrt{1 + (y-x)^2} = 2k$$
$$1 + (y-x)^2 = 4k^2 \quad \text{...(2)}$$

**From $YC = k$:**
$$YC = \sqrt{1 + (h-y)^2} = k$$
$$1 + (h-y)^2 = k^2 \quad \text{...(3)}$$

## Step 4: Apply Perpendicularity Conditions

**From $\angle AXY = 90°$:**
$$\vec{XA} = (-1, -x), \quad \vec{XY} = (-1, y-x)$$
$$\vec{XA} \cdot \vec{XY} = 1 - x(y-x) = 0$$
$$1 + x^2 = xy \quad \text{...(4)}$$

**From $\angle XYC = 90°$:**
$$\vec{YX} = (1, x-y), \quad \vec{YC} = (1, h-y)$$
$$\vec{YX} \cdot \vec{YC} = 1 + (x-y)(h-y) = 0$$
$$(x-y)(h-y) = -1 \quad \text{...(5)}$$

## Step 5: Solve the System of Equations

**From equations (1) and (3):**
$$1 + x^2 = 1 + (h-y)^2$$
$$x = h - y$$
$$y = h - x \quad \text{...(6)}$$

**Substitute (6) into (5):**
$$(x - (h-x))(h - (h-x)) = -1$$
$$(2x - h)(x) = -1$$
$$2x^2 - xh = -1$$
$$xh = 2x^2 + 1 \quad \text{...(7)}$$

**Substitute (6) into (2):**
$$1 + (h - 2x)^2 = 4k^2$$

Using $k^2 = 1 + x^2$ from (1):
$$1 + (h - 2x)^2 = 4(1 + x^2)$$
$$(h - 2x)^2 = 3 + 4x^2$$
$$h^2 - 4xh + 4x^2 = 3 + 4x^2$$
$$h^2 - 4xh = 3 \quad \text{...(8)}$$

**Substitute (7) into (8):**
$$h^2 - 4(2x^2 + 1) = 3$$
$$h^2 = 8x^2 + 7 \quad \text{...(9)}$$

**From (7):** $h = \frac{2x^2 + 1}{x}$

Squaring: $h^2 = \frac{(2x^2 + 1)^2}{x^2} = \frac{4x^4 + 4x^2 + 1}{x^2}$

**Equate with (9):**
$$\frac{4x^4 + 4x^2 + 1}{x^2} = 8x^2 + 7$$
$$4x^4 + 4x^2 + 1 = 8x^4 + 7x^2$$
$$4x^4 + 3x^2 - 1 = 0$$

**Using the quadratic formula with $u = x^2$:**
$$4u^2 + 3u - 1 = 0$$
$$u = \frac{-3 \pm \sqrt{9 + 16}}{8} = \frac{-3 \pm 5}{8}$$

$$u = \frac{1}{4} \quad \text{(rejecting negative solution)}$$

Therefore: $x = \frac{1}{2}$

**From (9):**
$$h^2 = 8 \cdot \frac{1}{4} + 7 = 2 + 7 = 9$$
$$h = 3$$

## Step 6: Verification

With $x = \frac{1}{2}$, $y = \frac{5}{2}$, $h = 3$, $k = \frac{\sqrt{5}}{2}$:

- $AX = \sqrt{1 + \frac{1}{4}} = \frac{\sqrt{5}}{2}$ ✓
- $XY = \sqrt{1 + (2)^2} = \sqrt{5} = 2k$ ✓
- $YC = \sqrt{1 + (\frac{1}{2})^2} = \frac{\sqrt{5}}{2}$ ✓
- $xy = \frac{5}{4} = 1 + x^2$ ✓
- $(x-y)(h-y) = (-2)(\frac{1}{2}) = -1$ ✓

FINAL ANSWER: **3**
