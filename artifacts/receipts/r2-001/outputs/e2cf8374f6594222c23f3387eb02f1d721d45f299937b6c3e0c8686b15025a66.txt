# Solution: Counting Palindromes with Digit Sum 13

I'll find all palindromes with digit sum exactly 13, where all digits are non-zero.

## Step 1: Categorize by Length

For an n-digit palindrome, only ⌈n/2⌉ digits are independent (the rest are determined by symmetry).

## Step 2: Analyze Each Length

### **1-Digit Palindromes**
- Independent positions: 1
- Need digit sum = 13
- Since max digit is 9, this is **impossible**
- **Count: 0**

### **2-Digit Palindromes (form: aa)**
- Independent positions: 1 (just choose a)
- Total sum = a + a = 2a
- Need 2a = 13 → a = 6.5
- **Not an integer, impossible**
- **Count: 0**

### **3-Digit Palindromes (form: aba)**
- Independent positions: 2 (first and middle)
- Total sum = a + b + a = 2a + b = 13
- Need: b = 13 - 2a, where 1 ≤ a, b ≤ 9

Finding valid (a,b) pairs:
- a = 1: b = 11 ✗ (b > 9)
- a = 2: b = 9 ✓ → palindrome: **292**
- a = 3: b = 7 ✓ → palindrome: **373**
- a = 4: b = 5 ✓ → palindrome: **454**
- a = 5: b = 3 ✓ → palindrome: **535**
- a = 6: b = 1 ✓ → palindrome: **616**
- a = 7: b = -1 ✗ (b < 1)

**Count: 5**

### **4-Digit Palindromes (form: abba)**
- Independent positions: 2 (first and second)
- Total sum = a + b + b + a = 2a + 2b = 13
- Need: 2(a + b) = 13 → a + b = 6.5
- **Not an integer, impossible**
- **Count: 0**

### **5-Digit Palindromes (form: abcba)**
- Independent positions: 3 (first, second, and middle)
- Total sum = a + b + c + b + a = 2a + 2b + c = 13
- Need: c = 13 - 2a - 2b, where 1 ≤ a, b, c ≤ 9

Finding valid (a, b, c) triples:

For each a, we need c = 13 - 2a - 2b with 1 ≤ c ≤ 9:

- **a = 1**: 2b + c = 11
  - b = 1: c = 9 ✓ → **11911**
  - b = 2: c = 7 ✓ → **12721**
  - b = 3: c = 5 ✓ → **13531**
  - b = 4: c = 3 ✓ → **14341**
  - b = 5: c = 1 ✓ → **15151**

- **a = 2**: 2b + c = 9
  - b = 1: c = 7 ✓ → **21712**
  - b = 2: c = 5 ✓ → **22522**
  - b = 3: c = 3 ✓ → **23332**
  - b = 4: c = 1 ✓ → **24142**

- **a = 3**: 2b + c = 7
  - b = 1: c = 5 ✓ → **31513**
  - b = 2: c = 3 ✓ → **32323**
  - b = 3: c = 1 ✓ → **33133**

- **a = 4**: 2b + c = 5
  - b = 1: c = 3 ✓ → **41314**
  - b = 2: c = 1 ✓ → **42124** ✓ (matches example!)

- **a = 5**: 2b + c = 3
  - b = 1: c = 1 ✓ → **51115**

- **a = 6**: 2b + c = 1
  - No valid solutions (would need b + c/2 = 0.5)

**Count: 14**

### **6-Digit Palindromes (form: abccba)**
- Independent positions: 3
- Total sum = 2a + 2b + 2c = 13
- Need: 2(a + b + c) = 13 → a + b + c = 6.5
- **Not an integer, impossible**
- **Count: 0**

### **7+ Digit Palindromes**
- All even-length palindromes require even digit sums (impossible for sum = 13)
- All odd palindromes of 7+ digits have more independent positions, but 2(a+b+c+d...) = 13 → impossible
- **Count: 0**
