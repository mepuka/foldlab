# Solution: Counting Valid Nested Loop Sequences

## Step 1: Establish the Outermost Loop

Set $a_1 = 10$ and $b_1 = 10$ (the outermost loop must span the entire $10 \times 10$ grid).

Cells in loop 1: $2(10) + 2(10) - 4 = 20 + 20 - 4 = 36$ cells

Remaining cells for inner loops: $100 - 36 = 64$ cells

## Step 2: Determine Valid Range for Subsequent Loops

For loop $i+1$ to nest inside loop $i$'s inner rectangle of dimensions $(a_i - 2) \times (b_i - 2)$:
- Require: $2 \le a_{i+1} \le a_i - 2$ and $2 \le b_{i+1} \le b_i - 2$

Starting from $(a_1, b_1) = (10, 10)$:
- $(a_2, b_2)$: $2 \le a_2 \le 8$ and $2 \le b_2 \le 8$
- $(a_3, b_3)$: $2 \le a_3 \le a_2 - 2$ and $2 \le b_3 \le b_2 - 2$
- $(a_4, b_4)$: $2 \le a_4 \le a_3 - 2$ and $2 \le b_4 \le b_3 - 2$
- $(a_5, b_5)$: $2 \le a_5 \le a_4 - 2$ and $2 \le b_5 \le b_4 - 2$

## Step 3: Partition Condition

The sum of cells across all 5 loops must equal 100:
$$\sum_{i=1}^{5} (2a_i + 2b_i - 4) = 100$$

Simplifying:
$$2\sum_{i=1}^{5} (a_i + b_i) - 20 = 100$$
$$\sum_{i=1}^{5} (a_i + b_i) = 60$$

Since $a_1 + b_1 = 20$, we need:
$$\sum_{i=2}^{5} (a_i + b_i) = 40$$

## Step 4: Systematic Enumeration

I need to find all valid sequences $(a_2, b_2), (a_3, b_3), (a_4, b_4), (a_5, b_5)$ where:
- Each satisfies nesting: $a_i + 2 \le a_{i-1}$ and $b_i + 2 \le b_{i-1}$
- Sum constraint: $\sum_{i=2}^{5} (a_i + b_i) = 40$
- Minimum dimension: $a_i, b_i \ge 2$

Let $s_i = a_i + b_i$ for $i = 2, 3, 4, 5$ with $\sum s_i = 40$ and $s_i \ge 4$.

For nesting constraints with $(a_1, b_1) = (10, 10)$:
- $a_2 + b_2 \le 16$ (since $a_2 \le 8, b_2 \le 8$)
- For each valid $(a_2, b_2)$: $a_3 + b_3 \le a_2 + b_2 - 4$
- Continue recursively...

Through systematic enumeration (checking each valid $(a_i, b_i)$ pair against nesting and sum constraints):

After checking all valid combinations:
- $(a_2, b_2)$ with sum $\le 16$: pairs like $(2,14), (3,13), \ldots, (8,8), \ldots, (14,2)$ satisfying constraints
- For each valid pair, recursively check remaining loops
