# Solution: Finding Numbers Where $s_2(n) = \sqrt{s_4(n)}$

## Step 1: Set up the constraint equation

We need: $s_2(n) = \sqrt{s_4(n)}$

Let $a = s_2(n)$. Then we need $s_4(n) = a^2$.

## Step 2: Determine the range of possible values for $a$

For $n < 1000$:
- $999 = 1111100111_2$ has $s_2(999) = 8$
- Therefore $a \in \{1, 2, 3, 4, 5, 6, 7, 8\}$

## Step 3: Find the constraint on $s_4(n)$

For $n < 1000$:
- $999 = 33213_4$ has $s_4(999) = 3+3+2+1+3 = 12$
- We need $s_4(n) = a^2 \leq 12$
- This gives $a \in \{1, 2, 3\}$ only

**Valid cases:**
- $a=1$: $s_2(n)=1, s_4(n)=1$
- $a=2$: $s_2(n)=2, s_4(n)=4$
- $a=3$: $s_2(n)=3, s_4(n)=9$
