I need to find all possible values of $M$ where $|\alpha| = |\beta| = M$ and $\alpha\beta + \alpha + \beta + 100 = 0$.

**Rewriting the constraint:**

From $\alpha\beta + \alpha + \beta + 100 = 0$, I can factor:
$$\alpha\beta + \alpha + \beta + 1 = -99$$
$$\alpha(1 + \beta) + (1 + \beta) = -99$$
$$(1 + \alpha)(1 + \beta) = -99$$

**Setting up equations with the constraint $|\alpha| = |\beta| = M$:**

Let me denote $\alpha$ and $\beta$ such that $|\alpha| = |\beta| = M$.

From $(1 + \alpha)(1 + \beta) = -99$, taking absolute values:
$$|1 + \alpha||1 + \beta| = 99$$

**Using symmetry:**

Since the condition is symmetric in $\alpha$ and $\beta$, consider whether $\alpha = \beta$.

If $\alpha = \beta$, then:
$$(1 + \alpha)^2 = -99$$
$$1 + \alpha = \pm i\sqrt{99} = \pm 3i\sqrt{11}$$
$$\alpha = -1 \pm 3i\sqrt{11}$$

Then:
$$M = |\alpha| = |-1 \pm 3i\sqrt{11}| = \sqrt{1 + 99} = \sqrt{100} = 10$$

**Checking if there are other solutions:**

Suppose $\alpha \neq \beta$. We have $|\alpha| = |\beta| = M$.

From $(1 + \alpha)(1 + \beta) = -99$:
- $|1 + \alpha||1 + \beta| = 99$

Let $|1 + \alpha| = r$ and $|1 + \beta| = s$ where $rs = 99$.

Also, $(1 + \alpha)(1 + \beta) = -99$ is a negative real number, so:
$$1 + \alpha + \beta + \alpha\beta = -99$$

Since $|\alpha| = |\beta| = M$, we can write $\alpha = Me^{i\theta_1}$ and $\beta = Me^{i\theta_2}$.

Taking the complex conjugate of $(1 + \alpha)(1 + \beta) = -99$:
$$(\overline{1 + \alpha})(\overline{1 + \beta}) = -99$$
$$(1 + \bar{\alpha})(1 + \bar{\beta}) = -99$$

If $|\alpha| = M$, then $\bar{\alpha} = M^2/\alpha$ only if $\alpha$ is real, which isn't generally true.

**Alternative approach - using the constraint differently:**

From $(1 + \alpha)(1 + \beta) = -99$ and $|\alpha| = |\beta| = M$:

If $(1+\alpha)(1+\beta) = -99$ (real), then $1 + \alpha + \beta + \alpha\beta = -99$, so:
$$\alpha + \beta = -100 - \alpha\beta$$

The constraint $(1+\alpha)(1+\beta) = -99$ is real, which means the argument of $(1+\alpha)$ plus the argument of $(1+\beta)$ equals $\pi$ (mod $2\pi$).

For the case $\alpha = \beta = -1 + 3i\sqrt{11}$, we already found $M = 10$.

For $M = 0$: If $\alpha = \beta = 0$, then $0 + 0 + 0 + 100 = 100 \neq 0$, so $M = 0$ doesn't work.

By the constraint and symmetry analysis, the condition forces $\alpha = \beta$, giving us the unique solution:

$$M = 10$$
