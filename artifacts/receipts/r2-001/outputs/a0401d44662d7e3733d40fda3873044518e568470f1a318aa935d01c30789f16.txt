# Step-by-Step Solution for Fixed Points of f(n)

## Step 1: Understanding the Function f(n)

**What we're calculating:** Understanding f(n) means finding the greatest digit d in n, converting n to base (d+1), then reading the result as a base-10 number.

**Example:** For n = 19, greatest digit is 9, so base = 10. The number 19 in base 10 is "19", which reads as 19 in base 10. Thus f(19) = 19.

---

## Step 2: One-Digit Numbers (n = 1 to 9)

**What we're calculating:** Whether all single digits satisfy f(d) = d

**Complete calculation:**
- For any 1-digit number n = d (where 1 ≤ d ≤ 9)
- Greatest digit: d
- Base: b = d + 1
- n in base (d+1): simply the digit d
- Reading d in base 10: gives d
- Therefore: f(d) = d ✓

**Verification:** This holds for all digits 1-9.

**Result: 9 fixed points**

---

## Step 3: Two-Digit Numbers (n = 10 to 99)

**What we're calculating:** Two-digit numbers where f(n) = n

**Complete calculation:**
- Write n = 10a + c where a ∈ {1,...,9}, c ∈ {0,...,9}
- Greatest digit: d = max(a,c)
- Base: b = d + 1
- In base b: n = a·b + c (since all digits must be valid in base b)
- For fixed point: 10a + c = a·b + c
- Simplifying: 10a = a·b = a(d+1)
- Since a > 0: **10 = d + 1, so d = 9**

**Finding all numbers with greatest digit 9:**
- If a = 9: c ∈ {0,1,2,...,9} → **10 numbers** (90-99)
- If a ≠ 9 but c = 9: a ∈ {1,2,...,8} → **8 numbers** (19, 29, 39, 49, 59, 69, 79, 89)

**Verification:** For n = 90: greatest digit is 9, so base = 10. In base 10: 90 = 9·10 + 0. f(90) = 90 ✓

**Result: 18 fixed points**

---

## Step 4: Three-Digit Numbers (n = 100 to 999)

**What we're calculating:** Three-digit numbers where f(n) = n

**Complete calculation:**
- Write n = 100a + 10b + c where a ∈ {1,...,9}, b,c ∈ {0,...,9}
- Greatest digit: d = max(a,b,c)
- Base: = d + 1
- In base (d+1): n = a(d+1)² + b(d+1) + c
- For fixed point: 100a + 10b + c = a(d+1)² + b(d+1) + c
- Simplifying: 100a + 10b = a(d+1)² + b(d+1)
- Rearranging: **a[100 - (d+1)²] + b[10 - (d+1)] = 0**

**Testing values of d:**

**Case d = 9** (base = 10):
- a[100 - 100] + b[10 - 10] = 0
- 0 = 0 ✓
- This is always satisfied!
- Constraint: max(a,b,c) = 9 (at least one digit equals 9)

**Counting using inclusion-exclusion:**
- Total 3-digit numbers: 900
- Numbers with NO 9: a ∈ {1,...,8}, b ∈ {0,...,8}, c ∈ {0,...,8} 
  - Count: 8 × 9 × 9 = 648
- Numbers with at least one 9: 900 - 648 = **252**

**Case d = 8** (base = 9):
- a[100 - 81] + b[10 - 9] = 0
- 19a + b = 0
- Since a > 0 and b ≥ 0, this is impossible. ✗

**Case d ≤ 7:** The left coefficient becomes even larger while the right becomes increasingly negative, making all such cases impossible. ✗

**Verification:** For n = 900: greatest digit is 9, base = 10. In base 10: 900 = 9·100 + 0·10 + 0. f(900) = 900 ✓

**Result: 252 fixed points**

---

## Step 5: Summing All Categories

**What we're calculating:** Total number of fixed points

**Complete calculation:**
- 1-digit fixed points: 9
- 2-digit fixed points: 18
- 3-digit fixed points: 252
- **Total: 9 + 18 + 252 = 279**

**Verification by checking key patterns:**
- All 1-digit numbers work (trivial)
- All 2-digit numbers with at least one digit 9 work (10 + 8 = 18) ✓
- All 3-digit numbers with at least one digit 9 work (900 - 648 = 252) ✓

**Checking reasonableness:** We expect roughly 10% of 3-digit numbers (those containing 9) to be fixed points. 252/900 ≈ 28%, which is higher but makes sense given our analysis. The answer is a reasonable integer.

---

**FINAL ANSWER: 279**
