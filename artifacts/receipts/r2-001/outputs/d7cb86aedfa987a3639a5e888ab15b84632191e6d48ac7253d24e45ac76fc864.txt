# Solution: Counting "SUNS" Subsequences in "SUN" Repeated 10 Times

The string is: SUN repeated 10 times = SUNSUNSUNSUNSUNSUNSUNSUNSUNSUNSUN (30 characters total)

**Valid positions for each letter:**
- **S positions:** 1, 4, 7, 10, 13, 16, 19, 22, 25, 28 (pattern: 3k+1 for k=0,1,...,9)
- **U positions:** 2, 5, 8, 11, 14, 17, 20, 23, 26, 29 (pattern: 3k+2 for k=0,1,...,9)
- **N positions:** 3, 6, 9, 12, 15, 18, 21, 24, 27, 30 (pattern: 3k for k=1,2,...,10)

Verification: 10 positions for each letter. ✓

## Step 2: Set Up the Counting Framework

Let me index these positions:
- $s_i = 3i - 2$ for $i = 1, 2, ..., 10$ (S positions)
- $u_j = 3j - 1$ for $j = 1, 2, ..., 10$ (U positions)  
- $n_k = 3k$ for $k = 1, 2, ..., 10$ (N positions)

**Verification of indexing:**
- $s_1 = 3(1)-2 = 1$ ✓, $s_{10} = 3(10)-2 = 28$ ✓
- $u_1 = 3(1)-1 = 2$ ✓, $u_{10} = 3(10)-1 = 29$ ✓
- $n_1 = 3(1) = 3$ ✓, $n_{10} = 3(10) = 30$ ✓

## Step 3: Determine Constraints for Valid Quadruples

For positions $i_1 < i_2 < i_3 < i_4$ where we choose indices $(i,j,k,\ell)$:
- Need: $s_i < u_j < n_k < s_\ell$

**Checking $s_i < u_j$:**
$$3i - 2 < 3j - 1 \implies 3i < 3j + 1 \implies i \leq j$$
For strict inequality on positions: $i < j$ is required.

**Checking $u_j < n_k$:**
$$3j - 1 < 3k \implies 3j < 3k + 1 \implies j \leq k$$
For strict inequality on positions: $j < k$ is required.

**Checking $n_k < s_\ell$:**
$$3k < 3\ell - 2 \implies 3k + 2 < 3\ell \implies k + \frac{2}{3} < \ell$$
Since these are integers: $k < \ell$, so $\ell > k$.

**Summary:** We need $1 \leq i < j < k < \ell \leq 10$.

## Step 4: Count by Fixing k

For each fixed value of $k$:
- Count pairs $(i,j)$ with $1 \leq i < j < k$: This is $\binom{k-1}{2}$
- Count values of $\ell$ with $k < \ell \leq 10$: This is $10 - k$
- Contribution: $\binom{k-1}{2} \cdot (10-k)$

## Step 5: Calculate Total

$$\text{Total} = \sum_{k=1}^{10} \binom{k-1}{2} \cdot (10-k)$$

Computing each term:
