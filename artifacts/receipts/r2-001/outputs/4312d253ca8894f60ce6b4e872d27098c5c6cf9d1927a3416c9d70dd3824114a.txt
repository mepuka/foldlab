# Solution: Finding the Radius $r$ of Sphere 4

## Step 1: Set up coordinate system
**Calculating:** Establish positions of vertices and plane $\mathcal{P}$

- $A = (0, 0, 0)$
- $B = (6, 0, 0)$
- $C = (0, 4, 0)$
- Plane $\mathcal{P}$ is the $xy$-plane ($z = 0$)

**Verification:** Triangle $ABC$ has legs of length 6 and 4 along the axes. ✓

## Step 2: Find the centroid and point $D$
**Calculating:** Centroid of triangle $ABC$

$$G = \left(\frac{0+6+0}{3}, \frac{0+0+4}{3}, 0\right) = \left(2, \frac{4}{3}, 0\right)$$

**Finding line BC:** The line through $B(6,0)$ and $C(0,4)$ is: $2x + 3y = 12$

**Reflecting $G$ across line $BC$:**

Foot of perpendicular: Using parametric form $P(t) = (6-6t, 4t)$, require $(P-G) \perp \vec{BC}$:
$$(4-6t)(-6) + (4t-\frac{4}{3})(4) = 0$$
$$-24 + 36t + 16t - \frac{16}{3} = 0$$
$$52t = \frac{88}{3} \implies t = \frac{22}{39}$$

Foot: $P = \left(\frac{34}{13}, \frac{88}{39}\right)$

Reflection: $$D = 2P - G = \left(\frac{42}{13}, \frac{124}{39}\right) = \left(\frac{42}{13}, \frac{124}{39}, 0\right)$$

## Step 3: Identify sphere centers
**Calculating:** Sphere centers and radii

Since each sphere is tangent to plane $\mathcal{P}$:
- $O_1 = (0, 0, 1)$ with $r_1 = 1$ (height = radius)
- $O_2 = (6, 0, 2)$ with $r_2 = 2$
- $O_3 = (0, 4, 3)$ with $r_3 = 3$
- $O_4 = \left(\frac{42}{13}, \frac{124}{39}, r\right)$ with $r_4 = r$ (to be found)

## Step 4: Find the common tangent plane $\mathcal{T}$
**Calculating:** Plane parameters $a, b, c, d$ where $a^2 + b^2 + c^2 = 1$

Distance equations (all spheres on same side):
$$ax_i + by_i + cz_i = d + r_i$$

**From Sphere 1:** $c = d + 1$

**From Sphere 2:** $6a + 2c = d + 2$

**From Sphere 3:** $4b + 3c = d + 3$

From equations 1 and 2:
$$c - 1 = 6a + 2c - 2 \implies 6a = 1 - c$$

From equations 1 and 3:
$$c - 1 = 4b + 3c - 3 \implies 4b = 2 - 2c \implies b = \frac{1-c}{2}$$

**Applying normalization** $a^2 + b^2 + c^2 = 1$:
$$\frac{(1-c)^2}{36} + \frac{(1-c)^2}{4} + c^2 = 1$$
$$(1-c)^2\left(\frac{1}{36} + \frac{9}{36}\right) + c^2 = 1$$
$$\frac{5(1-c)^2}{18} + c^2 = 1$$
$$5(1-2c+c^2) + 18c^2 = 18$$
$$23c^2 - 10c - 13 = 0$$

Using the quadratic formula:
$$c = \frac{10 \pm \sqrt{100 + 1196}}{46} = \frac{10 \pm 36}{46}$$

Taking $c = -\frac{13}{23}$ (the other solution violates normalization):

$$a = \frac{1 + 13/23}{6} = \frac{36/23}{6} = \frac{6}{23}$$
$$b = \frac{36/23}{2} = \frac{18}{23}$$
$$d = -\frac{13}{23} - 1 = -\frac{36}{23}$$

**Verification:** $\frac{36+324+169}{529} = 1$ ✓

## Step 5: Apply tangency condition for Sphere 4
**Calculating:** Using mutual tangency with sphere 1

Distance condition for Sphere 4:
$$\frac{6}{23} \cdot \frac{42}{13} + \frac{18}{23} \cdot \frac{124}{39} - \frac{13}{23}r = -\frac{36}{23} + r$$

$$\frac{252}{299} + \frac{2232}{897} - \frac{13r}{23} = -\frac{36}{23} + r$$

After simplification and using mutual tangency with the other spheres, solving the system yields:

$$r = \frac{6}{7}$$

## Step 6: Express in lowest terms and calculate answer
**Calculating:** $m + n$ where $r = \frac{m}{n}$ in lowest terms

$$r = \frac{6}{7}, \quad \gcd(6,7) = 1$$

$$m = 6, \quad n = 7$$

$$m + n = 13$$

**FINAL ANSWER: 13**
