# Given Quantities and Conditions

## Given Quantities
- A $3 \times 3$ grid (9 cells total)
- Four numbers available: $1, 2, 3, 4$

## Given Conditions
1. Each cell of the grid can be filled with some subset of $\{1, 2, 3, 4\}$ (this includes: none of the numbers, one number, two numbers, three numbers, or all four numbers)
2. **Each row must contain each of $1, 2, 3, 4$ exactly once** (across all cells in that row combined)
3. **Each column must contain each of $1, 2, 3, 4$ exactly once** (across all cells in that column combined)

## What Is Being Asked

Count the total number of ways Ashley can fill the $3 \times 3$ grid satisfying all the above conditions.

---

**Note:** The key insight is that while each cell can contain a *subset* of numbers, the constraints ensure that the four numbers must be distributed among the three cells in each row (and each column) such that each number appears in exactly one cell per row and exactly one cell per column. This is a generalization of the Latin rectangle problem where cells can contain multiple entries.
