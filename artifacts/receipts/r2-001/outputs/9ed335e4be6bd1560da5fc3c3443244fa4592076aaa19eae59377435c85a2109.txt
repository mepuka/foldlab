# Solution Plan

1. **Establish the outermost loop constraint**
   - Set $a_1 = 10$ and $b_1 = 10$ (the outermost loop must span the entire grid)
   - This loop contains $2(10) + 2(10) - 4 = 36$ cells
   - Remaining cells for inner loops: $100 - 36 = 64$ cells

2. **Determine valid range for subsequent loops**
   - For loop $i+1$ to fit inside loop $i$'s inner rectangle $(a_i - 2) \times (b_i - 2)$:
   - Require $a_{i+1} \le a_i - 2$ and $b_{i+1} \le b_i - 2$
   - Require $a_{i+1} \ge 2$ and $b_{i+1} \ge 2$ (minimum cell loop dimensions)

3. **Enumerate all valid nesting sequences**
   - Starting from $(a_1, b_1) = (10, 10)$, systematically generate all valid sequences $(a_2, b_2), (a_3, b_3), (a_4, b_4), (a_5, b_5)$ satisfying:
     - $2 \le a_i \le a_{i-1} - 2$ for $i = 2, 3, 4, 5$
     - $2 \le b_i \le b_{i-1} - 2$ for $i = 2, 3, 4, 5$

4. **Verify the partition condition**
   - For each candidate sequence, calculate the total cells:
     $$\sum_{i=1}^{5} (2a_i + 2b_i - 4) = 100$$
   - Keep only sequences where this sum equals exactly 100

5. **Count valid configurations**
   - Count the total number of sequences that pass both the nesting constraint and the partition constraint
