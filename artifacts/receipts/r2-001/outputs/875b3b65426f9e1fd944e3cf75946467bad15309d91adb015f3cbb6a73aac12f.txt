# Solution: Finding the Fourth Sphere

## Step 1: Set up coordinate system

Place the triangle in 3D:
- $A = (0, 0, 0)$
- $B = (6, 0, 0)$
- $C = (0, 4, 0)$
- Plane $\mathcal{P}$ is the $xy$-plane ($z = 0$)

✓ **Verified**: Triangle has sides $AB = 6$, $AC = 4$, $BC = \sqrt{36+16} = \sqrt{52} = 2\sqrt{13}$

## Step 2: Find centroid and point D

**Centroid of triangle:**
$$G = \left(\frac{0+6+0}{3}, \frac{0+0+4}{3}, 0\right) = \left(2, \frac{4}{3}, 0\right)$$

**Line BC parametrization:**
$$\ell(t) = (1-t)B + tC = (6(1-t), 4t, 0)$$

**Projection of G onto BC:**
$$\vec{BG} = (-4, \frac{4}{3}, 0), \quad \vec{BC} = (-6, 4, 0)$$

$$t = \frac{\vec{BG} \cdot \vec{BC}}{|\vec{BC}|^2} = \frac{24 + \frac{16}{3}}{52} = \frac{88/3}{52} = \frac{22}{39}$$

**Projection point:**
$$P = \left(6 - 6 \cdot \frac{22}{39}, 4 \cdot \frac{22}{39}, 0\right) = \left(\frac{102}{39}, \frac{88}{39}, 0\right) = \left(\frac{34}{13}, \frac{88}{39}, 0\right)$$

**Reflection D:**
$$D = 2P - G = \left(\frac{68}{13} - 2, \frac{176}{39} - \frac{52}{39}, 0\right) = \left(\frac{42}{13}, \frac{124}{39}, 0\right)$$

✓ **Verified by distance check**: $|D| = |G|$ (reflection property)

## Step 3: Identify sphere centers

- $O_1 = (0, 0, 1)$, radius $r_1 = 1$
- $O_2 = (6, 0, 2)$, radius $r_2 = 2$
- $O_3 = (0, 4, 3)$, radius $r_3 = 3$
- $O_4 = \left(\frac{42}{13}, \frac{124}{39}, r\right)$, radius $r_4 = r$

(Each sphere rests on plane $\mathcal{P}$, so center height = radius)
