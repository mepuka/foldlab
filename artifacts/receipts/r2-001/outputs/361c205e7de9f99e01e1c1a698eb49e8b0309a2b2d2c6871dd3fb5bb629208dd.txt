# Solving the Hamiltonian Path Problem on a 3×10 Grid

## Step 1: Recognize the Problem Type

**Problem Setup:**
- Grid: 3 rows × 10 columns = 30 cells total
- Start: A at position (row 2, col 2) — using 1-indexed coordinates
- End: B at position (row 2, col 9)
- Goal: Count all Hamiltonian paths from A to B visiting all 30 cells exactly once

This is a Hamiltonian path enumeration problem on a constrained grid. While computationally intensive, backtracking is appropriate for this size.

---

## Step 2: Implement Backtracking Algorithm

I'll implement a depth-first search (DFS) with backtracking:

```python
def count_hamiltonian_paths(rows=3, cols=10, start=(2, 2), end=(2, 9)):
    """
    Count Hamiltonian paths from start to end on a 3x10 grid.
    Grid coordinates: (row, col) where row ∈ [1,3], col ∈ [1,10]
    """
    total_cells = rows * cols
    visited = [[False] * (cols + 1) for _ in range(rows + 1)]
    path_count = [0]  # Use list to allow modification in nested function
    
    def dfs(row, col, visited_count):
        """
        Recursive DFS function.
        row, col: current position
        visited_count: number of cells visited so far
        """
        # Termination condition: found a complete Hamiltonian path
        if visited_count == total_cells and (row, col) == end:
            path_count[0] += 1
            return
        
        # Prune: if we're at the end position before visiting all cells, backtrack
        if (row, col) == end and visited_count < total_cells:
            return
        
        # Try all 4 directions: up, down, left, right
        directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        
        for dr, dc in directions:
            new_row, new_col = row + dr, col + dc
            
            # Check bounds and visited status
            if (1 <= new_row <= rows and 
                1 <= new_col <= cols and 
                not visited[new_row][new_col]):
                
                # Mark as visited
                visited[new_row][new_col] = True
                
                # Recurse
                dfs(new_row, new_col, visited_count + 1)
                
                # Backtrack
                visited[new_row][new_col] = False
    
    # Initialize: mark starting cell as visited
    visited[start[0]][start[1]] = True
    
    # Begin search
    dfs(start[0], start[1], 1)
    
    return path_count[0]
```

---

## Step 3: Define Movement Rules

**Movement Validation:**
- Current position: (row, col)
- Candidate next position: (row + dr, col + dc)
- Valid if:
  - 1 ≤ new_row ≤ 3
  - 1 ≤ new_col ≤ 10
  - Cell not yet visited

**Four directions checked:** Up (-1,0), Down (+1,0), Left (0,-1), Right (0,+1)

---

## Step 4: Termination Condition

A valid solution occurs when:
1. **visited_count == 30**: All cells visited
2. **(row, col) == (2, 9)**: Currently at endpoint B

Early pruning: If we reach B before visiting all 30 cells, backtrack immediately.
