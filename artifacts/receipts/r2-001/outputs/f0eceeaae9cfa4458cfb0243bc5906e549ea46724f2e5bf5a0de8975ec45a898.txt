# Solution: Finding BC in Rectangle ABCD

## Step 1: Set up a coordinate system

I'll place the rectangle in a coordinate system:
- $A = (0, 0)$ at the origin
- $B = (1, 0)$ (since $AB = 1$)
- $D = (0, h)$ where $h = BC$ (unknown)
- $C = (1, h)$

This gives us a rectangle with width 1 and height $h$.

---

## Step 2: Express positions of X and Y using parameters

- $X = (1, x)$ for some $0 \leq x \leq h$ (point on side $\overline{BC}$)
- $Y = (0, y)$ for some $0 \leq y \leq h$ (point on side $\overline{AD}$)

---

## Step 3: Apply the length ratio conditions

**From $AX = k$:**
$$AX = \sqrt{(1-0)^2 + (x-0)^2} = \sqrt{1 + x^2} = k$$
$$\boxed{1 + x^2 = k^2} \quad \text{...(1)}$$

**From $XY = 2k$:**
$$XY = \sqrt{(0-1)^2 + (y-x)^2} = \sqrt{1 + (x-y)^2} = 2k$$
$$\boxed{1 + (x-y)^2 = 4k^2} \quad \text{...(2)}$$

**From $YC = k$:**
$$YC = \sqrt{(1-0)^2 + (h-y)^2} = \sqrt{1 + (h-y)^2} = k$$
$$\boxed{1 + (h-y)^2 = k^2} \quad \text{...(3)}$$

---

## Step 4: Apply the perpendicularity conditions

**From $\angle AXY = 90°$:**
$$\vec{XA} = (-1, -x), \quad \vec{XY} = (-1, y-x)$$
$$\vec{XA} \cdot \vec{XY} = (-1)(-1) + (-x)(y-x) = 1 - xy + x^2 = 0$$
$$\boxed{x^2 - xy + 1 = 0} \quad \text{...(4)}$$

**From $\angle XYC = 90°$:**
$$\vec{YX} = (1, x-y), \quad \vec{YC} = (1, h-y)$$
$$\vec{YX} \cdot \vec{YC} = (1)(1) + (x-y)(h-y) = 0$$
$$\boxed{(x-y)(h-y) = -1} \quad \text{...(5)}$$

---

## Step 5: Solve the system of equations

**From equations (1) and (3):**
$$1 + x^2 = 1 + (h-y)^2 \implies x^2 = (h-y)^2$$

Taking the positive root: $\boxed{y = h - x}$ ...(6)

**Substitute (6) into (4):**
$$x^2 - x(h-x) + 1 = 0$$
$$2x^2 - xh + 1 = 0$$
$$\boxed{xh = 2x^2 + 1} \quad \text{...(9)}$$

**Substitute (6) into (2):**
$$1 + (x-(h-x))^2 = 4k^2$$
$$1 + (2x-h)^2 = 4k^2 \quad \text{...(7)}$$

**Substitute $k^2 = 1 + x^2$ from (1) into (7):**
$$1 + (2x-h)^2 = 4(1 + x^2)$$
$$(2x-h)^2 = 3 + 4x^2$$
$$4x^2 - 4xh + h^2 = 3 + 4x^2$$
$$\boxed{h^2 - 4xh = 3} \quad \text{...(10)}$$

**Substitute (9) into (10):**
$$h^2 - 4(2x^2 + 1) = 3$$
$$h^2 = 8x^2 + 7 \quad \text{...(11)}$$

**From (9): $h = \frac{2x^2 + 1}{x}$. Substitute into (11):**
$$\left(\frac{2x^2 + 1}{x}\right)^2 = 8x^2 + 7$$
$$(2x^2 + 1)^2 = x^2(8x^2 + 7)$$
$$4x^4 + 4x^2 + 1 = 8x^4 + 7x^2$$
$$4x^4 + 3x^2 - 1 = 0$$

**Using the quadratic formula with $u = x^2$:**
$$u = \frac{-3 \pm \sqrt{9 + 16}}{8} = \frac{-3 \pm 5}{8}$$

Taking the positive solution: $x^2 = \frac{1}{4}$, so $x = \frac{1}{2}$

**From equation (11):**
$$h^2 = 8 \cdot \frac{1}{4} + 7 = 2 + 7 = 9$$
$$\boxed{h = 3}$$

---

## Step 6: Verify the solution

With $x = \frac{1}{2}$, $y = \frac{5}{2}$, $h = 3$, and $k = \frac{\sqrt{5}}{2}$:

| Condition | Verification |
|-----------|--------------|
| (1): $1 + x^2 = k^2$ | $1 + \frac{1}{4} = \frac{5}{4}$ ✓ |
| (2): $1 + (x-y)^2 = 4k^2$ | $1 + 4 = 5 = 4 \cdot \frac{5}{4}$ ✓ |
| (3): $1 + (h-y)^2 = k^2$ | $1 + \frac{1}{4} = \frac{5}{4}$ ✓ |
| (4): $x^2 - xy + 1 = 0$ | $\frac{1}{4} - \frac{5}{4} + 1 = 0$ ✓ |
| (5): $(x-y)(h-y) = -1$ | $(-2)(\frac{1}{2}) = -1$ ✓ |

All conditions are satisfied. Points lie within segments: $0 < x < h$ and $0 < y < h$ ✓

**FINAL ANSWER: 3**
