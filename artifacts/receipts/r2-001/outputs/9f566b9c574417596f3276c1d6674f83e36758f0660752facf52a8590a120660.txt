# Solution: Expected Number of Cells Traversed

## What We Are Calculating

The expected number of cells visited on a randomly selected path from the bottom-left corner $(0,0)$ to the top-right corner $(5,5)$ on a 6×6 grid.

## Complete Calculation

### Step 1: Establish the Baseline

Total paths with no restrictions:
- Required: 5 moves right, 5 moves up = 10 total moves
- Total paths: $\binom{10}{5} = 252$

**Key observation:** Every path visits exactly 11 cells (including start and end).

### Step 2: Count Paths Through Each Cell

For each cell $(x,y)$ where $0 \leq x, y \leq 5$:

$$P(x,y) = \binom{x+y}{x} \times \binom{(5-x)+(5-y)}{5-x} = \binom{x+y}{x}\binom{10-x-y}{5-x}$$

### Step 3: Sum Over All Cells

The expected number of cells is:

$$E = \frac{1}{252}\sum_{x=0}^{5}\sum_{y=0}^{5} \binom{x+y}{x}\binom{10-x-y}{5-x}$$

### Step 4: Exploit the Diagonal Structure

Group cells by diagonal $k = x+y$:

$$\sum_{x=0}^{5}\sum_{y=0}^{5} \binom{x+y}{x}\binom{10-x-y}{5-x} = \sum_{k=0}^{10} \sum_{\substack{x: \\ x+y=k \\ 0 \leq x,y \leq 5}} \binom{k}{x}\binom{10-k}{5-x}$$

### Step 5: Apply Vandermonde's Identity

For each diagonal $k$, the sum equals:
$$\sum_{x} \binom{k}{x}\binom{10-k}{5-x} = \binom{10}{5} = 252$$

**Justification:** By Vandermonde's identity, choosing 5 items from 10 total items (where $k$ come from one group and $10-k$ from another) yields $\binom{10}{5}$.

### Step 6: Calculate Total

Number of diagonals: $k = 0, 1, 2, \ldots, 10$ → **11 diagonals**

$$\sum_{x=0}^{5}\sum_{y=0}^{5} \binom{x+y}{x}\binom{10-x-y}{5-x} = 11 \times 252 = 2772$$

### Step 7: Compute Expected Value

$$E = \frac{2772}{252} = 11$$

## Verification

**Logical Check:** Each of 252 paths visits exactly 11 cells. The sum of all path-cell pairs is $252 \times 11 = 2772$. The expected number per path is $\frac{2772}{252} = 11$. ✓

**Alternative Verification:** On a 6×6 grid, moving from $(0,0)$ to $(5,5)$ requires:
- Starting position: 1 cell
- 10 moves through cells: 10 additional cells
- Total cells visited: 11 ✓

This is independent of which path is taken, confirming the expected value equals the deterministic value.

**Reasonableness Check:** The answer must be between 1 (impossible—requires moving) and 36 (all cells). 11 is reasonable for a shortest path plus some variation. ✓

---

**FINAL ANSWER: 11**
