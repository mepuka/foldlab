# Detailed Solution: Finding Area of △BCY

## Step 1: Set up coordinate system ✓
- Place square ABCD with:
  - A = (0, 0)
  - B = (12, 0)
  - C = (12, 12)
  - D = (0, 12)

This forms a 12 × 12 square.

## Step 2: Locate vertices W and X ✓
- W on $\overline{AD}$ with AW = 4: **W = (0, 4)** ✓
- X on $\overline{AB}$ with AX = 5: **X = (5, 0)** ✓

## Step 3: Verify the side length of square WXYZ ✓

$$|WX| = \sqrt{(5-0)^2 + (0-4)^2} = \sqrt{25 + 16} = \sqrt{41}$$

**Verified:** The side length is $\sqrt{41}$ (not 3).

## Step 4: Find coordinates of Y and Z ✓

**Vector from W to X:**
$$\vec{WX} = (5, -4)$$

**Rotate 90° counterclockwise** (using $(a,b) \to (-b,a)$):
$$\vec{WX} \text{ rotated} = (4, 5)$$

**Calculate Z and Y:**
$$Z = W + (4, 5) = (0, 4) + (4, 5) = (4, 9)$$
$$Y = X + (4, 5) = (5, 0) + (4, 5) = (9, 5)$$

**Verification that WXYZ is a square:**
- $|WX| = \sqrt{41}$ ✓
- $|XY| = \sqrt{(9-5)^2 + (5-0)^2} = \sqrt{16+25} = \sqrt{41}$ ✓
- $|YZ| = \sqrt{(4-9)^2 + (9-5)^2} = \sqrt{25+16} = \sqrt{41}$ ✓
- $|ZW| = \sqrt{(0-4)^2 + (4-9)^2} = \sqrt{16+25} = \sqrt{41}$ ✓
- $\vec{WX} \cdot \vec{XY} = (5)(4) + (-4)(5) = 20 - 20 = 0$ ✓ (perpendicular)

## Step 5: Calculate area of △BCY ✓

**Using the coordinate formula:**
$$\text{Area} = \frac{1}{2}|x_B(y_C - y_Y) + x_C(y_Y - y_B) + x_Y(y_B - y_C)|$$

Substituting B = (12, 0), C = (12, 12), Y = (9, 5):
$$= \frac{1}{2}|12(12-5) + 12(5-0) + 9(0-12)|$$
$$= \frac{1}{2}|12(7) + 12(5) + 9(-12)|$$
$$= \frac{1}{2}|84 + 60 - 108|$$
$$= \frac{1}{2}|36|$$
$$= 18$$

**Verification using base-height method:**
- Points B(12, 0) and C(12, 12) both lie on the vertical line $x = 12$
- Base BC has length: $|12 - 0| = 12$
- Height = perpendicular distance from Y(9, 5) to line $x = 12$: $|9 - 12| = 3$
- Area = $\frac{1}{2}(12)(3) = 18$ ✓

Both methods confirm the same result.

---

**FINAL ANSWER: 18**
