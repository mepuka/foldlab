# Solution: Counting Ordered Pairs $(a,b) \in S \times S$ where $a+b \in S$

## Step 1: Characterize Set $S$

Since $143 = 11 \times 13$, the set $S$ consists of all integers in $[1, 143)$ coprime to 143.

**Calculate $|S|$:**
$$|S| = \phi(143) = \phi(11 \times 13) = \phi(11) \cdot \phi(13) = 10 \times 12 = 120$$

## Step 2: Identify Valid Constraint

For pairs $(a,b) \in S \times S$ with $a+b \in S$:
- We need $a, b \geq 1$ and $a+b < 143$ (so $a+b$ can be in $S$)
- We need $\gcd(a+b, 143) = 1$

**Check the range:** Since $a, b \in S$ means $a, b \geq 1$, we have $a+b \geq 2$. Since $a, b < 143$, we have $a+b < 286$. However, requiring $a+b \in S$ automatically constrains $a+b < 143$ (since $S \subset [1,143)$). ✓

## Step 3: Count Using CRT Structure

By the Chinese Remainder Theorem, since $143 = 11 \times 13$:
$$a \in S \iff a \not\equiv 0 \pmod{11} \text{ and } a \not\equiv 0 \pmod{13}$$

For a **fixed $a \in S$**, we count $b \in S$ such that $a+b \in S$.

This requires:
- $\gcd(b, 143) = 1$ 
- $\gcd(a+b, 143) = 1$

**Rewrite the conditions modulo 11 and 13:**
- $b \not\equiv 0 \pmod{11}$ and $a+b \not\equiv 0 \pmod{11}$ ⟹ $b \not\equiv 0$ and $b \not\equiv -a \pmod{11}$
- $b \not\equiv 0 \pmod{13}$ and $a+b \not\equiv 0 \pmod{13}$ ⟹ $b \not\equiv 0$ and $b \not\equiv -a \pmod{13}$

## Step 4: Count Valid Values of $b$ Modulo 11 and 13

**Modulo 11:**
- Total residues: 11
- Exclude $b \equiv 0$: 1 element
- Exclude $b \equiv -a$: 1 element (different from 0 since $a \not\equiv 0 \pmod{11}$)
- Valid residues: $11 - 2 = 9$

**Modulo 13:**
- Total residues: 13
- Exclude $b \equiv 0$: 1 element
- Exclude $b \equiv -a$: 1 element (different from 0 since $a \not\equiv 0 \pmod{13}$)
- Valid residues: $13 - 2 = 11$

## Step 5: Apply CRT to Count Valid $b$ Values

By CRT, the number of residue classes $b \pmod{143}$ satisfying both modular conditions is:
$$9 \times 11 = 99$$

Since each residue class modulo 143 contains exactly one element in $[1, 143)$, there are exactly **99 valid values of $b \in S$** for each fixed $a \in S$.

**Verification by substitution:** Pick $a = 1 \in S$. We need $b \in S$ with $1+b \in S$:
- Exclude $b \equiv 0 \pmod{11}$ and $b \equiv -1 \equiv 10 \pmod{11}$: 9 choices
- Exclude $b \equiv 0 \pmod{13}$ and $b \equiv -1 \equiv 12 \pmod{13}$: 11 choices
- Combined: $9 \times 11 = 99$ ✓

## Step 6: Calculate Total Count

Since there are 120 choices for $a \in S$, and for each choice of $a$ there are exactly 99 valid choices for $b \in S$:

$$\text{Total} = 120 \times 99$$

**Calculate:**
$$120 \times 99 = 120 \times (100-1) = 12000 - 120 = 11880$$

**Double-check:** $120 \times 99 = 12 \times 10 \times 99 = 12 \times 990 = 11880$ ✓

FINAL ANSWER: **11880**
