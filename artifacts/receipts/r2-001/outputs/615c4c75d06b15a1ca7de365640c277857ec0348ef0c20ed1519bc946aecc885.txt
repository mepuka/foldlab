## Step 1: Set Up the Perimeter Equation

Let the five sides be $a, b, c, d, e$ with perimeter $P = a + b + c + d + e$.

We need: $P^2 = (a + b + c + d + e)^2$

Given: $a^2 + b^2 + c^2 + d^2 + e^2 = 308$

## Step 2: Expand $P^2$

$$P^2 = a^2 + b^2 + c^2 + d^2 + e^2 + 2\sum_{i<j} a_i a_j$$

$$P^2 = 308 + 2S$$

where $S = ab + ac + ad + ae + bc + bd + be + cd + ce + de$ (sum of all 10 pairwise products).

## Step 3: Apply Law of Cosines to Diagonals

For an equiangular pentagon, each interior angle is $\frac{(5-2) \cdot 180°}{5} = 108°$.

The 5 diagonals connect non-adjacent vertices. Using the law of cosines with $\cos(108°) = -\frac{1+\sqrt{5}}{4}$:

- $d_3^2 = c^2 + d^2 + 2cd \cdot \frac{1+\sqrt{5}}{4}$
- $d_4^2 = d^2 + e^2 + 2de \cdot \frac{1+\sqrt{5}}{4}$
- $d_5^2 = e^2 + a^2 + 2ea \cdot \frac{1+\sqrt{5}}{4}$

## Step 4: Sum the Diagonal Squares
