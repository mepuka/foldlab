# Step-by-Step Solution

## Step 1: Set up coordinates and variables

Place points $A, B, C, D$ on a horizontal line in order from left to right.

Let $AB = x$ and $CD = y$

Given: $BC = 10$ and $AD = 39$

Since the points are collinear in order:
$$AD = AB + BC + CD$$
$$39 = x + 10 + y$$
$$x + y = 29 \quad \text{...(Equation 1)}$$

## Step 2: Establish a coordinate system

Place:
- $B$ at the origin: $B = (0, 0)$
- $C$ on the positive x-axis: $C = (10, 0)$
- $A$ to the left: $A = (-x, 0)$
- $D$ to the right: $D = (10 + y, 0)$

## Step 3: Locate point E from the equilateral triangle

Triangle $BEC$ is equilateral with side length 10, so:
- $BE = EC = 10$
- All angles equal $60°$

The third vertex of an equilateral triangle with base $BC$ on the x-axis is:
$$E = (5, 5\sqrt{3})$$

**Verification:** 
- $BE = \sqrt{5^2 + (5\sqrt{3})^2} = \sqrt{25 + 75} = \sqrt{100} = 10$ ✓
- $EC = \sqrt{(10-5)^2 + (5\sqrt{3})^2} = \sqrt{25 + 75} = 10$ ✓

## Step 4: Apply the angle condition $\angle AED = 120°$

Vectors from $E$:
$$\vec{EA} = (-x, 0) - (5, 5\sqrt{3}) = (-x-5, -5\sqrt{3})$$
$$\vec{ED} = (10+y, 0) - (5, 5\sqrt{3}) = (5+y, -5\sqrt{3})$$

Using $\cos(120°) = -\frac{1}{2}$:

**Dot product:**
$$\vec{EA} \cdot \vec{ED} = (-x-5)(5+y) + 75$$
$$= -5x - xy - 25 - 5y + 75 = -xy - 5(x+y) + 50$$

Substituting $x + y = 29$:
$$\vec{EA} \cdot \vec{ED} = -xy - 145 + 50 = -xy - 95$$

**Magnitudes:**
$$|\vec{EA}|^2 = (x+5)^2 + 75 = x^2 + 10x + 100$$
$$|\vec{ED}|^2 = (5+y)^2 + 75 = y^2 + 10y + 100$$

**Angle equation:**
$$-\frac{1}{2} = \frac{-xy - 95}{\sqrt{x^2 + 10x + 100}\sqrt{y^2 + 10y + 100}}$$

$$\sqrt{x^2 + 10x + 100}\sqrt{y^2 + 10y + 100} = 2(xy + 95)$$

Squaring both sides:
$$(x^2 + 10x + 100)(y^2 + 10y + 100) = 4(xy + 95)^2$$

## Step 5: Expand and simplify

**Left side:**
$$x^2y^2 + 10xy(x+y) + 100(x^2 + y^2) + 1000(x+y) + 10000$$

**Right side:**
$$4(x^2y^2 + 190xy + 9025) = 4x^2y^2 + 760xy + 36100$$

Setting them equal and substituting $x + y = 29$:
$$x^2y^2 + 290xy + 100(x^2 + y^2) + 29000 + 10000 = 4x^2y^2 + 760xy + 36100$$

Since $x^2 + y^2 = (x+y)^2 - 2xy = 841 - 2xy$:
$$x^2y^2 + 290xy + 100(841 - 2xy) + 39000 = 4x^2y^2 + 760xy + 36100$$

$$x^2y^2 + 290xy + 84100 - 200xy + 39000 = 4x^2y^2 + 760xy + 36100$$

$$x^2y^2 + 90xy + 123100 = 4x^2y^2 + 760xy + 36100$$

$$0 = 3x^2y^2 + 670xy - 87000$$

## Step 6: Solve for xy

Let $p = xy$:
$$3p^2 + 670p - 87000 = 0$$

Using the quadratic formula or factoring:
$$3p^2 + 670p - 87000 = (3p - 540)(p + 50) = 0$$

This gives $p = 180$ or $p = -50$

Since $x, y > 0$, we have $xy = 180$.

## Step 7: Find x and y

With $x + y = 29$ and $xy = 180$:
$$t^2 - 29t + 180 = 0$$
$$(t - 20)(t - 9) = 0$$

So $x = 20, y = 9$ or $x = 9, y = 20$.

## Step 8: Calculate the answer

$$|AB - CD| = |x - y| = |20 - 9| = 11$$

**Verification:** $20 + 9 = 29$ ✓, $20 \times 9 = 180$ ✓

FINAL ANSWER: **11**
