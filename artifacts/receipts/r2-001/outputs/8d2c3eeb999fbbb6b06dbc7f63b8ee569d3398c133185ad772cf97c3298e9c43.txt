# Step-by-Step Solution

## Step 1: Establish the outermost loop constraint

Given $(a_1, b_1) = (10, 10)$:

**Cells in loop 1:** 
$$2a_1 + 2b_1 - 4 = 2(10) + 2(10) - 4 = 20 + 20 - 4 = 36 \text{ cells}$$

**Remaining cells:** $100 - 36 = 64$ cells

✓ Verified

## Step 2: Determine valid range for subsequent loops

For loop $i+1$ to nest inside loop $i$:
- $a_{i+1} \le a_i - 2$ and $b_{i+1} \le b_i - 2$
- $a_{i+1} \ge 2$ and $b_{i+1} \ge 2$ (minimum $2 \times 2$ loop dimensions)

## Step 3: Establish the sum constraint

For loops 2-5 to partition the remaining 64 cells:
$$\sum_{i=2}^{5} (2a_i + 2b_i - 4) = 64$$

Let $S_a = \sum_{i=2}^{5} a_i$ and $S_b = \sum_{i=2}^{5} b_i$

Then:
$$2S_a + 2S_b - 4(4) = 64$$
$$2S_a + 2S_b - 16 = 64$$
$$2(S_a + S_b) = 80$$
$$S_a + S_b = 40$$

## Step 4: Determine the maximum possible sums

Given the strict nesting constraints:
- Loop 2: $a_2 \le 10 - 2 = 8$
- Loop 3: $a_3 \le a_2 - 2 \le 8 - 2 = 6$
- Loop 4: $a_4 \le a_3 - 2 \le 6 - 2 = 4$
- Loop 5: $a_5 \le a_4 - 2 \le 4 - 2 = 2$

Similarly for $b_i$.

**Maximum possible:**
$$S_a^{\max} = 8 + 6 + 4 + 2 = 20$$
$$S_b^{\max} = 8 + 6 + 4 + 2 = 20$$

Therefore: $S_a^{\max} + S_b^{\max} = 40$

Since we need $S_a + S_b = 40$ and the maximum is 40, we must have:
$$S_a = 20 \text{ and } S_b = 20$$

This forces:
$$a_2 = 8, \quad a_3 = 6, \quad a_4 = 4, \quad a_5 = 2$$
$$b_2 = 8, \quad b_3 = 6, \quad b_4 = 4, \quad b_5 = 2$$

## Step 5: Verify this is the unique solution

**Nesting constraint check:**
- Loop 2 $(8, 8)$ in $(10-2) \times (10-2) = (8 \times 8)$ ✓
- Loop 3 $(6, 6)$ in $(8-2) \times (8-2) = (6 \times 6)$ ✓
- Loop 4 $(4, 4)$ in $(6-2) \times (6-2) = (4 \times 4)$ ✓
- Loop 5 $(2, 2)$ in $(4-2) \times (4-2) = (2 \times 2)$ ✓

**Cell count verification:**
- Loop 1: $2(10) + 2(10) - 4 = 36$
- Loop 2: $2(8) + 2(8) - 4 = 28$
- Loop 3: $2(6) + 2(6) - 4 = 20$
- Loop 4: $2(4) + 2(4) - 4 = 12$
- Loop 5: $2(2) + 2(2) - 4 = 4$

**Total:** $36 + 28 + 20 + 12 + 4 = 100$ ✓
