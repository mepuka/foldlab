# Complete Solution: Minimum Operations to Make All Numbers Equal

## 1. Establish the Lower Bound (Necessity)

### Step 1.1: Prove we need at least 2025 operations

**Initial Setup:**
- We start with 2026 distinct numbers on the blackboard
- Goal: make all numbers equal (1 distinct value remaining)

**Key Observation:**
- Each operation removes exactly one number and adds exactly one number
- In the best case, each operation reduces the count of distinct values by exactly 1
- This happens when the new value |max - min| is not already present

**Calculation:**
$$\text{Distinct values: } 2026 \to 2025 \to 2024 \to \cdots \to 2 \to 1$$
$$\text{Number of reductions needed: } 2026 - 1 = 2025$$

**Therefore:** $\boxed{\text{minimum} \geq 2025 \text{ operations}}$

### Step 1.2: Verify the bound is tight

This bound is achievable if we can construct a strategy where each operation strictly decreases the number of distinct values by exactly 1.

---

## 2. Construct an Explicit Strategy (Sufficiency)

### Step 2.1: Euclidean-Inspired Algorithm

**Initial Configuration:** $S_0 = \{1, 2, 3, \ldots, 2026\}$

**Strategy:** In each operation $k$:
- Identify $\max(S_{k-1}) = M$ and $\min(S_{k-1}) = m$
- Replace $M$ with $|M - m| = M - m$
- This removes the largest element and adds a smaller value

### Step 2.2: Detailed Execution

| Operation | Blackboard Set | Action | Distinct Values |
|-----------|---|---|---|
| 0 | {1, 2, 3, ..., 2026} | Start | 2026 |
| 1 | {1, 2, 3, ..., 2025} | Replace 2026 with \|2026-1\|=2025 | 2025 |
| 2 | {1, 2, 3, ..., 2024} | Replace 2025 with \|2025-1\|=2024 | 2024 |
| 3 | {1, 2, 3, ..., 2023} | Replace 2024 with \|2024-1\|=2023 | 2023 |
| ⋮ | ⋮ | ⋮ | ⋮ |
| 2024 | {1, 2} | Replace 3 with \|3-1\|=2 | 2 |
| 2025 | {1, 1, ..., 1} | Replace 2 with \|2-1\|=1 | 1 |

### Step 2.3: Why this strategy works

**Key Property:** At each step, the value $|M - m|$ is strictly smaller than $M$:
- When $M > m$: $|M - m| = M - m < M$
- The new value either equals an existing value or is genuinely new and smaller
- Since we're decreasing from 2026 toward 1, and we always have $m \geq 1$, we never create "new" distinct values
- The new value $M - m$ either:
  - Equals some value in $\{1, 2, \ldots, m\}$ (reduces distinct count), or
  - Equals an existing copy of $M - m$ (reduces distinct count)

**Convergence:** Following this algorithm, all numbers eventually become equal to 1.

---

## 3. Verify the Strategy Achieves Exactly 2025 Operations

### Step 3.1: Count operations

Using the algorithm above:
- Start: 2026 distinct numbers
- Each of the 2025 operations reduces distinct values by exactly 1
- After operation $k$: $2026 - k$ distinct values remain

$$\text{After operation 2025: } 2026 - 2025 = 1 \text{ distinct value}$$

### Step 3.2: Confirm termination

After 2025 operations:
- **Final state:** All 2026 numbers equal 1
- **Why no more operations possible?** When all numbers are equal: $\max = \min = 1$
  - Therefore $|M - m| = 0$, which doesn't change the configuration
  - The problem condition "all numbers are equal" is satisfied

---

## 4. Final Answer

$$\boxed{\text{The minimum number of operations is } \mathbf{2025}}$$

**Justification:**
- **Lower bound:** Reducing from 2026 to 1 distinct values requires at least 2025 steps
- **Upper bound:** Explicit algorithm (Euclidean-style) achieves this in exactly 2025 operations  
- **Tightness:** Both bounds match

**Answer: $n = \boxed{2025}$**
