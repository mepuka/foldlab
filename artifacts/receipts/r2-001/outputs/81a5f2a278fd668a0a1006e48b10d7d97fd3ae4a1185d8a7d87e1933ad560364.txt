# Solution: HATER + HEART = EARTH

## Step 1: Simplify the Algebraic Constraint

**Expand both sides:**

Left side (HATER + HEART):
$$(10000H + 1000A + 100T + 10E + R) + (10000H + 1000E + 100A + 10R + T)$$
$$= 20000H + 1100A + 101T + 1010E + 11R$$

Right side (EARTH):
$$10000E + 1000A + 100R + 10T + H$$

**Set up equation:**
$$20000H + 1100A + 101T + 1010E + 11R = 10000E + 1000A + 100R + 10T + H$$

**Rearrange to standard form:**
$$20000H - H + 1100A - 1000A + 101T - 10T + 1010E - 10000E + 11R - 100R = 0$$

$$19999H + 100A + 91T - 8990E - 89R = 0$$

## Step 2: Analyze the Simplified Equation

Rearranging to solve for H:
$$19999H = 8990E + 89R - 100A - 91T$$

$$H = \frac{8990E + 89R - 100A - 91T}{19999}$$

For H to be an integer, the numerator must be divisible by 19999.

**Key observation:** Since $19999 \approx 20000$ is large and H must be a single digit (1-9), the numerator must be quite small relative to the coefficient of H.

Let me rearrange differently:
$$19999H + 89R = 8990E + 100A + 91T$$

## Step 3: Apply Leading Digit Constraints

- $H \geq 1$ (leading digit of HATER and HEART)
- $E \geq 1$ (leading digit of EARTH)
- All variables: $0 \leq A, T, R \leq 9$

For the equation to balance with $H \geq 1$:
$$19999H \geq 19999$$

This means: $8990E + 100A + 91T \geq 19999 + 89R$

With $E \leq 9$: $8990(9) = 80910$, which is sufficient.
