# Detailed Solution

## Step 1: Structure of the Absolute Value Equation

The equation $|x^2 + ax + b| = c$ splits into two cases:
- Case A: $x^2 + ax + b = c$
- Case B: $x^2 + ax + b = -c$

The total number of integer solutions is the sum of solutions from both quadratics.

## Step 2: Condition for Exactly 3 Integer Solutions

To get exactly 3 solutions total, we need one quadratic to contribute 2 solutions and the other to contribute 1 solution.

A quadratic has exactly 1 solution when its discriminant equals 0 (double root).
A quadratic has exactly 2 solutions when its discriminant is positive.

## Step 3: Set up $p(x) = -c$ with a Double Root

Let $p(x) = x^2 + ax + b$. If $p(x) = -c$ has a double root at integer $x = x_0$:

$$p(x) + c = (x - x_0)^2$$
$$p(x) = (x - x_0)^2 - c$$

This gives us:
- $a = -2x_0$ and $b = x_0^2 - c$
- The double root at $x_0$ satisfies $p(x_0) = 0 - c = -c$ ✓

## Step 4: Condition for $p(x) = c$ to Have Exactly 2 Integer Solutions

Setting $p(x) = c$:
$$(x - x_0)^2 - c = c$$
$$(x - x_0)^2 = 2c$$

The solutions are: $x = x_0 \pm \sqrt{2c}$

**For both to be integers:** $\sqrt{2c}$ must be an integer.

Let $\sqrt{2c} = k$ (positive integer), so $2c = k^2$, giving $c = \frac{k^2}{2}$

**For $c$ to be an integer:** $k$ must be even.

Setting $k = 2m$ where $m$ is a positive integer:
$$c = \frac{(2m)^2}{2} = \frac{4m^2}{2} = 2m^2$$

## Step 5: Apply the Constraint $c \le 2025$

$$2m^2 \le 2025$$
$$m^2 \le 1012.5$$

Checking boundaries:
- $31^2 = 961 < 1012.5$ ✓
- $32^2 = 1024 > 1012.5$ ✗

Therefore: $m \in \{1, 2, 3, \ldots, 31\}$

## Step 6: Count the Values

Each value of $m$ produces a distinct value of $c = 2m^2$:

| $m$ | 1 | 2 | 3 | ... | 31 |
|-----|---|---|---|-----|-----|
| $c = 2m^2$ | 2 | 8 | 18 | ... | 1922 |

Since $2(31)^2 = 1922 \le 2025$ and $2(32)^2 = 2048 > 2025$, all 31 values are valid.
