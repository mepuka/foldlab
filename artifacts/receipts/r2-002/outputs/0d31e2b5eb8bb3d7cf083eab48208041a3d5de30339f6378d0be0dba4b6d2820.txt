# Solution: Maximum Area of Triangle EUV

## Step 1: Set up a coordinate system

I'll place triangle $SUN$ with known area 24:
- $U = (0, 0)$
- $N = (8, 0)$
- $S = (0, 6)$

**Verification:** Area$(SUN) = \frac{1}{2} \cdot 8 \cdot 6 = 24$ ✓

## Step 2: Apply the parallel conditions

Calculate the direction vectors:
- $\overrightarrow{SU} = U - S = (0, -6)$
- $\overrightarrow{UN} = N - U = (8, 0)$

**From condition** $NV \parallel SU$:
$$V = N + t_1 \cdot \overrightarrow{SU} = (8, 0) + t_1(0, -6) = (8, -6t_1)$$

**From condition** $SE \parallel UN$:
$$E = S + t_2 \cdot \overrightarrow{UN} = (0, 6) + t_2(8, 0) = (8t_2, 6)$$

## Step 3: Express pentagon area as a function of parameters

Using the shoelace formula for pentagon $VENUS$ with vertices $V, E, N, U, S$:

$$2 \cdot \text{Area} = \sum_{i} (x_i y_{i+1} - x_{i+1} y_i)$$

Computing term by term:
- $V$ to $E$: $8(6) - 8t_2(-6t_1) = 48 + 48t_1t_2$
- $E$ to $N$: $8t_2(0) - 8(6) = -48$
- $N$ to $U$: $8(0) - 0(0) = 0$
- $U$ to $S$: $0(6) - 0(0) = 0$
- $S$ to $V$: $0(-6t_1) - 8(6) = -48$

$$2 \cdot \text{Area}(VENUS) = 48 + 48t_1t_2 - 48 + 0 + 0 - 48 = 48t_1t_2 - 48$$

$$\text{Area}(VENUS) = 24t_1t_2 - 24$$

**Constraint from given area:**
$$24t_1t_2 - 24 = 84$$
$$24t_1t_2 = 108$$
$$t_1t_2 = 4.5$$

(Note: This assumes counterclockwise orientation with $t_1t_2 > 1$ for convexity)

## Step 4: Express triangle EUV area as a function of parameters

For triangle $EUV$ with vertices $E = (8t_2, 6)$, $U = (0, 0)$, $V = (8, -6t_1)$:

$$\text{Area}(EUV) = \frac{1}{2}|x_E(y_U - y_V) + x_U(y_V - y_E) + x_V(y_E - y_U)|$$

$$= \frac{1}{2}|8t_2(0 - (-6t_1)) + 0 + 8(6 - 0)|$$

$$= \frac{1}{2}|48t_1t_2 + 48|$$

$$= 24|t_1t_2 + 1|$$

## Step 5: Optimize subject to constraint

Given $t_1t_2 = 4.5$:

$$\text{Area}(EUV) = 24|4.5 + 1| = 24 \times 5.5 = 132$$

This value is **constant** for all $(t_1, t_2)$ satisfying the constraint $t_1t_2 = 4.5$.

## Step 6: Verify the solution

- Pentagon constraint: $24(4.5) - 24 = 108 - 24 = 84$ ✓
- Convexity: $t_1t_2 = 4.5 > 1$ ensures proper convex ordering ✓
- All arithmetic verified ✓

**Final Answer: 132**
