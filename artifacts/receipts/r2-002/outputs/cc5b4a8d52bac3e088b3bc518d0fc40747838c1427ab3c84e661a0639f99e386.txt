# Solution Plan for Finding RS

## 1. **Set Up Coordinates**
   - Place the tetrahedron in a coordinate system using symmetry
   - Let the two bases (triangles with sides $5\sqrt{10}, 5\sqrt{10}, 10$ and $5\sqrt{10}, 5\sqrt{10}, 18$) be parallel
   - Position them along the z-axis with the common edge aligned appropriately

## 2. **Find All Four Vertices**
   - Determine coordinates of the two base triangles
   - Use the constraint that edges connecting the two bases have length $5\sqrt{10}$
   - Verify the configuration satisfies all face specifications

## 3. **Calculate the Circumcenter S**
   - Set up equations: $|S - V_i|^2 = R^2$ for all four vertices $V_i$
   - Solve the system to find coordinates of $S$ and circumradius $R$

## 4. **Calculate the Inradius r**
   - Find the volume $V$ of the tetrahedron using the coordinate vertices
   - Calculate the surface area $A$ (sum of all four triangle areas)
   - Use the formula: $r = \frac{3V}{A}$

## 5. **Calculate the Incenter R**
   - Use the weighted average formula with face areas as weights
   - Incenter = $\frac{A_1 V_1 + A_2 V_2 + A_3 V_3 + A_4 V_4}{A_1 + A_2 + A_3 + A_4}$
   - where $A_i$ are face areas and $V_i$ are opposite vertices

## 6. **Compute Distance RS**
   - Calculate $RS = |S - R|$ using the coordinates from steps 3 and 5
   - Simplify to get exact value

## 7. **Express as Fraction in Lowest Terms**
   - Write $RS = \frac{m}{n}$ where $\gcd(m,n) = 1$
   - Verify the fraction is fully reduced

## 8. **Report Answer**
   - Calculate $m + n$
