# Detailed Solution

## Step 1: Set up coordinates
- $B = (0, 0)$
- $C = (10, 0)$ on the x-axis

## Step 2: Locate point $E$
For equilateral triangle $BEC$ with side length 10, the third vertex is:
- $E = (5, 5\sqrt{3})$

## Step 3: Express positions of $A$ and $D$
- $A = (-a, 0)$ where $a = AB > 0$
- $D = (10 + d, 0)$ where $d = CD > 0$

## Step 4: Apply angle condition using dot product

Vectors from $E$:
$$\overrightarrow{EA} = (-a-5, -5\sqrt{3})$$
$$\overrightarrow{ED} = (5+d, -5\sqrt{3})$$

Dot product:
$$\overrightarrow{EA} \cdot \overrightarrow{ED} = (-a-5)(5+d) + 75$$

Magnitudes:
$$|\overrightarrow{EA}| = \sqrt{(a+5)^2 + 75}$$
$$|\overrightarrow{ED}| = \sqrt{(5+d)^2 + 75}$$

For $\angle AED = 120°$:
$$\frac{(-a-5)(5+d) + 75}{\sqrt{(a+5)^2 + 75}\sqrt{(5+d)^2 + 75}} = -\frac{1}{2}$$

## Step 5: Expand into working form

Multiplying both sides by $-2$:
$$10a + 2ad + 10d - 100 = \sqrt{(a+5)^2 + 75}\sqrt{(5+d)^2 + 75}$$

## Step 6: Apply distance constraint

From collinearity: $AD = a + 10 + d = 39$

Therefore: **$a + d = 29$**

## Step 7: Substitute and solve

Let $d = 29 - a$:
$$10a + 2a(29-a) + 10(29-a) - 100 = \sqrt{(a+5)^2 + 75}\sqrt{(34-a)^2 + 75}$$

Simplifying the left side:
$$10a + 58a - 2a^2 + 290 - 10a - 100 = \sqrt{(a+5)^2 + 75}\sqrt{(34-a)^2 + 75}$$
$$-2a^2 + 58a + 190 = \sqrt{(a+5)^2 + 75}\sqrt{(34-a)^2 + 75}$$

Squaring both sides:
$$(-2a^2 + 58a + 190)^2 = [(a+5)^2 + 75][(34-a)^2 + 75]$$

**Left side:** 
$$4a^4 - 232a^3 + 2604a^2 + 22040a + 36100$$

**Right side:**
$$[a^2 + 10a + 100][a^2 - 68a + 1231] = a^4 - 58a^3 + 651a^2 + 5510a + 123100$$

This gives:
$$3a^4 - 174a^3 + 1953a^2 + 16530a - 87000 = 0$$

Dividing by 3:
$$a^4 - 58a^3 + 651a^2 + 5510a - 29000 = 0$$

**Testing $a = 4$:**
$$256 - 3712 + 10416 + 22040 - 29000 = 0$$ ✓

**Testing $a = 25$:**
$$390625 - 3712500 + 10406250 + 137750 - 29000 = 0$$ ✓

Both values satisfy the constraint $a + d = 29$.

## Step 8: Verify and compute final answer

**Solution 1:** $(a, d) = (4, 25)$ gives $AB = 4, CD = 25$

**Solution 2:** $(a, d) = (25, 4)$ gives $AB = 25, CD = 4$

In both cases:
$$|AB - CD| = |4 - 25| = |-21| = 21$$

**21**
