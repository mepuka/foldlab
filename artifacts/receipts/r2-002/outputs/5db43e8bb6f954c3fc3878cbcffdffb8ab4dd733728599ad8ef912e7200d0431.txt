# Systematic Count of Palindromes with Digit Sum 13

## 1-Digit Palindromes
Form: **a** where a = 13
- Impossible (a ≤ 9)
- **Count: 0**

## 2-Digit Palindromes  
Form: **aa** where 2a = 13
- Requires a = 6.5 (not integer)
- **Count: 0**

## 3-Digit Palindromes
Form: **aba** where 2a + b = 13, a ∈ {1,...,9}, b ∈ {0,...,9}

| a | b | Valid? |
|---|---|--------|
| 1 | 11 | ✗ |
| 2 | 9 | ✓ |
| 3 | 7 | ✓ |
| 4 | 5 | ✓ |
| 5 | 3 | ✓ |
| 6 | 1 | ✓ |
| 7+ | negative | ✗ |

- **Count: 5**

## 4-Digit Palindromes
Form: **abba** where 2a + 2b = 13
- Requires a + b = 6.5 (not integer)
- **Count: 0**

## 5-Digit Palindromes
Form: **abcba** where 2a + 2b + c = 13

For each a, count valid (b,c) pairs where c = 13 - 2a - 2b, with 0 ≤ c ≤ 9:

| a | b + c constraint | Valid pairs |
|---|------------------|------------|
| 1 | 2b + c = 11 | b∈{1,2,3,4,5}: 5 pairs |
| 2 | 2b + c = 9 | b∈{0,1,2,3,4}: 5 pairs |
| 3 | 2b + c = 7 | b∈{0,1,2,3}: 4 pairs |
| 4 | 2b + c = 5 | b∈{0,1,2}: 3 pairs ✓ (includes 42124) |
| 5 | 2b + c = 3 | b∈{0,1}: 2 pairs |
| 6 | 2b + c = 1 | b∈{0}: 1 pair |

- **Count: 5 + 5 + 4 + 3 + 2 + 1 = 20**

## 6-Digit Palindromes
Form: **abccba** where 2a + 2b + 2c = 13
- Requires a + b + c = 6.5 (not integer)
- **Count: 0**

## 7-Digit Palindromes
Form: **abcdcba** where 2a + 2b + 2c + d = 13, with d = 13 - 2a - 2b - 2c

Constraint: 0 ≤ d ≤ 9, requiring a + b + c ≤ 6

| a | Count of (b,c,d) |
|---|-----------------|
| 1 | 5+5+4+3+2+1 = 20 |
| 2 | 5+4+3+2+1 = 15 |
| 3 | 4+3+2+1 = 10 |
| 4 | 3+2+1 = 6 |
| 5 | 2+1 = 3 |
| 6 | 1 |

- **Count: 20 + 15 + 10 + 6 + 3 + 1 = 55**

## 8-Digit Palindromes
Form: **abcddcba** where 2a + 2b + 2c + 2d = 13
- Requires a + b + c + d = 6.5 (not integer)
- **Count: 0**

## 9-Digit Palindromes
Form: **abcdedcba** where 2a + 2b + 2c + 2d + e = 13

Constraint: a + b + c + d ≤ 6

For each a, count non-negative integer solutions to b + c + d ≤ (6-a):
- a = 1: b+c+d ≤ 5 → C(5+3,3) = 56
- a = 2: b+c+d ≤ 4 → C(4+3,3) = 35
- a = 3: b+c+d ≤ 3 → C(3+3,3) = 20
- a = 4: b+c+d ≤ 2 → C(2+3,3) = 10
- a = 5: b+c+d ≤ 1 → C(1+3,3) = 4
- a = 6: b+c+d ≤ 0 → C(0+3,3) = 1

- **Count: 56 + 35 + 20 + 10 + 4 + 1 = 126**

## Total Sum
0 + 0 + 5 + 0 + 20 + 0 + 55 + 0 + 126 = **206**
