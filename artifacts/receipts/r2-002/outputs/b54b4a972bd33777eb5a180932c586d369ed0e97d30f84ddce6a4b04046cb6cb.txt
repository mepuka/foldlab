# Step-by-Step Solution

## Step 1: Rewrite the expression

Given $n = a + b + ab$ where $a, b$ are distinct positive integers with $n \leq 100$.

Factoring:
$$n = a + b + ab = (a+1)(b+1) - 1$$

Therefore: $(a+1)(b+1) = n + 1 \leq 101$

## Step 2: Determine the range

- Since $a, b \geq 1$ and $a \neq b$, we need $(a+1), (b+1) \geq 2$ and $(a+1) \neq (b+1)$
- We need $(a+1)(b+1) \leq 101$
- Let $p = a+1$ and $q = b+1$, so we need pairs $(p,q)$ with $2 \leq p < q$ and $pq \leq 101$

## Step 3: Enumerate all valid pairs and collect values

For each pair $(p,q)$ with $p < q$ and $pq \leq 101$, we get $n = pq - 1$.

### **Odd values of $n$** (when at least one of $p,q$ is even):

From pairs $(2,q)$ where $q = 3$ to $50$:
- Products: $6, 8, 10, 12, ..., 100$
- Values: $n = 5, 7, 9, 11, 13, ..., 99$ (all odd numbers from 5 to 99)
- Count: $(99-5)/2 + 1 = \boxed{48}$ odd values

### **Even values of $n$** (when both $p,q$ are odd):

From pairs where both are odd and $pq \leq 101$:

**From $(3,q)$ with odd $q$:**
- $3 \times 5 = 15 → n = 14$
- $3 \times 7 = 21 → n = 20$
- $3 \times 9 = 27 → n = 26$
- $3 \times 11 = 33 → n = 32$
- $3 \times 13 = 39 → n = 38$
- $3 \times 15 = 45 → n = 44$
- $3 \times 17 = 51 → n = 50$
- $3 \times 19 = 57 → n = 56$
- $3 \times 21 = 63 → n = 62$
- $3 \times 23 = 69 → n = 68$
- $3 \times 25 = 75 → n = 74$
- $3 \times 27 = 81 → n = 80$
- $3 \times 29 = 87 → n = 86$
- $3 \times 31 = 93 → n = 92$
- $3 \times 33 = 99 → n = 98$

**From $(5,q)$ with odd $q > 5$:**
- $5 \times 7 = 35 → n = 34$
- $5 \times 9 = 45 → n = 44$ (duplicate)
- $5 \times 11 = 55 → n = 54$
- $5 \times 13 = 65 → n = 64$
- $5 \times 15 = 75 → n = 74$ (duplicate)
- $5 \times 17 = 85 → n = 84$
- $5 \times 19 = 95 → n = 94$

**From $(7,q)$ with odd $q > 7$:**
- $7 \times 9 = 63 → n = 62$ (duplicate)
- $7 \times 11 = 77 → n = 76$
- $7 \times 13 = 91 → n = 90$

**From $(9,11)$:**
- $9 \times 11 = 99 → n = 98$ (duplicate)

Distinct even values: $\{14, 20, 26, 32, 34, 38, 44, 50, 54, 56, 62, 64, 68, 74, 76, 80, 84, 86, 90, 92, 94, 98\}$

Count: $\boxed{22}$ even values

## Step 4: Count final set size

Total distinct values of $n$:
$$48 \text{ (odd)} + 22 \text{ (even)} = 70$$

ANSWER: **70**
