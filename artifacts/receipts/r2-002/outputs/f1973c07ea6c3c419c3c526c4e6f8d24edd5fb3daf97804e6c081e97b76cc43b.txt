# Detailed Verification

## Step 1: Understand the Set S
- $143 = 11 \times 13$
- $S = \{n : 1 \le n \le 142, \gcd(n, 143) = 1\}$
- $|S| = \phi(143) = \phi(11) \times \phi(13) = 10 \times 12 = 120$ ✓

## Step 2: Verify the Closure Condition
For $(a,b) \in S \times S$ to satisfy $a+b \in S$, we need $\gcd(a+b, 143) = 1$. ✓

## Step 3: Apply Chinese Remainder Theorem
Since $143 = 11 \times 13$:
$$\gcd(a+b, 143) = 1 \iff \gcd(a+b, 11) = 1 \text{ AND } \gcd(a+b, 13) = 1$$

This is equivalent to:
$$a+b \not\equiv 0 \pmod{11} \text{ AND } a+b \not\equiv 0 \pmod{13}$$

## Step 4: Count Pairs Modulo 11

Elements of $S$ coprime to 11: $\{1,2,3,...,10\}$ (10 elements)

- Total pairs $(a_{11}, b_{11})$: $10^2 = 100$
- Pairs where $a_{11} + b_{11} \equiv 0 \pmod{11}$:
  - For each $a_{11}$, exactly one $b_{11}$ exists such that $b_{11} \equiv -a_{11} \pmod{11}$
  - Since $a_{11} \in \{1,...,10\}$, we have $-a_{11} \in \{1,...,10\}$
  - Count: 10 pairs
- Valid pairs: $100 - 10 = 90$ ✓

## Step 5: Count Pairs Modulo 13

Elements of $S$ coprime to 13: $\{1,2,3,...,12\}$ (12 elements)

  - Count: 12 pairs
- Valid pairs: $144 - 12 = 132$ ✓

$$90 \times 132$$
