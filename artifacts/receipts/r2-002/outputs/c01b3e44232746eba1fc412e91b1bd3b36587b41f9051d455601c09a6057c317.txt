# Solving HATER + HEART = EARTH

## Step 1: Expand and Simplify the Equation

**Expanding each term:**
- HATER = 10000H + 1000A + 100T + 10E + R
- HEART = 10000H + 1000E + 100A + 10R + T  
- EARTH = 10000E + 1000A + 100R + 10T + H

**Setting up the equation:**
$$10000H + 1000A + 100T + 10E + R + 10000H + 1000E + 100A + 10R + T = 10000E + 1000A + 100R + 10T + H$$

**Combining like terms on the left:**
$$20000H + 1100A + 101T + 1010E + 11R = 10000E + 1000A + 100R + 10T + H$$

**Collecting all terms on one side:**
$$20000H - H + 1100A - 1000A + 101T - 10T + 1010E - 10000E + 11R - 100R = 0$$

**Simplified equation:**
$$19999H + 100A + 91T - 8990E - 89R = 0$$

Or rearranged:
$$19999H + 100A + 91T = 8990E + 89R$$

## Step 2: Apply Leading Digit Constraints

- H ≥ 1 (HATER must be 5-digit)
- E ≥ 1 (EARTH must be 5-digit)
- All digits must be distinct: H, A, T, E, R ∈ {0-9}

## Step 3: Determine Feasible Range for H

Since both HATER and HEART start with H:
$$2(10000H) < 100000$$
$$H < 5$$

Therefore: **H ∈ {1, 2, 3, 4}**
