# Solution: Finding the Minimum Value of AB

## Step 1: Set Up the Perimeter Ratio

For an isosceles triangle with $AB = BC = c$ and base $AC = b$, I'll use:
- Perimeter of $\triangle ABC$: $P_1 = 2c + b$
- Perimeter of $\triangle AIC$: $P_2 = 2 \cdot AI + b$ (since $AI = IC$ by symmetry)
- Given ratio: $\frac{P_1}{P_2} = \frac{125}{6}$

## Step 2: Derive the Formula for AI

Using standard formulas and the isosceles geometry:
- From the law of cosines: $b = 2c\cos(\alpha)$ where $\alpha$ is the base angle
- This gives: $\sin(\alpha/2) = \frac{\sqrt{2c-b}}{2\sqrt{c}}$

After careful calculation using $AI = \frac{r}{\sin(A/2)}$:
$$AI = \frac{b\sqrt{c(2c+b)}}{2c+b}$$

## Step 3: Parametrize with Perimeter Ratio

Let $P_1 = 125m$ and $P_2 = 6m$ for positive integer $m$.

Then:
- $2c + b = 125m$
- $2AI + b = 6m$

From the second equation:
$$AI = \frac{6m - b}{2}$$

Substituting $b = 125m - 2c$:
$$AI = \frac{6m - (125m - 2c)}{2} = \frac{2c - 119m}{2}$$

For $AI$ to be an integer, $m$ must be even.

## Step 4: Test m = 4

Let $m = 4$:
- $P_1 = 500$
- $P_2 = 24$  
- $2c + b = 500$, so $b = 500 - 2c$
- $AI = c - 238$

For valid triangle: $c > 238$ and $c < 250$

## Step 5: Apply the AI Formula

Substituting into $AI = \frac{b\sqrt{c(2c+b)}}{500}$:

$$500(c - 238) = (500 - 2c)\sqrt{500c}$$

$$50(c - 238) = (500 - 2c)\sqrt{5c}$$

## Step 6: Solve for Integer Solutions

Let $\sqrt{5c} = 5\ell$ (ensuring $c = 5\ell^2$ is an integer):

$$50(5\ell^2 - 238) = (500 - 10\ell^2) \cdot 5\ell$$

$$\ell^3 + 5\ell^2 - 50\ell - 238 = 0$$

Testing $\ell = 7$:
$$343 + 245 - 350 - 238 = 0$$ ✓

## Step 7: Verify the Solution

With $\ell = 7$: $c = 5(49) = 245$

- $b = 500 - 2(245) = 10$
- Triangle inequality: $2c = 490 > b = 10$ ✓
- $AI = 245 - 238 = 7$

Verification:
$$AI = \frac{10\sqrt{245 \cdot 500}}{500} = \frac{10\sqrt{122500}}{500} = \frac{10 \cdot 350}{500} = 7$$ ✓

Perimeter check:
- $P_1 = 490 + 10 = 500$
- $P_2 = 14 + 10 = 24$
- $\frac{500}{24} = \frac{125}{6}$ ✓
