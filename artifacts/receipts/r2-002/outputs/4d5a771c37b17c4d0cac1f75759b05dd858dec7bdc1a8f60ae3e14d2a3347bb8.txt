# Solution: Finding all $n < 1000$ where $s_4(n) = [s_2(n)]^2$

## Step 1: Establish the constraint on $s_2(n)$

For $n < 1000$ in base 4, the maximum digit sum is:
$$999 = (33333)_4 \implies s_4(999) = 3+3+3+3+3 = 15$$

Let $m = s_2(n)$. We need $s_4(n) = m^2$.

Since $s_4(n) \leq 15$ and $s_4(n) = m^2$, we require:
$$m^2 \leq 15 \implies m \in \{1, 2, 3\}$$

(Note: $m$ must be positive since $n > 0$)

## Step 2: Understand the base-2 to base-4 relationship

Each base-4 digit converts to binary as:
- $0 = (00)_2$ → contributes 0 ones
- $1 = (01)_2$ → contributes 1 one  
- $2 = (10)_2$ → contributes 1 one
- $3 = (11)_2$ → contributes 2 ones

For $n = \sum_i d_i \cdot 4^i$ where $d_i \in \{0,1,2,3\}$:
- $s_4(n) = \sum_i d_i$
- $s_2(n) = \sum_i c(d_i)$ where $c(0)=0, c(1)=1, c(2)=1, c(3)=2$

## Step 3: Determine conditions for each case

**Case $m = 1$:** Need $s_4(n) = 1$ and $s_2(n) = 1$

This requires exactly one nonzero digit $d_i$ with $c(d_i) = 1$, so $d_i \in \{1,2\}$.

- If $d_i = 1$: $s_4(n) = 1$ and $s_2(n) = 1$ ✓
- If $d_i = 2$: $s_4(n) = 2$ and $s_2(n) = 1$ ✗

Valid numbers: $1 \cdot 4^i$ for $i = 0,1,2,3,4$

$$\boxed{m=1: \{1, 4, 16, 64, 256\}}$$

**Case $m = 2$:** Need $s_4(n) = 4$ and $s_2(n) = 2$

With $a$ ones, $b$ twos, $c$ threes:
$$a + 2b + 3c = 4$$
$$a + b + 2c = 2$$

Subtracting: $b + c = 2$, so $b = 2-c$ and $a = 2-b-2c = -c$

For $a \geq 0$: we need $c = 0$, giving $a = 0, b = 2$.

Valid configuration: exactly two digits equal to 2, all others 0.

For positions $i < j$, we have $n = 2 \cdot 4^i + 2 \cdot 4^j$:

$$\boxed{m=2: \{10, 34, 40, 130, 136, 160, 514, 520, 544, 640\}}$$

(Pairs: $(0,1), (0,2), (1,2), (0,3), (1,3), (2,3), (0,4), (1,4), (2,4), (3,4)$)

**Case $m = 3$:** Need $s_4(n) = 9$ and $s_2(n) = 3$

$$a + 2b + 3c = 9$$
$$a + b + 2c = 3$$

Subtracting: $b + c = 6$, so $a = 3 - b - 2c = 3 - (6-c) - 2c = -3-c < 0$

No valid solutions.

## Step 4: Calculate the sum

Sum of all valid $n$:

**From $m = 1$:** 
$$1 + 4 + 16 + 64 + 256 = 341$$

**From $m = 2$:** 
$$10 + 34 + 40 + 130 + 136 + 160 + 514 + 520 + 544 + 640 = 2728$$

**Total:**
$$341 + 2728 = 3069$$

**3069**
