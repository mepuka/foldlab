# Solution: Finding $BC$ in Rectangle $ABCD$

## Step 1: Coordinate System Setup
- $A = (0, 0)$
- $B = (0, 1)$ (since $AB = 1$)
- $D = (a, 0)$ where $a = BC$ (unknown)
- $C = (a, 1)$

## Step 2: Express Positions of $X$ and $Y$
- $X = (t, 1)$ where $0 \leq t \leq a$ (on $\overline{BC}$)
- $Y = (y, 0)$ where $0 \leq y \leq a$ (on $\overline{AD}$)

## Step 3: Apply Perpendicularity at $X$: $\angle AXY = 90°$

$\overrightarrow{XA} = (0,0) - (t,1) = (-t, -1)$

$\overrightarrow{XY} = (y,0) - (t,1) = (y-t, -1)$

Dot product equals zero:
$$(-t)(y-t) + (-1)(-1) = 0$$
$$-ty + t^2 + 1 = 0$$
$$ty = t^2 + 1 \quad \text{...(Equation 1)}$$

## Step 4: Apply Perpendicularity at $Y$: $\angle XYC = 90°$

$\overrightarrow{YX} = (t-y, 1)$

$\overrightarrow{YC} = (a-y, 1)$

Dot product equals zero:
$$(t-y)(a-y) + 1 = 0$$
$$(t-y)(a-y) = -1 \quad \text{...(Equation 2)}$$

## Step 5: Apply Ratio Condition $AX : XY : YC = 1 : 2 : 1$

Calculate distances:
- $AX = \sqrt{t^2 + 1}$
- $XY = \sqrt{(y-t)^2 + 1}$
- $YC = \sqrt{(a-y)^2 + 1}$

From the ratio:
$$AX = YC \implies t^2 = (a-y)^2 \quad \text{...(Equation 3)}$$

$$XY = 2 \cdot AX \implies (y-t)^2 + 1 = 4(t^2 + 1)$$
$$(y-t)^2 = 4t^2 + 3 \quad \text{...(Equation 4)}$$

## Step 6: Solve the System

From Equation 1: $y = t + \frac{1}{t}$

From Equation 4: $y - t = \sqrt{4t^2 + 3}$ (positive root)

Therefore:
$$\frac{1}{t} = \sqrt{4t^2 + 3}$$

Squaring both sides:
$$\frac{1}{t^2} = 4t^2 + 3$$
$$1 = 4t^4 + 3t^2$$
$$4t^4 + 3t^2 - 1 = 0$$

Using the quadratic formula with $u = t^2$:
$$u = \frac{-3 \pm \sqrt{9 + 16}}{8} = \frac{-3 \pm 5}{8}$$

Taking the positive root: $u = \frac{1}{4}$, so $t = \frac{1}{2}$

Then: $y = \frac{1}{2} + 2 = \frac{5}{2}$

From Equation 3: $\frac{1}{4} = (a - \frac{5}{2})^2$

So: $a - \frac{5}{2} = \pm\frac{1}{2}$

From Equation 2: $({\textstyle\frac{1}{2}} - {\textstyle\frac{5}{2}})(a - {\textstyle\frac{5}{2}}) = -1$

$(-2)(a - \frac{5}{2}) = -1 \implies a - \frac{5}{2} = \frac{1}{2}$

$$a = 3$$

## Step 7: Verification
- Equation 1: $\frac{1}{2} \cdot \frac{5}{2} = \frac{1}{4} + 1 = \frac{5}{4}$ ✓
- Equation 2: $(-2)(\frac{1}{2}) = -1$ ✓
- $X = (\frac{1}{2}, 1)$ is on $\overline{BC}$ ✓
- $Y = (\frac{5}{2}, 0)$ is on $\overline{AD}$ ✓
