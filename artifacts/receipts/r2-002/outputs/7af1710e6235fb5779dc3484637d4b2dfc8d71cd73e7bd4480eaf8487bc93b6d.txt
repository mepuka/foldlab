# Solution

## Step 1: Coordinate System Setup
- $A = (0, 0, 0)$
- $B = (6, 0, 0)$  
- $C = (0, 4, 0)$
- Plane $\mathcal{P}$: $z = 0$ ✓

## Step 2: Locate Point $D$

**Find centroid $G$ of $\triangle ABC$:**
$$G = \frac{1}{3}(A + B + C) = \frac{1}{3}(6, 4, 0) = \left(2, \frac{4}{3}, 0\right)$$

**Find perpendicular from $G$ to line $BC$:**

Line $BC$: parametrized as $(6, 0, 0) + t(-6, 4, 0)$ where $\vec{BC} = (-6, 4, 0)$

Foot of perpendicular: $(6-6t, 4t, 0) - G$ perpendicular to $\vec{BC}$

$$(4-6t, 4t - \tfrac{4}{3}, 0) \cdot (-6, 4, 0) = 0$$
$$-24 + 36t + 16t - \frac{16}{3} = 0$$
$$52t = \frac{88}{3} \implies t = \frac{22}{39}$$

Foot: $H = \left(\frac{34}{13}, \frac{88}{39}, 0\right)$

**Reflect $G$ across $H$:**
$$D = 2H - G = 2\left(\frac{34}{13}, \frac{88}{39}, 0\right) - \left(2, \frac{4}{3}, 0\right)$$
$$= \left(\frac{68}{13} - 2, \frac{176}{39} - \frac{52}{39}, 0\right) = \left(\frac{42}{13}, \frac{124}{39}, 0\right)$$

## Step 3: Sphere Centers
- $O_1 = (0, 0, 1)$ with radius $r_1 = 1$
- $O_2 = (6, 0, 2)$ with radius $r_2 = 2$
- $O_3 = (0, 4, 3)$ with radius $r_3 = 3$
- $O_4 = \left(\frac{42}{13}, \frac{124}{39}, r\right)$ with radius $r_4 = r$

## Step 4: Find Plane $\mathcal{T}$

Let plane be $ax + by + cz = d$ with $a^2 + b^2 + c^2 = 1$.

**Distance conditions:**
- From $O_1$: $|c - d| = 1 \implies d = c - 1$
- From $O_2$: $|6a + 2c - d| = 2 \implies |6a + c + 1| = 2$
- From $O_3$: $|4b + 3c - d| = 3 \implies |4b + 2c + 1| = 3$

**Case analysis:** $6a + c + 1 = 2$ and $4b + 2c + 1 = 3$

$$a = \frac{1-c}{6}, \quad b = \frac{1-c}{2}$$

**Substituting into normalization:**
$$\frac{(1-c)^2}{36} + \frac{(1-c)^2}{4} + c^2 = 1$$
$$(1-c)^2 \cdot \frac{10}{36} + c^2 = 1$$
$$\frac{5(1-c)^2}{18} + c^2 = 1$$

Multiplying by 18:
$$5(1-2c+c^2) + 18c^2 = 18$$
$$23c^2 - 10c - 13 = 0$$
$$c = \frac{10 \pm 36}{46}$$

Taking $c = -\frac{13}{23}$:
$$a = \frac{6}{23}, \quad b = \frac{18}{23}, \quad d = -\frac{36}{23}$$

**Plane equation:** $6x + 18y - 13z + 36 = 0$

## Step 5: Apply Tangency for Sphere 4

Distance from $O_4$ to plane:
$$\frac{\left|6 \cdot \frac{42}{13} + 18 \cdot \frac{124}{39} - 13r + 36\right|}{\sqrt{36+324+169}}$$

$$= \frac{\left|\frac{756 + 2232 + 1404}{39} - 13r\right|}{23} = \frac{|4392 - 507r|}{897}$$

Setting equal to $r$:
$$|4392 - 507r| = 897r$$

Taking the positive case:
$$4392 - 507r = 897r$$
$$4392 = 1404r$$
$$r = \frac{4392}{1404} = \frac{122}{39}$$

**Verify:** $\gcd(122, 39) = 1$ ✓

$$m + n = 122 + 39 = \boxed{161}$$
