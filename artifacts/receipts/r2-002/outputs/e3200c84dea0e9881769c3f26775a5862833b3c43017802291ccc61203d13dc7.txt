# Step-by-Step Solution

## Step 1: Set up a coordinate system

I'll place square $ABCD$ with:
- $A = (0, 0)$
- $B = (12, 0)$
- $C = (12, 12)$
- $D = (0, 12)$

## Step 2: Locate points $W$ and $X$

Given that $W$ is on $\overline{AD}$ with $AW = 4$:
$$W = (0, 4)$$

Given that $X$ is on $\overline{AB}$ with $AX = 5$:
$$X = (5, 0)$$

## Step 3: Determine the side length of square $WXYZ$

Calculate the distance $|WX|$:
$$|WX| = \sqrt{(5-0)^2 + (0-4)^2} = \sqrt{25 + 16} = \sqrt{41}$$

This is the side length of square $WXYZ$.

## Step 4: Find the direction vector and perpendicular direction

The vector from $W$ to $X$ is:
$$\overrightarrow{WX} = (5, -4)$$

To form a square, we rotate this vector $90°$ counterclockwise:
$$\text{Rotation of } (5, -4) \text{ by } 90° \text{ counterclockwise} = (4, 5)$$

We can verify: $(5)·(4) + (-4)·(5) = 20 - 20 = 0$ ✓ (perpendicular)
And: $\sqrt{4^2 + 5^2} = \sqrt{41}$ ✓ (same length)

## Step 5: Locate point $Y$

From $X$, move in the perpendicular direction $(4, 5)$ by distance $\sqrt{41}$:
$$Y = X + (4, 5) = (5, 0) + (4, 5) = (9, 5)$$

Verification that $Y$ is inside $ABCD$: $0 < 9 < 12$ and $0 < 5 < 12$ ✓

## Step 6: Calculate the area of $\triangle BCY$

The vertices are:
- $B = (12, 0)$
- $C = (12, 12)$
- $Y = (9, 5)$

Using the coordinate formula for triangle area:
$$\text{Area} = \frac{1}{2}|x_B(y_C - y_Y) + x_C(y_Y - y_B) + x_Y(y_B - y_C)|$$

$$= \frac{1}{2}|12(12 - 5) + 12(5 - 0) + 9(0 - 12)|$$

$$= \frac{1}{2}|12(7) + 12(5) + 9(-12)|$$

$$= \frac{1}{2}|84 + 60 - 108|$$

$$= \frac{1}{2}|36| = 18$$

# Final Answer

The area of $\triangle BCY$ is $\boxed{18}$.
