# Plan for Solving the Problem

1. **Rewrite the expression in a more useful form**
   - Factor: $n = a + b + ab = (a+1)(b+1) - 1$
   - This means we need $(a+1)(b+1) \leq 101$

2. **Determine the range for $(a+1)$ and $(b+1)$**
   - Since $a, b \geq 1$ and $a \neq b$, we have $(a+1), (b+1) \geq 2$
   - Since $(a+1)(b+1) \leq 101$, both factors are at most 101

3. **Enumerate all valid pairs $(a,b)$**
   - For each pair of distinct positive integers $(a,b)$, compute $n = a + b + ab$
   - Include the pair only if $n \leq 100$
   - Note: Since the formula is symmetric in $a$ and $b$, the pairs $(a,b)$ and $(b,a)$ produce the same $n$

4. **Collect all distinct values of $n$**
   - Store each computed value of $n$ in a set to eliminate duplicates
   - This accounts for different pairs $(a,b)$ that may produce the same result

5. **Count the final set size**
   - Count the number of distinct integers in the resulting set
   - This is the answer
