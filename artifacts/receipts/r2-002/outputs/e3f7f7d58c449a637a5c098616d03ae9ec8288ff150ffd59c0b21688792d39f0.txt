# Solution: Counting Pairs $(a,b) \in S \times S$ with $a+b \in S$

## Step 1: Understanding the Set $S$
Set $S = \{x : 1 \leq x \leq 142, \gcd(x, 143) = 1\}$

Size: $|S| = \phi(143) = \phi(11 \times 13) = \phi(11) \times \phi(13) = 10 \times 12 = 120$ ✓

## Step 2: Key Insight
We want to count pairs $(a,b) \in S \times S$ where $(a+b \bmod 143) \in S$.

This requires: $\gcd(a+b, 143) = 1$

## Step 3: Chinese Remainder Theorem Decomposition
Since $143 = 11 \times 13$:
$$\gcd(a+b, 143) = 1 \iff \gcd(a+b, 11) = 1 \text{ AND } \gcd(a+b, 13) = 1$$

The conditions for working modulo each prime are independent, so we count separately and multiply.

## Step 4: Count Valid Pairs Modulo 11

**Elements coprime to 11:** $\{1, 2, 3, ..., 10\}$ (10 elements)

**Total pairs from these elements:** $10^2 = 100$

**Pairs where $a+b \equiv 0 \pmod{11}$:** 
- For each $a \in \{1,...,10\}$, exactly one value $b \equiv -a \pmod{11}$ makes the sum $\equiv 0$
- Count: 10 pairs

**Valid pairs (sum $\not\equiv 0 \pmod{11}$):** 
$$100 - 10 = 90 \text{ pairs} \checkmark$$

## Step 5: Count Valid Pairs Modulo 13

**Elements coprime to 13:** $\{1, 2, 3, ..., 12\}$ (12 elements)

**Total pairs from these elements:** $12^2 = 144$

**Pairs where $a+b \equiv 0 \pmod{13}$:**
- For each $a \in \{1,...,12\}$, exactly one value $b \equiv -a \pmod{13}$ makes the sum $\equiv 0$
- Count: 12 pairs

**Valid pairs (sum $\not\equiv 0 \pmod{13}$):**
$$144 - 12 = 132 \text{ pairs} \checkmark$$

## Step 6: Apply CRT to Combine Results

By the Chinese Remainder Theorem, since the conditions modulo 11 and modulo 13 are independent:

$$\text{Total count} = 90 \times 132$$

**Calculation:**
$$90 \times 132 = 90 \times (130 + 2) = 9,000 + 180 + 1,700 = 11,880$$

**Double-check:**
$$90 \times 132 = (10 \times 9) \times (12 \times 11) = (10 \times 12) \times (9 \times 11) = 120 \times 99 = 11,880$$ ✓

Or: $120 \times 99 = 120 \times (100-1) = 12,000 - 120 = 11,880$ ✓

## Final Answer

ANSWER: **11880**
