# Extended Solution

## Step 1-3: Set up coordinates

- Place $B$ at origin: $B = (0, 0)$
- Place $C$ on x-axis: $C = (10, 0)$ (since $BC = 10$)
- For equilateral triangle $BEC$ with side 10: $E = (5, 5\sqrt{3})$
- Point $A$ on the line left of $B$: $A = (-a, 0)$ where $a = AB > 0$
- Point $D$ on the line right of $C$: $D = (10 + d, 0)$ where $d = CD > 0$

## Step 4-5: Apply angle condition $\angle AED = 120°$

Compute vectors from $E$:
$$\overrightarrow{EA} = (-a-5, -5\sqrt{3})$$
$$\overrightarrow{ED} = (5+d, -5\sqrt{3})$$

Dot product:
$$\overrightarrow{EA} \cdot \overrightarrow{ED} = (-a-5)(5+d) + 75$$

Magnitudes:
$$|\overrightarrow{EA}| = \sqrt{(a+5)^2 + 75}$$
$$|\overrightarrow{ED}| = \sqrt{(5+d)^2 + 75}$$

Using $\cos(120°) = -\frac{1}{2}$:
$$\frac{(-a-5)(5+d) + 75}{\sqrt{(a+5)^2 + 75}\sqrt{(5+d)^2 + 75}} = -\frac{1}{2}$$

## Step 6: Apply distance constraint

From collinearity with $AD = 39$:
$$AD = (10+d) - (-a) = a + d + 10 = 39$$
$$\boxed{a + d = 29}$$

## Step 7: Substitute and solve

Substitute $d = 29 - a$ into the angle equation:

$$(-a-5)(34-a) + 75 = -\frac{1}{2}\sqrt{(a+5)^2 + 75}\sqrt{(34-a)^2 + 75}$$

Expand left side:
$$a^2 - 29a - 170 + 75 = -\frac{1}{2}\sqrt{(a+5)^2 + 75}\sqrt{(34-a)^2 + 75}$$
$$a^2 - 29a - 95 = -\frac{1}{2}\sqrt{(a+5)^2 + 75}\sqrt{(34-a)^2 + 75}$$

Multiply by $-2$ and square:
$$(-2a^2 + 58a + 190)^2 = [(a+5)^2 + 75][(34-a)^2 + 75]$$

**Left side:**
$$4a^4 - 232a^3 + 2604a^2 + 22040a + 36100$$

**Right side:** Let me expand $(a^2 + 10a + 100)(a^2 - 68a + 1231)$:
$$a^4 - 58a^3 + 651a^2 + 5510a + 123100$$

Setting equal:
$$3a^4 - 174a^3 + 1953a^2 + 16530a - 87000 = 0$$

Divide by 3:
$$a^4 - 58a^3 + 651a^2 + 5510a - 29000 = 0$$

**Testing $a = 25$:**
$$625 - 7250 + 16275 + 27550 - 29000 = 0$$ ✓

Therefore: $a = 25$ and $d = 29 - 25 = 4$

## Verification

With $a = 25$, $d = 4$:
- $\overrightarrow{EA} = (-30, -5\sqrt{3})$, $|\overrightarrow{EA}| = \sqrt{900 + 75} = 5\sqrt{39}$
- $\overrightarrow{ED} = (9, -5\sqrt{3})$, $|\overrightarrow{ED}| = \sqrt{81 + 75} = 2\sqrt{39}$
- $\overrightarrow{EA} \cdot \overrightarrow{ED} = -270 + 75 = -195$
- $\cos(\angle AED) = \frac{-195}{10 \cdot 39} = -\frac{1}{2}$ ✓
- $AD = 25 + 10 + 4 = 39$ ✓

## Step 8: Compute $|AB - CD|$

$$|AB - CD| = |a - d| = |25 - 4| = 21$$

Final answer (single integer only): **21**
