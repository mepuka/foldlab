# Verification of Solution

## Step 1: Coordinate System ✓
- Square $ABCD$ with side length 12
- $A = (0, 0)$, $B = (12, 0)$, $C = (12, 12)$, $D = (0, 12)$

## Step 2: Locate Points W and X ✓

**Point W:** On segment $\overline{AD}$ with $AW = 4$
- Since $A = (0,0)$ and $D = (0,12)$, moving 4 units up the $y$-axis gives
- $W = (0, 4)$ ✓

**Point X:** On segment $\overline{AB}$ with $AX = 5$
- Since $A = (0,0)$ and $B = (12,0)$, moving 5 units along the $x$-axis gives
- $X = (5, 0)$ ✓

## Step 3: Side Length of Square WXYZ ✓

$$|WX| = \sqrt{(5-0)^2 + (0-4)^2} = \sqrt{25 + 16} = \sqrt{41}$$

## Step 4: Direction Vectors ✓

**Vector from W to X:**
$$\overrightarrow{WX} = (5-0, 0-4) = (5, -4)$$

**Perpendicular direction (90° counterclockwise rotation):**
- Formula: $(x, y) \to (-y, x)$
- $(5, -4) \to (4, 5)$
- Length check: $\sqrt{4^2 + 5^2} = \sqrt{16+25} = \sqrt{41}$ ✓

## Step 5: Locate Point Y ✓

Moving from $X$ in the perpendicular direction by distance $\sqrt{41}$:
$$Y = X + (4, 5) = (5, 0) + (4, 5) = (9, 5)$$

**Verification that Y is inside square ABCD:**
- $0 < 9 < 12$ ✓
- $0 < 5 < 12$ ✓

## Step 6: Calculate Area of △BCY ✓

Vertices: $B = (12, 0)$, $C = (12, 12)$, $Y = (9, 5)$

Using the shoelace formula:
$$\text{Area} = \frac{1}{2}|x_B(y_C - y_Y) + x_C(y_Y - y_B) + x_Y(y_B - y_C)|$$

Computing each term:
- $x_B(y_C - y_Y) = 12(12 - 5) = 12(7) = 84$
- $x_C(y_Y - y_B) = 12(5 - 0) = 12(5) = 60$
- $x_Y(y_B - y_C) = 9(0 - 12) = 9(-12) = -108$

Sum: $84 + 60 - 108 = 36$

$$\text{Area} = \frac{1}{2}|36| = 18$$

All calculations verified! ✓

ANSWER: **18**
