## Step 3: Interior Angle Sum Check

Sum of interior angles in a pentagon: $(5-2) \times 180° = 540°$

$$90° + 45° + \angle C + 45° + 90° = 540°$$
$$\angle C = 270°$$

So $C$ is a reflex angle (nonconvex vertex). ✓

## Step 4: Determine Position of C Using Angle Constraints

**At vertex $B$:** The interior angle is $45°$. 
- Vector $\vec{BA}$ points downward (angle $270°$)
- For interior angle $45°$, vector $\vec{BC}$ points at angle $270° + 45° = 315°$
- Direction: $(\cos 315°, \sin 315°) = (\frac{1}{\sqrt{2}}, -\frac{1}{\sqrt{2}})$

With $BC = 14\sqrt{2}$:
$$\vec{BC} = 14\sqrt{2} \cdot (\frac{1}{\sqrt{2}}, -\frac{1}{\sqrt{2}}) = (14, -14)$$
$$C = (0, b) + (14, -14) = (14, b-14)$$

**At vertex $D$:** Similarly, with interior angle $45°$:
- $\vec{DC}$ must point at angle $225°$
- Direction: $(-\frac{1}{\sqrt{2}}, -\frac{1}{\sqrt{2}})$

For $C = (14, b-14)$:
$$\vec{DC} = (14-20, b-14-d) = (-6, b-14-d)$$

For this to be proportional to $(-1, -1)$:
$$-6 = b - 14 - d$$
$$d = b - 8$$

Since we need $d < b$: $b - 8 < b$ ✓ (always satisfied)
