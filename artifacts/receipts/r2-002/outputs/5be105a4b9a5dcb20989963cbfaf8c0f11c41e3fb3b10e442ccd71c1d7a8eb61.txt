# Solution Plan

1. **Set up the system of equations** using inclusion-exclusion principle:
   - Let $a = \gcd(I,E)$, $b = \gcd(I,G)$, $c = \gcd(E,G)$, $d = \gcd(I,E,G)$
   - Equation 1: $I + E + G - a - b - c + d = 54$
   - Equation 2: $a + b + c - 2d = 11$
   - Constraint: $d \geq 1$

2. **Eliminate one variable** by adding the two equations:
   - $I + E + G - d = 65$
   - Therefore: $I + E + G = 65 + d$

3. **Substitute back into Equation 1** to find a relationship:
   - From $a + b + c = 11 + 2d$ (rearranged Equation 2)
   - This gives us: $a + b + c - d = 11 + d$

4. **Test values of $d$** starting from $d = 1$:
   - For each value of $d$, determine $a + b + c = 11 + 2d$
   - Find integer triples $(I, E, G)$ where:
     - $I + E + G = 65 + d$
     - $\gcd(I,E) = a$, $\gcd(I,G) = b$, $\gcd(E,G) = c$
     - $\gcd(I,E,G) = d$

5. **Verify divisibility constraints**:
   - Since $d$ divides $a$, $b$, and $c$, write $a = da'$, $b = db'$, $c = dc'$
   - Ensure $\gcd(a', b', c') = 1$

6. **Check the solution** against all three original constraints with the found values

7. **Calculate the product** $I \cdot E \cdot G$
