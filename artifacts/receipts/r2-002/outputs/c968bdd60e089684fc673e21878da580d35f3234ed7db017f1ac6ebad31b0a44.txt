# Detailed Solution

## Step 1: Identify valid values of $r$

For $n = \frac{5r + 8}{4}$ to be an integer, we need:
$$5r + 8 \equiv 0 \pmod{4}$$
$$5r \equiv -8 \equiv 0 \pmod{4}$$
$$r \equiv 0 \pmod{4}$$

Therefore, **$r = 4k$ for positive integers $k$**.

## Step 2: Apply the minimum color constraint

Substituting $r = 4k$:
$$n = \frac{5(4k) + 8}{4} = \frac{20k + 8}{4} = 5k + 2$$

And since blue squares are the remainder:
$$b = n - r = (5k + 2) - 4k = k + 2$$

The constraints are:
- $r \geq 7$: requires $4k \geq 7$, so $k \geq 1.75$ → $k \geq 2$
- $b \geq 7$: requires $k + 2 \geq 7$, so $k \geq 5$

The **binding constraint is $k \geq 5$**.

## Step 3: Find the five smallest valid $n$ values

Testing $k = 5, 6, 7, 8, 9$:

| $k$ | $r = 4k$ | $n = 5k + 2$ | $b = k + 2$ | Valid? |
|-----|----------|--------------|------------|--------|
| 5   | 20       | 27           | 7          | ✓      |
| 6   | 24       | 32           | 8          | ✓      |
| 7   | 28       | 37           | 9          | ✓      |
| 8   | 32       | 42           | 10         | ✓      |
| 9   | 36       | 47           | 11         | ✓      |

The five smallest valid $n$ values are: **27, 32, 37, 42, 47**

## Step 4: Calculate the sum

$$\sum n = 27 + 32 + 37 + 42 + 47$$
$$= (27 + 47) + (32 + 42) + 37$$
$$= 74 + 74 + 37$$
$$= 148 + 37$$
$$= 185$$

**185**
