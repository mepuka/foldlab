# Solution: Counting "SUNS" Subsequences

## Step 1: Verify String Structure
The string is "SUN" repeated 10 times, giving us:
- **S positions**: 1, 4, 7, 10, 13, 16, 19, 22, 25, 28 (10 positions, form 3k-2 for k=1..10)
- **U positions**: 2, 5, 8, 11, 14, 17, 20, 23, 26, 29 (10 positions, form 3k-1 for k=1..10)  
- **N positions**: 3, 6, 9, 12, 15, 18, 21, 24, 27, 30 (10 positions, form 3k for k=1..10)

## Step 2: Set Up Index Variables
Let:
- a = index of first S (1 ≤ a ≤ 10)
- b = index of U (1 ≤ b ≤ 10)
- d = index of N (1 ≤ d ≤ 10)
- c = index of second S (1 ≤ c ≤ 10)

Actual positions are:
- First S: 3a - 2
- U: 3b - 1
- N: 3d
- Second S: 3c - 2

## Step 3: Determine Constraints
For valid subsequence ordering:

**Position a < Position b:**
$$3a - 2 < 3b - 1 \implies 3a < 3b + 1 \implies a < b + \tfrac{1}{3} \implies \boxed{a < b}$$

**Position b ≤ Position d:**
$$3b - 1 < 3d \implies 3b < 3d + 1 \implies b < d + \tfrac{1}{3} \implies \boxed{b \leq d}$$

**Position d < Position c:**
$$3d < 3c - 2 \implies 3d + 2 < 3c \implies d < c - \tfrac{2}{3} \implies \boxed{d < c}$$

**Combined constraint:** $1 \leq a < b \leq d < c \leq 10$

## Step 4: Count Valid 4-Tuples
$$\sum_{a=1}^{8} \sum_{b=a+1}^{9} \sum_{d=b}^{9} \sum_{c=d+1}^{10} 1$$

**Innermost sum:**
$$\sum_{c=d+1}^{10} 1 = 10 - d$$

**Third sum:**
$$\sum_{d=b}^{9} (10-d) = \sum_{j=1}^{10-b} j = \frac{(10-b)(11-b)}{2}$$

**Second sum:**
$$\sum_{b=a+1}^{9} \frac{(10-b)(11-b)}{2}$$

Let $m = 10-b$; as $b$ goes from $a+1$ to $9$, $m$ goes from $9-a$ to $1$:
$$= \sum_{m=1}^{9-a} \frac{m(m+1)}{2} = \frac{1}{2}\left[\sum m^2 + \sum m\right]$$

$$= \frac{1}{2}\left[\frac{(9-a)(10-a)(19-2a)}{6} + \frac{(9-a)(10-a)}{2}\right]$$

$$= \frac{(9-a)(10-a)}{2}\left[\frac{19-2a}{6} + \frac{1}{2}\right] = \frac{(9-a)(10-a)(22-2a)}{12}$$

$$= \frac{(9-a)(10-a)(11-a)}{6}$$

**First sum:**
$$\sum_{a=1}^{8} \frac{(9-a)(10-a)(11-a)}{6}$$

Let $n = 9-a$; as $a$ goes from $1$ to $8$, $n$ goes from $8$ to $1$:
$$= \frac{1}{6}\sum_{n=1}^{8} n(n+1)(n+2)$$

Using the formula $\sum_{n=1}^{k} n(n+1)(n+2) = \frac{k(k+1)(k+2)(k+3)}{4}$:

$$= \frac{1}{6} \cdot \frac{8 \cdot 9 \cdot 10 \cdot 11}{4} = \frac{1}{6} \cdot \frac{7920}{4} = \frac{1980}{6} = 330$$
