# Solving the 3×3 Grid Problem with Numbers {1,2,3,4}

## Step 1: Understand the Problem Structure

We need to fill a 3×3 grid where each cell contains a subset of {1,2,3,4}, with constraints:
- Each number appears **exactly once** per row
- Each number appears **exactly once** per column

## Step 2: Reformulate as Permutation Matrices

For each number $i \in \{1,2,3,4\}$, define a 3×3 binary matrix $P_i$ where:
- $P_i[r,c] = 1$ if number $i$ appears at grid position $(r,c)$
- $P_i[r,c] = 0$ otherwise

**Key insight:** Each $P_i$ must be a **permutation matrix** because:
- Sum of row $r$ in $P_i$ = 1 (number $i$ appears once in row $r$)
- Sum of column $c$ in $P_i$ = 1 (number $i$ appears once in column $c$)

A permutation matrix corresponds to a permutation $\pi_i \in S_3$ where $P_i[r,c] = 1$ iff $\pi_i(r) = c$.

## Step 3: Map Permutations to Grid Configurations

Given four permutations $(\pi_1, \pi_2, \pi_3, \pi_4) \in S_3 \times S_3 \times S_3 \times S_3$:

For each grid position $(r,c)$, the cell contains:
$$\text{Cell}(r,c) = \{i \in \{1,2,3,4\} : \pi_i(r) = c\}$$

**Verification of constraints:**
- For number $i$ in row $r$: appears in column $\pi_i(r)$ only → appears exactly once ✓
- For number $i$ in column $c$: appears in row $\pi_i^{-1}(c)$ only → appears exactly once ✓

## Step 4: Count Valid Configurations

Each valid configuration is uniquely determined by an ordered 4-tuple of permutations.

- Number of permutations in $S_3$ = $3! = 6$
- Number of choices for $\pi_1$ = 6
- Number of choices for $\pi_2$ = 6  
- Number of choices for $\pi_3$ = 6
- Number of choices for $\pi_4$ = 6

By the multiplication principle:
$$\text{Total configurations} = 6 \times 6 \times 6 \times 6 = 6^4$$

## Step 5: Calculate

$$6^4 = (6^2)^2 = 36^2 = 1296$$

Or: $6^4 = 6 \times 6 \times 6 \times 6 = 36 \times 36 = 1296$

## Step 6: Verification

- Each permutation in $S_3$ is valid (can be arranged in 6 ways)
- Different 4-tuples of permutations produce different grids (distinct cell contents)
- All constraints are satisfied by construction
- No double-counting (one-to-one correspondence between permutation 4-tuples and valid grids)

**1296**
