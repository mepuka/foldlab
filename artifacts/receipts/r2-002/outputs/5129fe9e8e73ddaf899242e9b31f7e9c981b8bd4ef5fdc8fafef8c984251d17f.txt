# Solution: Downward-Closed Divisor Subsets with Pairing Constraint

## Step 1: Coordinate Representation
Each divisor of $10^9 = 2^9 \cdot 5^9$ has the form $d = 2^a \cdot 5^b$ where $0 \le a \le 9$ and $0 \le b \le 9$.

Represent each divisor as a coordinate pair $(a,b)$.

The complementary divisor is $\frac{10^9}{d} = 2^{9-a} \cdot 5^{9-b}$, represented as $(9-a, 9-b)$.

## Step 2: Self-Paired Analysis
A pair $(a,b)$ is self-paired if $(a,b) = (9-a, 9-b)$, which requires:
- $a = 9-a \Rightarrow a = 4.5$ (not an integer)
- $b = 9-b \Rightarrow b = 4.5$ (not an integer)

**No self-paired elements exist.** Every element has a distinct complement.

## Step 3: Downward-Closure Condition
The divisibility order on coordinates is: $(a,b) \preceq (a',b')$ iff $a \le a'$ AND $b \le b'$.

A downward-closed set (order ideal) $T$ satisfies: if $(a,b) \in T$ and $(a',b') \preceq (a,b)$, then $(a',b') \in T$.

## Step 4: Pairing Constraint
For each complementary pair $\{(a,b), (9-a,9-b)\}$, exactly one element must be in $T$.

This means:
- $T \cap \phi(T) = \emptyset$ where $\phi(T) = \{(9-a, 9-b) : (a,b) \in T\}$
- $T \cup \phi(T) = [0,9] \times [0,9]$
- Therefore: $|T| = 50$ (each set has half the grid)

## Step 5: Combined Characterization
We need order ideals of size exactly 50 that satisfy: **no $(a,b) \in T$ and $(9-a, 9-b) \in T$ simultaneously**.

The involution $\phi: (a,b) \mapsto (9-a, 9-b)$ has no fixed points and acts freely on the 100-element grid.
