# Solution: Finding All Digiroots with $s_2(n) = s_4(n)^2$

## Step 1: Establish the constraint on $s_2(n)$

For $n < 1000$:
- Maximum value: $999 = 512 + 256 + 128 + 64 + 32 + 4 + 2 + 1$
- $s_2(999) = 1+1+1+1+1+0+1+1+1 = 8$ (in binary: $1111100111_2$)
- Actually, $999_{10} = 1111100111_2$, so $s_2(999) = 8$

Let $m = s_2(n)$. Then $s_4(n) = m^2$, requiring:
$$m^2 \leq s_4(n) \leq s_4(999)$$

For $999 = 33333_4$: $s_4(999) = 3+3+3+3+3 = 15$

So $m^2 \leq 15$, giving $m \in \{1, 2, 3\}$ (positive integers only).

## Step 2: Relationship between base-2 and base-4 digit sums

Base-4 digits in binary:
- $0_4 = 00_2$ (zero 1-bits)
- $1_4 = 01_2$ (one 1-bit)
- $2_4 = 10_2$ (one 1-bit)
- $3_4 = 11_2$ (two 1-bits)

If $n$ has base-4 digits $d_k, d_{k-1}, \ldots, d_0$:
- $s_4(n) = \sum d_i$
- $s_2(n) =$ total count of 1-bits across all binary representations of $d_i$

## Step 3: Conditions for each valid $m$

**Case $m=1$:** $s_2(n)=1$ and $s_4(n)=1$
- Only one 1-bit total, so exactly one base-4 digit is 1, others are 0
- Numbers: $1, 4, 16, 64, 256$

**Case $m=2$:** $s_2(n)=2$ and $s_4(n)=4$
- Two 1-bits total; either one digit is 3 ($11_2$) or two digits are 1 or 2
- Valid digit combinations: one 3, or two from {1,2}

**Case $m=3$:** $s_2(n)=3$ and $s_4(n)=9$
- Three 1-bits total; three digits of 1, or one 3 + one 1 or 2, etc.

## Step 4: Enumerate all digiroots

- $1, 4, 16, 64, 256$

Verify: $s_2(1)=1, s_4(1)=1$ ✓

  - $5_4 = 2+1 = 3$ (sum not 4)
  - Need: $11_4=5, 12_4=6, 21_4=9, 22_4=10$ — checking sums: none sum to 4 this way
  - Only: $3, 12, 48, 192, 768$

Verify $s_2(3)=2$ (binary: $11_2$), $s_4(3)=3$ ✗
