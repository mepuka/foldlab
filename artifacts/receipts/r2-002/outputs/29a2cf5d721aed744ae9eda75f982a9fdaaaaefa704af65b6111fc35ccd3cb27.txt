# Counting "SUNS" Subsequences - Detailed Solution

## Step 1: Verify String Structure

The string "SUNSUNSUN...SUN" repeated 10 times has length 30 with:
- **S-positions**: 1, 4, 7, 10, 13, 16, 19, 22, 25, 28 (10 positions)
- **U-positions**: 2, 5, 8, 11, 14, 17, 20, 23, 26, 29 (10 positions)  
- **N-positions**: 3, 6, 9, 12, 15, 18, 21, 24, 27, 30 (10 positions)

## Step 2: Index Mapping

For indices a, b, d, c ∈ {1, 2, ..., 10}, the actual positions are:
- First S (index a): position = 3a - 2
- U (index b): position = 3b - 1
- N (index d): position = 3d
- Second S (index c): position = 3c - 2

## Step 3: Derive Position Constraints

For a valid subsequence "SUNS", we need:

**First S before U:**
$$3a - 2 < 3b - 1 \implies a < b + \frac{1}{3} \implies a \leq b$$

**U before N:**
$$3b - 1 < 3d \implies b < d + \frac{1}{3} \implies b \leq d$$

**N before Second S:**
$$3d < 3c - 2 \implies d < c - \frac{2}{3} \implies d < c$$

**Combined constraints:**
- $1 \leq a \leq b \leq 10$
- $b \leq d \leq 10$
- $d < c \leq 10$

## Step 4: Count Valid 4-tuples

For each valid pair (b, d) with $b \leq d$:
- **Choices for a**: {1, 2, ..., b} → **b choices**
- **Choices for c**: {d+1, d+2, ..., 10} → **(10 - d) choices**

**Total count:**
$$\sum_{b=1}^{10} \sum_{d=b}^{10} b \cdot (10 - d)$$

## Step 5: Calculate Using Summation Formula

For each b, compute $\sum_{d=b}^{10} (10 - d) = \frac{(10-b)(11-b)}{2}$

Therefore:
$$\text{Total} = \sum_{b=1}^{10} b \cdot \frac{(10-b)(11-b)}{2}$$
