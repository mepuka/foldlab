# Solution: Finding all $n < 1000$ where $s_2(n) = (s_4(n))^2$

## Step 1: Establish the constraint on $s_4(n)$

First, I need to find the maximum possible value of $s_4(n)$ for $n < 1000$.

Converting 999 to base 4:
- $999 \div 4 = 249$ R $3$
- $249 \div 4 = 62$ R $1$
- $62 \div 4 = 15$ R $2$
- $15 \div 4 = 3$ R $3$
- $3 \div 4 = 0$ R $3$

So $999 = 33213_4$ and $s_4(999) = 3 + 3 + 2 + 1 + 3 = 12$

Since $n < 1024 = 2^{10}$, we have $s_2(n) \leq 10$.

For $s_2(n) = (s_4(n))^2$:
- If $s_4(n) = 1$: $s_2(n) = 1$ ✓
- If $s_4(n) = 2$: $s_2(n) = 4$ ✓
- If $s_4(n) = 3$: $s_2(n) = 9$ ✓
- If $s_4(n) = 4$: $s_2(n) = 16 > 10$ ✗

Therefore, we need $s_4(n) \in \{1, 2, 3\}$.

## Step 2: Analyze the binary representation of base-4 digits

Key observation: Each base-4 digit encoded in binary:
- $0_4 = 00_2$ → contributes 0 to $s_2$
- $1_4 = 01_2$ → contributes 1 to $s_2$
- $2_4 = 10_2$ → contributes 1 to $s_2$
- $3_4 = 11_2$ → contributes 2 to $s_2$

When $n$ is represented with base-4 digits using only 1 and 2, each contributes equally to $s_2$ and $s_4$. Only digit 3 contributes more to $s_2$ (2 ones) than to $s_4$ (value 1).

## Step 3: Case analysis

**Case $s_4(n) = 1$, $s_2(n) = 1$:**

For $s_4(n) = 1$, exactly one digit is 1, all others are 0. Since $1_4 = 1_2$, we have $s_2 = 1$ automatically.

These are powers of 4: $n = 4^k$ for $k \geq 0$

Checking which are $< 1000$:
- $4^0 = 1$ ✓
- $4^1 = 4$ ✓
- $4^2 = 16$ ✓
- $4^3 = 64$ ✓
- $4^4 = 256$ ✓
- $4^5 = 1024 \geq 1000$ ✗

**Case $s_4(n) = 2$, $s_2(n) = 4$:**

Using digits 1 and/or 2 summing to 2 gives $s_2 = 2 \neq 4$.

Using digit 3 would require $s_4(n) \geq 3$.

**No solutions exist for this case.**

**Case $s_4(n) = 3$, $s_2(n) = 9$:**

Possible digit combinations for $s_4(n) = 3$:
- Three 1's: $s_2 = 3 \neq 9$ ✗
- One 1, one 2: $s_2 = 2 \neq 9$ ✗
- One 3: $s_2 = 2 \neq 9$ ✗

**No solutions exist for this case.**
