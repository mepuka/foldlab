## Step 1: Express $AI$ in terms of triangle parameters

For the isosceles triangle with $AB = BC = c$ and $AC = b$:
- Base angles: $\angle A = \angle C$ (so $AI = IC$)
- Semiperimeter: $s = \frac{2c+b}{2}$

Using $s - c = \frac{b}{2}$ and $s - b = \frac{2c-b}{2}$:

Area: $K = \sqrt{s(s-c)^2(s-b)} = \frac{b}{4}\sqrt{4c^2-b^2}$

Inradius: $r = \frac{K}{s} = \frac{b\sqrt{4c^2-b^2}}{2(2c+b)}$

For angle $A$: $\cos A = \frac{b}{2c}$, so $\sin(A/2) = \sqrt{\frac{2c-b}{4c}}$

Therefore:
$$AI = \frac{r}{\sin(A/2)} = b\sqrt{\frac{c}{2c+b}}$$

## Step 2: Set up the perimeter ratio equation

- Perimeter of $\triangle ABC$: $P_1 = 2c + b$
- Perimeter of $\triangle AIC$: $P_2 = 2 \cdot AI + b$

$$\frac{2c + b}{2b\sqrt{\frac{c}{2c+b}} + b} = \frac{125}{6}$$
