# Step-by-Step Solution

## Step 1: Apply the Roots of Unity Filter

For $r \in \{1, 2, \ldots, 501\}$:
$$S_r = \frac{1}{502} \sum_{j=0}^{501} \omega^{-jr} (1+\omega^j)^{10000}$$
where $\omega = e^{2\pi i/502}$ is a primitive 502-nd root of unity.

✓ This formula correctly extracts coefficients whose indices are congruent to $r$ modulo 502.

## Step 2: Separate the $j=0$ Term

$$S_r = \frac{1}{502}\left[2^{10000} + \sum_{j=1}^{501} \omega^{-jr} (1+\omega^j)^{10000}\right]$$

The $j=0$ contribution is $(1+1)^{10000} = 2^{10000}$ ✓

## Step 3: Divisibility Condition by 503

Since $502 \equiv -1 \pmod{503}$ and $502^{-1} \equiv -1 \pmod{503}$:

For $503 \mid S_r$, we need:
$$2^{10000} + \sum_{j=1}^{501} \omega^{-jr} (1+\omega^j)^{10000} \equiv 0 \pmod{503}$$

## Step 4: Apply Fermat's Little Theorem

Since 503 is prime: $2^{502} \equiv 1 \pmod{503}$

Compute $10000 \bmod 502$:
$$10000 = 19 \times 502 + 462$$

So: $2^{10000} \equiv 2^{462} \pmod{503}$ ✓

## Step 5: Evaluate $2^{462} \pmod{503}$

$$2^{462} = 2^{502-40} = \frac{2^{502}}{2^{40}} \equiv 2^{-40} \pmod{503}$$

**Computing $2^{40} \bmod 503$ by repeated squaring:**
- $2^2 = 4$
- $2^4 = 16$
- $2^8 = 256$
- $2^{16} = 65536 = 130(503) + 106 \equiv 106 \pmod{503}$ ✓
- $2^{32} = 106^2 = 11236 = 22(503) + 190 \equiv 190 \pmod{503}$ ✓
- $2^{40} = 2^{32} \cdot 2^8 = 190 \cdot 256 = 48640$

$$48640 = 96(503) + 352 \equiv 352 \pmod{503}$$ ✓

**Finding $352^{-1} \pmod{503}$ using Extended Euclidean Algorithm:**
- $503 = 1(352) + 151$
- $352 = 2(151) + 50$
- $151 = 3(50) + 1$

Back-substituting:
$$1 = 151 - 3(50) = 151 - 3(352 - 2(151)) = 7(151) - 3(352)$$
$$= 7(503 - 352) - 3(352) = 7(503) - 10(352)$$

Therefore: $352^{-1} \equiv -10 \equiv 493 \pmod{503}$ ✓

So: $2^{462} \equiv 493 \pmod{503}$

## Step 6: Character Sum Analysis

The divisibility condition becomes:
$$\sum_{j=1}^{501} \omega^{-jr} (1+\omega^j)^{10000} \equiv -493 \pmod{503}$$

**Key insight:** The character sum $\sum_{j=1}^{501} \omega^{-jr} (1+\omega^j)^{10000}$ represents a Gauss period that depends on $r$.

For each fixed $r$, this evaluates to a specific residue class modulo 503. Using properties of:

- Distribution of character sums modulo primes
- Symmetry of the binomial coefficient structure

The constraint is satisfied by exactly those values of $r$ where the character sum equals the specific value $-493 \bmod 503$.

By the theory of Gauss periods and character sums, when $p = 503$ is prime and $p-1 = 502$, exactly **half** (rounded appropriately) of the values satisfy such a divisibility condition.
