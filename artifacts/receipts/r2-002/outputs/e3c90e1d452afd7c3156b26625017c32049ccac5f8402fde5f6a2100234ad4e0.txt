## Step 4: Set up dynamic programming recurrence

**Transitions from column x to x+1:**

- f[x+1][1] = f[x][0] + f[x][0] + f[x][1]
  - First term: using D(x) directly
  - Second term: using V(x) then H₁(x)

This simplifies to:
$$f[x+1][1] = 2 \cdot f[x][0] + f[x][1]$$
