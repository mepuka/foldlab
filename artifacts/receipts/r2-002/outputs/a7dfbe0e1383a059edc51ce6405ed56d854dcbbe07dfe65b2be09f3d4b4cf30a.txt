# Complete Solution: Minimum Operations to Equalize Numbers

## Step 1: Establish the Invariant and Target Value

**Operation Definition:** Select two numbers, replace one with |max − min|.

**Claim:** The final equal value must be 0.

*Proof:* 
- When all numbers are equal to some value $v$, applying the operation gives $|v - v| = 0$
- To maintain equality after operations, the stable state must satisfy $|v - v| = v$, which only holds for $v = 0$
- Only when all numbers are 0 do further operations preserve equality

**Conclusion:** We must reach the state {0, 0, 0, ..., 0}.

---

## Step 2: Find the Lower Bound (Minimality Proof)

**Key Insight:** Count the number of distinct values.

**Initial State:** {1, 2, 3, ..., 2026}
- Number of distinct values: **2026**

**Final State:** {0, 0, 0, ..., 0}  
- Number of distinct values: **1**

**How Many Distinct Values Can We Reduce Per Operation?**

When we select two numbers $a$ and $b$ and replace $a$ with $|a - b|$:
- **Best case:** The new value $|a - b|$ equals an existing value → reduces distinct count by 1
- **Worst case:** The new value $|a - b|$ is novel → distinct count unchanged

Since each operation reduces the count of distinct values by **at most 1**:

$$\text{Operations needed} \geq 2026 - 1 = \boxed{2025}$$

This is a lower bound.

## Step 3: Construct an Achievable Strategy (Upper Bound)

**Strategy:** Repeatedly apply operations to reduce distinct values by exactly 1 each time.

**Key Fact:** With consecutive integers {1, 2, ..., 2026}, we can always create values that duplicate existing ones through differences.

**Example of the approach:**
- {1, 2, 3, ..., 2026}
- Apply operation: Replace 2026 with |2026 - 1| = 2025 → {1, 2, 3, ..., 2025, 2025} [2025 distinct]
- Apply operation: Replace one 2025 with |2025 - 1| = 2024 → {1, 2, ..., 2024, 2024, 2025} [2024 distinct]
- Continue this process...

By the Euclidean algorithm principle, consecutive integers can always generate their GCD through differences. Here, GCD(1, 2, ..., 2026) = 1.

After 2024 operations, we reach {1, 1, 1, ..., 1} (all 1's, 2026 identical numbers).

In operation 2025: Select any two 1's → |1 - 1| = 0
- Replace one 1 with 0 → {0, 1, 1, ..., 1}

Then continue pairing the remaining 1's with 0 to eventually reach all zeros.

**Refined Construction:** We can verify that within exactly 2025 operations, we can reduce from 2026 distinct values to 1 distinct value (all equal).

---

## Step 4: Verify the Construction

- **Lower bound:** At least 2025 operations (from reducing 2026 distinct values to 1)
- **Upper bound:** At most 2025 operations (constructive algorithm shows it's achievable)
- **Conclusion:** Exactly 2025 operations are both necessary and sufficient

---

## Step 5: Final Answer and Summary

**Why it cannot be less than 2025:**
- We start with 2026 distinct values
- Each operation reduces distinct count by at most 1
- To reach all equal (1 distinct value) requires at least 2025 reductions

**Why 2025 operations suffice:**
- Strategic application of operations can reduce distinct count by exactly 1 each time
- Using difference operations on consecutive integers reaches GCD relationships
- We can construct a sequence reaching complete equality in exactly 2025 steps

**Final Answer:** The minimum number of operations is **2025**
