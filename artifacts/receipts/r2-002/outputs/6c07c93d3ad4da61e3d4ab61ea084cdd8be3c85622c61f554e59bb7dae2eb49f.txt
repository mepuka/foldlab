# Detailed Solution

## Step 1: Set up coordinates
- $B$ at origin $(0, 0)$
- $C$ at $(10, 0)$

## Step 2: Locate point $E$
For an equilateral triangle $BEC$ with side length 10, the third vertex is at:
$$E = (5, 5\sqrt{3})$$
(midpoint of $BC$ horizontally, with height $\frac{10\sqrt{3}}{2}$)

## Step 3: Express positions of $A$ and $D$
- $A = (-a, 0)$ where $a = AB > 0$
- $D = (10 + d, 0)$ where $d = CD > 0$

## Step 4: Set up the angle condition

Compute the vectors:
$$\overrightarrow{EA} = (-a-5, -5\sqrt{3})$$
$$\overrightarrow{ED} = (5+d, -5\sqrt{3})$$

Dot product:
$$\overrightarrow{EA} \cdot \overrightarrow{ED} = (-a-5)(5+d) + 75 = -(a+5)(5+d) + 75$$

Magnitudes:
$$|\overrightarrow{EA}| = \sqrt{(a+5)^2 + 75}$$
$$|\overrightarrow{ED}| = \sqrt{(5+d)^2 + 75}$$

Using $\cos(120°) = -\frac{1}{2}$:
$$\frac{-(a+5)(5+d) + 75}{\sqrt{(a+5)^2 + 75}\sqrt{(5+d)^2 + 75}} = -\frac{1}{2}$$

## Step 5: Use the distance constraint

From collinearity: 
$$AD = a + 10 + d = 39$$
$$\therefore a + d = 29$$

## Step 6: Substitute and solve

Let $d = 29 - a$. Rearranging the angle equation:
$$2[-(a+5)(34-a) + 75] = -\sqrt{(a+5)^2 + 75}\sqrt{(34-a)^2 + 75}$$

$$-2a^2 + 58a + 190 = \sqrt{(a+5)^2 + 75}\sqrt{(34-a)^2 + 75}$$

Squaring both sides:
$$(-2a^2 + 58a + 190)^2 = [(a+5)^2 + 75][(34-a)^2 + 75]$$

Expanding the left side:
$$4a^4 - 232a^3 + 2604a^2 + 22040a + 36100$$

Expanding the right side (using $(a+5)^2 + 75 = a^2 + 10a + 100$ and $(34-a)^2 + 75 = a^2 - 68a + 1231$):
$$a^4 - 58a^3 + 651a^2 + 5510a + 123100$$

Setting equal and simplifying:
$$3a^4 - 174a^3 + 1953a^2 + 16530a - 87000 = 0$$
$$a^4 - 58a^3 + 651a^2 + 5510a - 29000 = 0$$

Testing $a = 4$:
$$256 - 3712 + 10416 + 22040 - 29000 = 0$$ ✓

## Step 7: Verify the solution

With $a = 4$, we have $d = 25$.

Check angle:
- $\overrightarrow{EA} = (-9, -5\sqrt{3})$, $|\overrightarrow{EA}| = \sqrt{81 + 75} = 2\sqrt{39}$
- $\overrightarrow{ED} = (30, -5\sqrt{3})$, $|\overrightarrow{ED}| = \sqrt{900 + 75} = 5\sqrt{39}$
- $\overrightarrow{EA} \cdot \overrightarrow{ED} = -270 + 75 = -195$
- $\cos(\angle AED) = \frac{-195}{10 \cdot 39} = -\frac{1}{2}$ ✓

Check distance: $AD = 4 + 10 + 25 = 39$ ✓

## Step 8: Compute $|AB - CD|$

$$|AB - CD| = |4 - 25| = |-21| = 21$$

**Final Answer: 21**
