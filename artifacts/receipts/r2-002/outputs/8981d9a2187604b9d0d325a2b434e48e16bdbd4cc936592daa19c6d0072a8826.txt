# Solution Plan

1. **Establish the constraint on $s_2(n)$**
   - Since $n < 1000$, we have $s_2(n) \leq s_2(999) = 8 + 4 + 2 + 1 = 15$
   - Let $m = s_2(n)$. Then $s_4(n) = m^2$, so $m^2 \leq 15$
   - Therefore $m \in \{1, 2, 3\}$ (since $m$ must be positive)

2. **Find the relationship between $s_2(n)$ and $s_4(n)$**
   - Every digit in base 4 can be written as two base-2 digits: $0=00_2$, $1=01_2$, $2=10_2$, $3=11_2$
   - If $n$ has base-4 representation with digits summing to $s_4(n)$, then $s_2(n)$ equals the sum of all base-2 digits in this representation
   - Key insight: $s_2(n) = \sum(\text{digit count of 1's in each base-4 digit's binary form})$

3. **For each valid value of $m$, determine conditions on base-4 digits**
   - For $m = 1$: Need $s_2(n) = 1$ and $s_4(n) = 1$ → only digit 1 appears in base 4
   - For $m = 2$: Need $s_2(n) = 2$ and $s_4(n) = 4$ → digits must sum to 4 with exactly two 1-bits total
   - For $m = 3$: Need $s_2(n) = 3$ and $s_4(n) = 9$ → digits must sum to 9 with exactly three 1-bits total

4. **Enumerate all digiroots for each case**
   - Systematically list all $n < 1000$ for each valid $m$ value
   - Verify each candidate by computing $s_2(n)$ and $s_4(n)$ directly

5. **Calculate the sum**
   - Add all digiroots found in step 4 to get the final answer
