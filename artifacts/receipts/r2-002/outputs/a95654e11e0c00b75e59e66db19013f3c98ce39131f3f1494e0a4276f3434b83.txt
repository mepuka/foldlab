## Verification of the Factorization

The factorization is correct:
$$n = a + b + ab = (a+1)(b+1) - 1$$

So we need $(a+1)(b+1) \leq 101$ with $a, b$ distinct positive integers.

## Systematic Count

For each value of $a$, we need $b > a$ (to avoid double-counting) and:
$$n = a + b + ab \leq 100$$
$$b(1+a) \leq 100 - a$$
$$b \leq \frac{100-a}{1+a}$$
