# Complete Solution: Minimum Operations to Make All Numbers Equal

## 1. Establish the Invariant and Target Value

**Operation Definition**: Replace two numbers with their difference |max − min|

**Key Observation 1**: Each operation takes the maximum and minimum of our set and replaces them with |max − min|.

**Key Observation 2**: The new value satisfies: |max − min| ≤ max

This means the largest number can never increase.

**Claim**: The only possible final equal value is **0**.

*Proof*: Suppose all remaining numbers equal some value $k > 0$. Then max = min = $k$, so |max − min| = 0. If we perform any operation, we create a 0, contradicting that all numbers equal $k > 0$. Therefore, the only stable equal state is all zeros.

---

## 2. Find the Lower Bound (Necessity)

**Counting Non-Zero Numbers**

Starting set: {1, 2, 3, ..., 2026}
- Initially: **2025 non-zero numbers** (all positive)

**Claim**: Each operation reduces the count of non-zero numbers by **at most 1**.

*Proof*: 
- Each operation removes two numbers (the current max and min)
- Each operation adds one number: |max − min|
- Net change: removes 2, adds 1 = removes 1 net
- However, if |max − min| = 0, we add a zero (which we don't count as non-zero)
- If |max − min| ≠ 0, we still reduce non-zeros by exactly 1

**Counting Argument**:
- Start: 2025 non-zero numbers
- Target: 0 non-zero numbers
- Reduction needed: 2025 non-zero numbers
- Each operation reduces non-zeros by at most 1
- **Minimum operations required: 2025**

---

## 3. Construct an Achievable Strategy (Sufficiency)

**Strategy**: Apply operations in the following systematic way:

**Step-by-step construction**:
- Current set: {1, 2, 3, ..., 2026}
- **Operation 1**: Replace min=1 and max=2026 with |2026−1|=2025
  - Result: {2, 3, 4, ..., 2025, 2025}

- **Operation 2**: Replace min=2 and max=2025 with |2025−2|=2023
  - Result: {3, 4, 5, ..., 2024, 2023, 2025}

- **Operation 3**: Replace min=3 and max=2025 with |2025−3|=2022
  - Result: {4, 5, 6, ..., 2024, 2022, 2023}

**General Pattern** (Operation $k$, for $k = 1, 2, ..., 2024$):
- Current minimum: $k$
- Current maximum: $2027-k$ (approximately)
- Replace them with their difference
- This systematically pairs numbers from the low and high ends

**Final Operations**:
- After 2024 operations: We're left with two equal numbers, say {$a, a$} where $a > 0$
- **Operation 2025**: Replace min=$a$ and max=$a$ with |$a-a$|=0
  - Result: {0, 0, ..., 0}

**Why exactly 2025 operations?**

After operation $k$: 
- We have removed $k$ "distinct non-zero values" from the original set
- We have 2026 − $k$ positions that can contain values
- We still need to eliminate the remaining 2025 − $k$ non-zero values
- After 2024 operations: 1 pair of equal non-zero values remains
- After 2025 operations: All zeros

---

## 4. Verify the Construction Works

**Verification of Feasibility**:

Each operation is valid because:
1. ✓ We always have at least 2 numbers (until the final state)
2. ✓ max ≥ min always (by definition)
3. ✓ |max − min| is always well-defined and ≥ 0

**Progress Toward Goal**:

| Operation | Non-Zero Count | Example State |
|-----------|---|---|
| Start | 2025 | {1, 2, 3, ..., 2026} |
| After 1 | 2024 | {2, 3, ..., 2025, 2025} |
| After 2 | 2023 | {3, 4, ..., 2024, 2023, 2025} |
| After k | 2025−k | (k distinct values eliminated) |
| After 2024 | 1 | {$a, a$} for some $a > 0$ |
| After 2025 | 0 | {0, 0, ..., 0} |

✓ Each operation reduces non-zero count by exactly 1  
✓ Process terminates when all numbers equal 0  
✓ Terminates in exactly 2025 operations  

---

## 5. Final Answer and Proof Summary

### **ANSWER: 2025**

**Lower Bound (Necessity)**:
- We start with 2025 positive numbers
- Each operation reduces the count of non-zero numbers by at most 1
- We need to reach 0 non-zero numbers
- Therefore, at least **2025 operations** are required

**Upper Bound (Sufficiency)**:
- We constructed an explicit sequence of 2025 operations
- This sequence transforms {1, 2, 3, ..., 2026} into {0, 0, ..., 0}
- Therefore, **at most 2025 operations** are needed

**Conclusion**:
The minimum number of operations is **exactly 2025**, as the lower and upper bounds coincide.
