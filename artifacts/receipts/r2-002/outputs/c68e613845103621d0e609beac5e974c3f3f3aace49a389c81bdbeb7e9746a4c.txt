# Solution: Pentagon HORSE Area Calculation

## Step 1: Set up Coordinate System
- Place $O$ at the origin: $O = (0, 0)$
- Place $H$ at: $H = (20, 0)$ (using $HO = 20$)

## Step 2: Find Point E
Since $\angle EHO = 90°$, point $E$ lies perpendicular to line $HO$ from $H$.
Therefore: $E = (20, h)$ for some height $h > 0$

## Step 3: Find Point S
Since $\angle SEH = 90°$, vectors $\vec{EH}$ and $\vec{ES}$ are perpendicular.

$\vec{EH} = (0, -h)$

For perpendicularity: $\vec{EH} \cdot \vec{ES} = 0$
$$0 \cdot (S_x - 20) + (-h)(S_y - h) = 0$$
$$S_y = h$$

So $S = (S_x, h)$ for some $S_x$.

**Using $OS = 10$:**
$$S_x^2 + h^2 = 100$$

**Using $SE = 26$:**
$$|S_x - 20| = 26$$
$$S_x = -6 \text{ or } S_x = 46$$

Testing $S_x = -6$:
$$36 + h^2 = 100 \implies h = 8$$

Therefore: $S = (-6, 8)$ and $E = (20, 8)$

## Step 4: Find Point R
The ray $OR$ makes angle $\angle HOR = 135°$ with ray $OH$.

Direction of $OR$: $(\cos 135°, \sin 135°) = (-\frac{\sqrt{2}}{2}, \frac{\sqrt{2}}{2})$

Let $R = (-\frac{r\sqrt{2}}{2}, \frac{r\sqrt{2}}{2})$ for some $r > 0$

**Using $\angle ORS = 90°$:**
$$\vec{RO} \cdot \vec{RS} = 0$$

$$\vec{RO} = (\frac{r\sqrt{2}}{2}, -\frac{r\sqrt{2}}{2})$$
$$\vec{RS} = (-6 + \frac{r\sqrt{2}}{2}, 8 - \frac{r\sqrt{2}}{2})$$

$$\frac{r\sqrt{2}}{2}(-6 + \frac{r\sqrt{2}}{2}) - \frac{r\sqrt{2}}{2}(8 - \frac{r\sqrt{2}}{2}) = 0$$

$$\frac{r\sqrt{2}}{2}[-14 + r\sqrt{2}] = 0$$

$$r = 7\sqrt{2}$$

Therefore: $R = (-7, 7)$

**Verification of $\angle RSE = 135°$:**
- $\vec{SR} = (-1, -1)$, $\vec{SE} = (26, 0)$
- $\cos(\angle RSE) = \frac{-26}{26\sqrt{2}} = -\frac{\sqrt{2}}{2}$ ✓ (equals $\cos 135°$)

## Step 5: Calculate Area using Triangulation

Pentagon vertices in order: $H(20, 0) \to O(0, 0) \to R(-7, 7) \to S(-6, 8) \to E(20, 8)$

Triangulate from vertex $H$:

**Triangle HOR:**
$$A_1 = \frac{1}{2}|20(0-7) + 0(7-0) + (-7)(0-0)| = \frac{1}{2}|-140| = 70$$

**Triangle HRS:**
$$A_2 = \frac{1}{2}|20(7-8) + (-7)(8-0) + (-6)(0-7)|$$
$$= \frac{1}{2}|-20 - 56 + 42| = \frac{1}{2}|-34| = 17$$

**Triangle HSE:**
$$A_3 = \frac{1}{2}|20(8-8) + (-6)(8-0) + 20(0-8)|$$
$$= \frac{1}{2}|0 - 48 - 160| = \frac{1}{2}|-208| = 104$$

**Total Area:**
$$A = 70 + 17 + 104 = 191$$
