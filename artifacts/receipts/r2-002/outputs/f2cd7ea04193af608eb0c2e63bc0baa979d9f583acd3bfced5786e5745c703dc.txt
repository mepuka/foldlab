# Solution: Finding All Fixed Points of f(n)

## Step 1-3: One-Digit Numbers (1-9)

For any single digit $n$ where $1 \leq n \leq 9$:
- The base is $b = n + 1$
- The digit $n$ in base $b$ represents value $n$ (since $n < b$)
- Therefore $f(n) = n$ automatically

**Count: 9 fixed points**

---

## Step 4: Two-Digit Numbers (10-99)

Let $n = 10a + c$ where $1 \leq a \leq 9$ and $0 \leq c \leq 9$.

**Setting up the equation:**
- Base: $b = \max(a, c) + 1$
- In base $b$, the digits form: $ab + c$
- Fixed point condition: $ab + c = 10a + c$

**Solving:**
$$ab + c = 10a + c$$
$$ab = 10a$$
$$b = 10$$

This requires: $\max(a, c) + 1 = 10$, so $\max(a, c) = 9$

**Counting solutions where $\max(a, c) = 9$:**

- **Case 1:** $a = 9$ (automatically $\max = 9$)
  - $c$ can be $0, 1, 2, ..., 9$ → **10 solutions**
  - Numbers: 90, 91, 92, ..., 99

- **Case 2:** $a \in \{1, 2, ..., 8\}$ and $c = 9$
  - $a$ can be $1, 2, ..., 8$ → **8 solutions**
  - Numbers: 19, 29, 39, 49, 59, 69, 79, 89

**Verification:** $n = 59$: base $b = \max(5,9) + 1 = 10$; $f(59) = 5 \times 10 + 9 = 59$ ✓

**Count: 18 fixed points**

---

## Step 5: Three-Digit Numbers (100-999)

Let $n = 100a + 10b + c$ where $1 \leq a \leq 9$ and $0 \leq b, c \leq 9$.

**Setting up the equation:**
- Base: $B = \max(a, b, c) + 1$
- In base $B$: $aB^2 + bB + c$
- Fixed point condition: $aB^2 + bB + c = 100a + 10b + c$

**Simplifying:**
$$aB^2 + bB = 100a + 10b$$
$$a(B^2 - 100) + b(B - 10) = 0$$
$$a(B^2 - 100) = b(10 - B)$$

**Finding valid bases:**

- **If $B = 10$:** Then $a(0) = b(0)$, which is satisfied for any valid digits!

- **If $B > 10$:** Then $B^2 - 100 > 0$ (positive) and $10 - B < 0$ (negative). Since $a > 0$, LHS is positive, but RHS is non-positive (negative or zero). This forces $b = 0$, then $a(B^2-100) = 0$, impossible.

- **If $B < 10$ (i.e., $B \leq 9$):** Then $B^2 - 100 < 0$ (negative) and $10 - B > 0$ (positive). For $b > 0$, RHS is positive while LHS is negative, contradiction. For $b = 0$, we get $a(B^2-100) = 0$, impossible.

**Therefore $B = 10$ is the only solution,** requiring $\max(a, b, c) = 9$.

**Counting solutions where $\max(a, b, c) = 9$:**

Using complementary counting:
- Total three-digit numbers: $9 \times 10 \times 10 = 900$
- Numbers where all digits $\leq 8$: $8 \times 9 \times 9 = 648$
- Numbers where $\max(a, b, c) = 9$: $900 - 648 = 252$

**Verification:** $n = 900$: digits are 9, 0, 0; base $B = 10$; $f(900) = 9(100) + 0(10) + 0 = 900$ ✓

**Count: 252 fixed points**

---

## Final Answer

$$\text{Total} = 9 + 18 + 252 = \boxed{279}$$
