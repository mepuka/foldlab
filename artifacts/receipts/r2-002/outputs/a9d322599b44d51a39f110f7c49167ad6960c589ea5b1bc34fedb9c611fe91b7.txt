# Solution to HATER + HEART = EARTH

## Step 1: Simplify the Equation

Starting with: HATER + HEART = EARTH

**Expand each number:**
- HATER = 10000H + 1000A + 100T + 10E + R
- HEART = 10000H + 1000E + 100A + 10R + T
- EARTH = 10000E + 1000A + 100R + 10T + H

**Set up the equation:**
$$10000H + 1000A + 100T + 10E + R + 10000H + 1000E + 100A + 10R + T = 10000E + 1000A + 100R + 10T + H$$

**Combine like terms on left side:**
$$20000H + 1100A + 101T + 1010E + 11R = 10000E + 1000A + 100R + 10T + H$$

**Move all terms to one side:**
$$20000H - H + 1100A - 1000A + 101T - 10T + 1010E - 10000E + 11R - 100R = 0$$

$$19999H + 100A + 91T - 8990E - 89R = 0$$

**Rearrange:**
$$19999H + 100A + 91T = 8990E + 89R$$
