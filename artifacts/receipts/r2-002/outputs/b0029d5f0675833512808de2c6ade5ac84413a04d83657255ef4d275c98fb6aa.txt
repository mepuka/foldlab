# Solution

## Step 1: Identify valid values of $r$

For $n = \frac{5r + 8}{4}$ to be an integer, we need:
$$5r + 8 \equiv 0 \pmod{4}$$

Since $8 \equiv 0 \pmod{4}$:
$$5r \equiv 0 \pmod{4}$$

Since $5 \equiv 1 \pmod{4}$:
$$r \equiv 0 \pmod{4}$$

Therefore $r = 4k$ for positive integers $k$.

## Step 2: Apply the minimum color constraint

We need both $r \geq 7$ and $b \geq 7$.

**For $r \geq 7$:** Since $r = 4k$, we need $k \geq 2$ (as $4 \cdot 2 = 8 \geq 7$).

**For $b \geq 7$:**
$$b = n - r = \frac{5r + 8}{4} - r = \frac{5r + 8 - 4r}{4} = \frac{r + 8}{4}$$

$$\frac{r + 8}{4} \geq 7$$
$$r + 8 \geq 28$$
$$r \geq 20$$

Combined: $r \geq 20$ and $r \equiv 0 \pmod{4}$.

## Step 3: Find the five smallest valid values of $n$

Testing $r = 20, 24, 28, 32, 36$:

| $r$ | $n = \frac{5r + 8}{4}$ | $b = n - r$ | Check |
|-----|----------------------|-------------|-------|
| 20  | $\frac{108}{4} = 27$ | $27 - 20 = 7$ | ✓ |
| 24  | $\frac{128}{4} = 32$ | $32 - 24 = 8$ | ✓ |
| 28  | $\frac{148}{4} = 37$ | $37 - 28 = 9$ | ✓ |
| 32  | $\frac{168}{4} = 42$ | $42 - 32 = 10$ | ✓ |
| 36  | $\frac{188}{4} = 47$ | $47 - 36 = 11$ | ✓ |

Five smallest valid $n$ values: $27, 32, 37, 42, 47$

## Step 4: Calculate the sum

These form an arithmetic sequence with first term $a_1 = 27$, last term $a_5 = 47$, and $n = 5$ terms.

$$\text{Sum} = \frac{n(a_1 + a_5)}{2} = \frac{5(27 + 47)}{2} = \frac{5 \times 74}{2} = \frac{370}{2} = 185$$

**Verification by direct addition:** $27 + 32 + 37 + 42 + 47 = 185$ ✓

Final answer (single integer only): **185**
