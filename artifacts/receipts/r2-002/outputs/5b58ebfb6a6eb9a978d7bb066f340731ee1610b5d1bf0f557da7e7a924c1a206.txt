# Solution

## Step 1: Set up coordinates
- Place $B$ at origin: $B = (0, 0)$
- Place $C$ on x-axis: $C = (10, 0)$
- Verified: $BC = 10$ ✓

## Step 2: Locate point $E$
For equilateral triangle $BEC$ with side length 10:
- The third vertex is at the midpoint x-coordinate: $x = 5$
- Height of equilateral triangle: $h = \frac{10\sqrt{3}}{2} = 5\sqrt{3}$
- Therefore: $E = (5, 5\sqrt{3})$ ✓

## Step 3: Express positions of $A$ and $D$
- $A = (-a, 0)$ where $a = AB > 0$ (left of $B$)
- $D = (10 + d, 0)$ where $d = CD > 0$ (right of $C$)

## Step 4: Apply angle condition $\angle AED = 120°$

Compute vectors:
- $\overrightarrow{EA} = (-a - 5, -5\sqrt{3})$
- $\overrightarrow{ED} = (5 + d, -5\sqrt{3})$

Dot product:
$$\overrightarrow{EA} \cdot \overrightarrow{ED} = (-a-5)(5+d) + 75$$

Magnitudes:
$$|\overrightarrow{EA}| = \sqrt{(a+5)^2 + 75}$$
$$|\overrightarrow{ED}| = \sqrt{(5+d)^2 + 75}$$

Using $\cos(120°) = -\frac{1}{2}$:
$$\frac{(-a-5)(5+d) + 75}{\sqrt{(a+5)^2 + 75}\sqrt{(5+d)^2 + 75}} = -\frac{1}{2}$$

## Step 5: Use distance constraint $AD = 39$

From collinearity:
$$AD = (10 + d) - (-a) = a + 10 + d = 39$$
$$a + d = 29$$
$$d = 29 - a$$

## Step 6: Substitute constraint into angle equation

Replace $d = 29 - a$, so $5 + d = 34 - a$:
$$\frac{(-a-5)(34-a) + 75}{\sqrt{(a+5)^2 + 75}\sqrt{(34-a)^2 + 75}} = -\frac{1}{2}$$

Expand numerator:
$$(-a-5)(34-a) + 75 = -34a + a^2 - 170 + 5a + 75 = a^2 - 29a - 95$$

Cross multiply:
$$2(a^2 - 29a - 95) = -\sqrt{(a+5)^2 + 75}\sqrt{(34-a)^2 + 75}$$

Square both sides:
$$4(a^2 - 29a - 95)^2 = [(a+5)^2 + 75][(34-a)^2 + 75]$$

**Left side:** $4(a^4 - 58a^3 + 651a^2 + 5510a + 9025)$

**Right side:** 
- $(a+5)^2 + 75 = a^2 + 10a + 100$
- $(34-a)^2 + 75 = a^2 - 68a + 1231$
- Product: $a^4 - 58a^3 + 651a^2 + 5510a + 123100$

Simplifying:
$$4a^4 - 232a^3 + 2604a^2 + 22040a + 36100 = a^4 - 58a^3 + 651a^2 + 5510a + 123100$$

$$3a^4 - 174a^3 + 1953a^2 + 16530a - 87000 = 0$$

Divide by 3:
$$a^4 - 58a^3 + 651a^2 + 5510a - 29000 = 0$$

## Step 7: Find solution

Testing $a = 4$:
$$256 - 58(64) + 651(16) + 5510(4) - 29000$$
$$= 256 - 3712 + 10416 + 22040 - 29000 = 0$$ ✓

Therefore $a = 4$ and $d = 29 - 4 = 25$.

## Step 8: Verification and final calculation

Check: $\cos(\angle AED) = \frac{-195}{2\sqrt{39} \cdot 5\sqrt{39}} = \frac{-195}{390} = -\frac{1}{2}$ ✓

Calculate:
$$|AB - CD| = |a - d| = |4 - 25| = |-21| = 21$$

ANSWER: **21**
