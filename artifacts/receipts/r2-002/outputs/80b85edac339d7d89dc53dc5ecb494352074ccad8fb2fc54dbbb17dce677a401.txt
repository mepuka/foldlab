# Solution to Pentagon HORSE Area Problem

## Step 1: Set up a coordinate system

Place $O$ at the origin and $H$ on the positive $x$-axis:
- $O = (0, 0)$
- $H = (20, 0)$ (since $HO = 20$)

## Step 2: Find point $S$ using $OS = 10$ and angle constraints

Point $S$ lies on a circle of radius 10 centered at $O$. We need to determine its angular position.

Given $\angle HOR = 135°$, this is the angle at $O$ from ray $OH$ to ray $OR$.

For point $S$, we use $OS = 10$. Based on the constraint that $\angle RSE = 135°$ and $\angle ORS = 90°$, let's position $S$ at angle $\theta_S$ from the positive $x$-axis.

Let me place: $S = (10\cos\alpha, 10\sin\alpha)$ for some angle $\alpha$ to be determined.

## Step 3: Locate point $E$ using constraints

We have:
- $SE = 26$
- $\angle SEH = 90°$ (right angle at $E$)
- $\angle EHO = 90°$ (right angle at $H$)

Since $\angle EHO = 90°$, point $E$ lies on a line perpendicular to $HO$ at $H$.
Since $HO$ is along the $x$-axis, $E$ must be directly above or below $H$:
$$E = (20, h)$$ for some $h \neq 0$.

## Step 4: Find point $R$ using angle constraints

Given $\angle HOR = 135°$, and $R$ is positioned such that:
$$R = (|OR|\cos(135°), |OR|\sin(135°)) = (-\frac{|OR|}{\sqrt{2}}, \frac{|OR|}{\sqrt{2}})$$

Using $\angle ORS = 90°$: vectors $\vec{RO}$ and $\vec{RS}$ are perpendicular.

Let me work backwards from the constraint $\angle RSE = 135°$.

## Step 5: Solve the system systematically

From $\angle EHO = 90°$: $E = (20, y_E)$ where $y_E > 0$.

From $SE = 26$ and $\angle SEH = 90°$:
- $\vec{ES} \perp \vec{EH}$
- $\vec{EH} = (0, -y_E)$ (pointing downward)
- So $\vec{ES}$ must be horizontal: $S = (20 - 26, y_E) = (-6, y_E)$

From $OS = 10$:
$$(-6)^2 + y_E^2 = 100$$
$$36 + y_E^2 = 100$$
$$y_E = 8$$

Therefore: $S = (-6, 8)$ and $E = (20, 8)$

From $\angle HOR = 135°$ and $\angle ORS = 90°$:

Let $R = (r_x, r_y)$. Then:
- $\vec{RO} \cdot \vec{RS} = 0$ (perpendicularity at $R$)
- $\vec{RO} = (-r_x, -r_y)$ and $\vec{RS} = (-6 - r_x, 8 - r_y)$

$$(-r_x)(-6 - r_x) + (-r_y)(8 - r_y) = 0$$
$$r_x(6 + r_x) + r_y(r_y - 8) = 0$$
$$r_x^2 + 6r_x + r_y^2 - 8r_y = 0$$

With $\angle HOR = 135°$: $R = (r\cos(135°), r\sin(135°)) = (-\frac{r}{\sqrt{2}}, \frac{r}{\sqrt{2}})$

Substituting:
$$\frac{r^2}{2} - \frac{6r}{\sqrt{2}} + \frac{r^2}{2} - \frac{8r}{\sqrt{2}} = 0$$
$$r^2 - \frac{14r}{\sqrt{2}} = 0$$
$$r = \frac{14}{\sqrt{2}} = 7\sqrt{2}$$

Therefore: $R = (-7, 7)$

## Step 6: Calculate area using the Shoelace formula

Vertices in order: $H = (20, 0)$, $O = (0, 0)$, $R = (-7, 7)$, $S = (-6, 8)$, $E = (20, 8)$

$$\text{Area} = \frac{1}{2}|x_1(y_2-y_5) + x_2(y_3-y_1) + x_3(y_4-y_2) + x_4(y_5-y_3) + x_5(y_1-y_4)|$$

$$= \frac{1}{2}|20(0-8) + 0(7-0) + (-7)(8-0) + (-6)(8-7) + 20(0-8)|$$
$$= \frac{1}{2}|-160 + 0 - 56 - 6 - 160|$$
$$= \frac{1}{2}|-382| = 191$$

# Final Answer

The area of pentagon $HORSE$ is $\boxed{191}$ square units.
