Columnar projection spike

Three UI views of kernel-language data, each an anchored fold state: a checkpointed read, not a live dashboard. Every control below is a lawful combinator with its law named. Security is a first-class column dimension: sealed column families, two viewer authorities, and deterministic-vs-random encryption side by side.

Glossary — every house term, glossed for outsiders
digest
A value's name: the hash of its one canonical byte form. One value, one name, forever. Reads re-derive the digest of what they fetched (“verify-on-read”), so nothing is trusted.
anchor
A checkpoint coordinate — (floor, state, head) in one partition of one event lane. An answer pinned to an anchor is never wrong later, only earlier.
fold
The kernel's one read of changing state: reduce everything recorded on a lane, as of an anchor. Rosters, audits, and search are all folds with different declared reductions — and so is each view on this page.
writ
A capability document. Authority only narrows: a child's writ is the meet (greatest lower bound) of its parent's and its request. Here, a writ decides which column-family keys a viewer holds.
hole / provision
A declared parameter of a program, and the event that fills it. The environment is not a mutable map: it is the set of positioned provision events, read back as “greatest position wins.”
rung
Where an aggregation's algebra sits on the ladder (monoid, commutative monoid, semilattice). The rung fixes what delivery discipline the aggregate can survive.
dot
One journal coordinate: (lane, shard, position). The meaning plane and the storage plane meet only there — rows are joined by position, never by pointer.
redacted vs absent
Redacted: the data exists and its integrity is verified, but your writ holds no key — access is withheld, visibly. Absent: the fetch itself failed verification. Different states, rendered differently, never conflated.
convergent encryption
Deterministic sealing: the key is derived from the content plus a scope secret, so the same plaintext always yields the same ciphertext — naming and dedup survive encryption. Cost: within the scope, equal values are visibly equal (an equality leak). Tahoe-LAFS is the prior art.
AEAD associated data
Authenticated encryption can bind extra bytes (“associated data”) into its integrity check. Binding the dot coordinate means sealed bytes cannot be replayed at a different coordinate.

A. The taught-refusal table

The 16 refusal rows of the kernel language, verbatim from verify/kernel/projections/kernel.ts. A refusal is a value carrying the law it defends and the legal next move. Grouped by applicability: machine-applicable means the repair is a mechanical rewrite of the refused sentence alone; advisory means the repair needs something the sentence does not carry. Each group carries per-column statistics wearing their rung badges.

B. The example-sentence roster

The nine walkthrough sentences of kernel.ts (s1–s8 plus the roster read), one row per spoken act. Encoded identity is the digest of each sentence's canonical byte form — the sentence's own name (simulated hash; see footer). The digests referenced aggregate is a set union: the semilattice aggregate in its purest form.

C. Positioned-provision log — three column families, two planes, two writs

A synthetic 20-row provision log (minted for this spike; a real view derives these rows from declared lanes). Each row fills a program hole at a journal position. The meaning family is the value plane; the storage family is placement hints, joined to meaning only by row position (the dot); the seal family is security metadata for the sealed columns. greatest_read is derived, not stored: per hole, the provision at the greatest position wins — the environment as a fold. Toggle the viewer's writ to see honest redaction; toggle convergent vs random sealing to watch content-addressed naming survive or fracture.

Simulation notice. No real cryptography runs on this page. Digests are FNV-1a toy hashes (not SHA-256); “sealed,” “verified,” and “redacted” are rendered states; no key material exists anywhere in this file — key references are data, key material is outside meaning by law. What is demonstrated is the algebra: which view operations commute with which security choices. Scheme names (AES-SIV, AES-GCM) label the simulated states, nothing more.
