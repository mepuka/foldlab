Notes:

- The minimum premise counterexample is only the first three publishes:
  A1@1, B1@2, A2@3. Partition A cannot advance from floor 1 to A2@3 because
  position 2 belongs to B and can never arrive through A's filter.
- The later rows exercise durable client reattachment, redelivery, and abrupt
  restart of the same file-backed server store. The hard server stop can replay
  recently acknowledged records; this probe does not use that observation to
  make an acknowledgement-durability claim. It is pertinent here only because
  every replay preserves the event's stream sequence while consumer sequence
  describes deliveries rather than event identity.
