### P1 - Extraction : PARTIAL, blocked twice

   Result: {"admitted": true, "state": "filled"}. Provenance is SHAPE-ONLY

   semantics falsely); mint one protocol per document via the free `name`

   identifies "the extraction protocol").

Ingress CAN carry a briefing corpus today: probe-p3-research.ts (p3.stdout,

corpus exists. The REFERENCE half does not.

SINGLE SMALLEST MISSING PIECE: one optional, identity-bearing field on the
flb.req.protocol.session.open event naming what the session is over (a

G7 (pin to head or to session identity) - CONSTRAINED BY MEASUREMENT. Since
session identity is a pure function of (protocol, bindings, predecessor?)
(I1), pinning "to a session identity" pins to something already determined by
the parent's own choice of protocol and bindings - it carries no information
about the run. The draft's instinct ("pin to head") is the only option that
carries evidence.

   types -> protocol -> sessions for one domain; P2 proves session ->
   protocol -> session. Together they close the tower's middle.
